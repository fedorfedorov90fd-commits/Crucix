# Copper-Gold Ratio Module

## 📋 Описание
**Русский:**
Модуль **Copper-Gold Ratio** отображает соотношение цен на медь и золото — ключевой индикатор экономического цикла. Медь (Dr. Copper) отражает промышленный спрос, золото — защитный актив. Рост соотношения указывает на экономический подъём, падение — на рецессию.

**English:**
The **Copper-Gold Ratio** module displays the copper-to-gold price ratio — a key economic cycle indicator. Copper (Dr. Copper) reflects industrial demand, gold is a safe-haven asset. Rising ratio indicates economic expansion, falling indicates recession.

## 🎯 Назначение
- Предсказание рецессий
- Оценка промышленной активности
- Торговые сигналы

## 🚀 Использование
1. Страница: `/copper-gold`
2. API: `/api/copper-gold`
3. Параметры: `?interval=daily`
