# COVID-19 Module

## 📋 Описание
**Русский:**
Модуль **COVID-19** отслеживает статистику пандемии: случаи, смертность, вакцинацию, варианты вируса. Интегрируется с WHO, CDC, ECDC и университетскими проектами. Используется для эпидемиологического мониторинга.

**English:**
The **COVID-19** module tracks pandemic statistics: cases, deaths, vaccination, virus variants. Integrates with WHO, CDC, ECDC and university projects. Used for epidemiological monitoring.

## 🎯 Назначение
- Эпидемиологический мониторинг
- Отслеживание вакцинации
- Анализ вариантов вируса

## 🚀 Использование
1. Страница: `/covid`
2. API: `/api/covid`
3. Параметры: `?country=US&variant=Omicron`
