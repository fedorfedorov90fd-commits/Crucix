# Reports Module

## 📋 Описание
**Русский:**
Модуль **Reports** предоставляет систему генерации отчётов в Crucix. Поддерживает различные форматы: PDF, Excel, HTML, CSV. Позволяет настраивать шаблоны, расписания и автоматическую отправку.

**English:**
The **Reports** module provides a report generation system in Crucix. Supports various formats: PDF, Excel, HTML, CSV. Allows configuring templates, schedules and automatic sending.

## 🎯 Назначение
- Генерация отчётов
- Экспорт в форматы
- Автоматическая отправка

## 🚀 Использование
1. Страница: `/reports`
2. API: `/api/reports`
3. Параметры: `?format=pdf&template=daily`
