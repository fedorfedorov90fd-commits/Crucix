# ai-processor

## 📋 О МОДУЛЕ / ABOUT

**Русский:**
AI-процессор для анализа новостей и данных. Использует локальный Ollama (deepseek-r1:1.5b) для оценки и генерации ответов.

**English:**
AI processor for news and data analysis. Uses local Ollama (deepseek-r1:1.5b) for evaluation and response generation.
