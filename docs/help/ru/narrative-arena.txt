───────────────────────────────────────
НАЗНАЧЕНИЕ
───────────────────────────────────────
Сверить российский и западный нарративы по заданной теме.
Три колонки: РОССИЯ / ЗАПАД / РАСХОЖДЕНИЯ.

Это интерактивная страница — пользователь вводит тему, нажимает
«СВЕРИТЬ НАРРАТИВЫ», и видит, как одна и та же тема освещается
двумя сторонами.

Терминология: слово «сверить» выбрано специально — это научный термин
сопоставления, а не разговорное «сварить» или бухгалтерское «сверка».
Глагольная форма: «Сверить нарративы».

───────────────────────────────────────
КАК ПОЛЬЗОВАТЬСЯ
───────────────────────────────────────
1. Открой http://localhost:3117/narrative-arena
2. Введи тему в поле ввода (или нажми пресет)
3. Нажми «СВЕРИТЬ НАРРАТИВЫ»
4. Смотри на три колонки:
   - Слева: Российский нарратив (claims, отсортированные по дате)
   - Справа: Западный нарратив
   - По центру: Расхождения (silence, framing_gap, double_standard)
5. Внизу: хронология (timeline) — все claims в порядке даты

ПРЕСЕТЫ (быстрые кнопки):
  санкции, Украина, энергопереход, конфликт, газ

АВТОЗАПУСК: при открытии страницы сразу вызывается weld() с текущей темой
(по умолчанию «санкции»).

───────────────────────────────────────
ЧТО ПОКАЗЫВАЕТ КАЖДАЯ ЧАСТЬ
───────────────────────────────────────
STATS BAR (верхняя полоса):
  Просканировано: сколько items из rsshub.json обработано
  По теме: сколько совпало с фильтром
  🇷🇺: сколько в российском полюсе
  🇺🇸: сколько в западном
  🌍: сколько в неприсоединившихся
  Источник: какой basket-файл использован

КОЛОНКА «РОССИЙСКИЙ НАРРАТИВ»:
  - Заголовок: «🇷🇺 Российский нарратив»
  - Фрейминг: «Российский нарратив по теме «X» (всего: N)»
  - Список claims: заголовок + источник + ссылка ↗ + дата
  - Если пусто: «Нет упоминаний»

КОЛОНКА «ЗАПАДНЫЙ НАРРАТИВ»:
  Симметрично для западных источников

КОЛОНКА «РАСХОЖДЕНИЯ»:
  Каждая точка расхождения с цветовой кодировкой:
  - Жёлтый — silence (замалчивание) — одна сторона пишет, другая молчит
  - Красный — double_standard (двойной стандарт) — дисбаланс >3x
  - Синий — framing_gap (расхождение) — обе пишут, но по-разному

TIMELINE (внизу):
  Все claims из обеих сторон по дате, с цветовой маркировкой полюса
  РФ (красный) / ЗАП (зелёный)

КНОПКА «КОПИРОВАТЬ»
───────────────────────────────────────

───────────────────────────────────────
ТЕХНИЧЕСКИЕ ДЕТАЛИ
───────────────────────────────────────
API endpoint, который вызывает страница:
  /api/layers/narrative-splitter?topic={тема}&limit=15

Ответ ожидается в формате:
  {
    success: true,
    data: {
      topic, topic_prefix, source_file,
      stats: { total_scanned, topic_matches, russian_count, ... },
      russian_narrative: { framing, count, sources, claims },
      western_narrative: { ... },
      non_aligned_narrative: { ... },
      welding_points: [ { type, severity, description, evidence } ],
      timeline: [ { date, event, source, pole } ]
    }
  }

Если API не отвечает — fallback с текстом «Не удалось сверить нарративы».

───────────────────────────────────────
ЧАСТЫЕ ПРОБЛЕМЫ
───────────────────────────────────────
Западный нарратив пустой
  Это НЕ баг. В rsshub.json сейчас 429 российских vs 9 западных items.
  Западные источники (Guardian, NYT) могут не попасть в текущий снимок
  по этой теме. Решение: расширить фид западными источниками.

Ничего не находится по теме
  Возможно, темы нет в свежем снимке rsshub.json.
  Проверь: curl -s "http://localhost:3117/api/layers/narrative-splitter?topic=..." | head -40
  Если topic_matches: 0 — темы нет в данных.

Страница не грузится (404)
  Проверь, что маршрут зарегистрирован:
  grep -c "narrative-arena" server/routes-pages.json → должно быть >0
  Перезапусти сервер: pkill -f "node server.mjs" && node server.mjs

Данные в колонках не обновляются
  Ctrl+Shift+R (hard reload) в браузере — кэш.
