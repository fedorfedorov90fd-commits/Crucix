ОПИСАНИЕ:
Централизованный мониторинг состояния всех сборщиков данных Crucix.

ФУНКЦИОНАЛ:

- Список всех сборщиков с их статусами
- Количество записей в корзине для каждого сборщика
- Возраст данных (время с последнего обновления)
- Размер данных в корзине
- Ошибки в логах
- Последний запуск сборщика
- Просмотр логов сборщиков по клику
