# Круговая диаграмма: pie.js

## Простое объяснение (для новичков)

Этот файл — «круговая диаграмма» на дашборде. Он показывает, как статьи распределены по группам источников: сколько процентов от всех новостей приходится на российские, сколько на западные, сколько на нейтральные.

**Что он делает:**

1. **Запрашивает данные** у API `/api/layers/articles/stats`.
2. **Строит круговую диаграмму** — сектора разных цветов.
3. **Подписывает сектора** — название группы и процент.
4. **Добавляет легенду** — чтобы было понятно, какой цвет какой группе соответствует.

**Как читать диаграмму:**

- Большой синий сектор — большинство новостей от российских источников.
- Маленький красный сектор — мало новостей от западных.
- Зелёный сектор — нейтральные источники.

**Зачем это нужно:**

Вы сразу видите баланс сил в информационном поле. Если 80% новостей — от одной группы, а 20% — от другой, это уже сигнал: одна сторона доминирует.

**Аналогия:**

Это как круговая диаграмма бюджета семьи. Сколько процентов уходит на еду, сколько на жильё, сколько на развлечения. Только вместо бюджета — новости, а вместо категорий — группы источников.

## Научная база (для специалистов)

Виджет реализует **круговую диаграмму** (pie chart) на SVG для визуализации распределения статей по группам источников.

**Архитектура:**

- **Технология:** Vanilla JS, SVG. Без D3.js — для простоты и портативности.
- **Данные:** `GET /api/layers/articles/stats` — агрегаты по группам.
- **Формат:** `{ by_group: { russian: 385, western: 115, neutral: 0 } }`.
- **Цвета:** `russian` — `#3b82f6` (синий), `western` — `#ef4444` (красный), `neutral` — `#10b981` (зелёный).
- **Геометрия:** круг радиусом `R = 100`, центр в `(cx, cy) = (150, 150)`. Каждый сектор — дуга от `startAngle` до `endAngle`.

**Формально:**

Для каждой группы `g` с количеством `count(g)`:

**angle(g) = (count(g) / total) · 2π**

Сектор рисуется как путь SVG:

M cx cy
L x1 y1
A R R 0 largeArc sweep x2 y2
Z
text


где `(x1, y1)` и `(x2, y2)` — точки на окружности, `largeArc` — флаг для больших дуг (> 180°), `sweep` — направление.

**Подписи:**

- Название группы — в центре сектора.
- Процент — рядом.

**Легенда:**

- Цветной квадрат + название группы + количество.

**Ограничения:**

- Круговая диаграмма плохо работает с большим количеством категорий (> 7). Для нашего случая (3 группы) — идеально.
- Не показывает динамику (только срез на момент запроса).
- Не показывает абсолютные значения на самом графике (только в легенде).

## Как работает (пошагово)

1. При загрузке страницы (`DOMContentLoaded`) вызывается `mountPie()`.
2. `mountPie()` находит контейнер по `id` (по умолчанию `'pie'`).
3. Отправляет `fetch('/api/layers/articles/stats')`.
4. Получает JSON, извлекает `stats.by_group`.
5. Если данных нет — показывает «Нет данных».
6. Вычисляет `total` — сумму всех групп.
7. Для каждой группы вычисляет `angle` — долю от 2π.
8. Создаёт SVG с `viewBox="0 0 300 300"`.
9. Рисует сектора: для каждой группы — путь SVG.
10. Добавляет подписи: название группы и процент.
11. Добавляет легенду: цветной квадрат + название + количество.

**Структура SVG:**

```html
<svg viewBox="0 0 300 300">
  <!-- Сектор russian -->
  <path d="M150,150 L150,50 A100,100 0 1,1 ... Z" fill="#3b82f6" />
  <!-- Сектор western -->
  <path d="M150,150 L..." fill="#ef4444" />
  <!-- Подписи -->
  <text x="..." y="...">russian 77%</text>
  <!-- Легенда -->
  <rect x="10" y="270" width="10" height="10" fill="#3b82f6" />
  <text x="25" y="279">russian: 385</text>
</svg>

Пример использования

В HTML-странице:
html

<div id="pie"></div>
<script type="module" src="/widgets/pie.js"></script>

В другом виджете (программно):
javascript

import { mountPie } from '/widgets/pie.js';

mountPie('my-pie-container');

Что появится на экране:

    Круговая диаграмма 300×300.

    Три сектора: синий (russian), красный (western), зелёный (neutral).

    Подписи: название группы и процент.

    Легенда: цветной квадрат + название + количество.

Пример данных от API:
json

{
  "stats": {
    "by_group": {
      "russian": 385,
      "western": 115,
      "neutral": 0
    },
    "count": 500
  }
}

Практические рекомендации

    Цвета групп — russian (синий), western (красный), neutral (зелёный). Интуитивно и совпадает с другими виджетами.

    viewBox="0 0 300 300" — компактный размер. Позволяет масштабировать SVG без потери качества.

    largeArc — флаг для дуг > 180°. Если сектор больше половины круга — largeArc = 1. Иначе 0.

    sweep — направление дуги. 1 — по часовой стрелке, 0 — против. Для круговой диаграммы — 1.

    Подписи в секторах — только если сектор достаточно большой. Для маленьких секторов (< 5%) — подпись может не влезть. В этом случае — только в легенде.

    Легенда — обязательна. Без неё непонятно, какой цвет какой группе соответствует.

    total = 0 — если данных нет, показывается «Нет данных». Не делите на ноль.

    Fallback на ошибки — если API недоступен, показывается сообщение. Страница не падает.

    Тёмная тема — background: #0d0d1a. Стандарт для профессиональных терминалов.

    Не используйте для динамики — круговая диаграмма показывает только срез. Для динамики — линейный график (real-chart.js).

    Не используйте для > 7 категорий — сектора становятся нечитаемыми. Для нашего случая (3 группы) — идеально.
