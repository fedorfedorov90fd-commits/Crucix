# Profile Module

## 📋 Описание
**Русский:**
Модуль **Profile** управляет пользовательским профилем: настройки, предпочтения, сохранённые отчёты, история запросов. Позволяет настраивать интерфейс, уведомления и параметры отображения данных.

**English:**
The **Profile** module manages user profiles: settings, preferences, saved reports, request history. Allows customizing interface, notifications and data display parameters.

## 🎯 Назначение
- Управление настройками
- Сохранение предпочтений
- История активности

## 🚀 Использование
1. Страница: `/profile`
2. API: `/api/profile`
3. Параметры: `?section=preferences`
