# Карта RSS-новостей: rss-map.js

## Простое объяснение (для новичков)

Этот файл — «географическая карта» новостей. Он показывает, где в мире происходят события, о которых пишут СМИ. Каждая точка на карте — это новость, привязанная к координатам.

**Что он делает:**

1. **Запрашивает данные** у API `/api/layers/articles?limit=500`.
2. **Создаёт карту** через библиотеку Leaflet (OpenStreetMap).
3. **Рисует маркеры** — для каждой статьи с координатами (`latitude`, `longitude`).
4. **Раскрашивает маркеры** по группе источника: синий — `russian`, красный — `western`, зелёный — `neutral`.
5. **Добавляет подсказки** — при клике на маркер открывается карточка с заголовком, датой и источником.

**Как читать карту:**

- Кластер точек в одном регионе — там происходит много событий.
- Красные точки — западные источники пишут об этом регионе.
- Синие точки — российские источники.
- Зелёные — нейтральные.

**Зачем это нужно:**

Вы сразу видите географию информационного поля: где события происходят, а где — молчат. Это визуальное дополнение к таблицам и графикам.

**Аналогия:**

Это как карта пробок. Красные точки — заторы (события), зелёные — свободно (нет событий). Только вместо дорог — мир, а вместо машин — новости.

## Научная база (для специалистов)

Виджет реализует **геопространственную визуализацию** на Leaflet — открытой библиотеке интерактивных карт.

**Архитектура:**

- **Библиотека:** Leaflet 1.9.4 (CDN: `unpkg.com/leaflet@1.9.4`).
- **Тайлы:** OpenStreetMap (`https://{s}.tile.openstreetmap.org/{z}/{x}/{y}.png`). Бесплатно, без ключа.
- **Маркеры:** `L.marker` с кастомными иконками (цветные булавки).
- **Попапы:** `bindPopup` с заголовком, датой и источником. `autoClose: false` — аналитик может держать несколько попапов открытыми.
- **Кластеризация:** не используется. При 500+ маркерах карта может тормозить. Для больших объёмов — `Leaflet.markercluster`.

**Формально:**

Для каждой статьи с координатами `(lat, lng)`:

1. Создаётся маркер: `L.marker([lat, lng])`.
2. Привязывается попап: `bindPopup(...)`.
3. Устанавливается иконка: `L.icon({ iconUrl: ... })`.
4. Добавляется на карту: `marker.addTo(map)`.

**Цветовая кодировка:**

- `russian` — синяя иконка (`marker-icon-blue.png`).
- `western` — красная (`marker-icon-red.png`).
- `neutral` — зелёная (`marker-icon-green.png`).

Иконки берутся с GitHub (`pointhi/leaflet-color-markers`). Это стандартный набор для Leaflet.

**Центр карты:**

`[55.7558, 37.6173]` — Москва. Стандарт для российских систем. Можно изменить на любую точку.

**Ограничения:**

- Не все статьи имеют координаты. Если у статьи нет `latitude`/`longitude` — маркер не создаётся.
- При 500+ маркерах карта тормозит. Для больших объёмов — кластеризация.
- OpenStreetMap может быть медленным. Для продакшена — свой тайл-сервер.

## Как работает (пошагово)

1. При загрузке страницы (`DOMContentLoaded`) вызывается `mountRssMap()`.
2. `mountRssMap()` находит контейнер по `id` (по умолчанию `'rss-map'`).
3. Создаёт карту: `L.map(containerId).setView([55.7558, 37.6173], 2)`.
4. Добавляет тайлы OpenStreetMap.
5. Отправляет `fetch('/api/layers/articles?limit=500')`.
6. Получает JSON, извлекает `data.items`.
7. Для каждой статьи с координатами:
   - Создаёт маркер.
   - Привязывает попап.
   - Устанавливает иконку по группе.
   - Добавляет на карту.
8. При клике на маркер — открывается попап.

<div id="rss-map" style="height: 500px;"></div>
<script type="module" src="/widgets/rss-map.js"></script>

Практические рекомендации

    Центр карты — [55.7558, 37.6173] (Москва). Измените на любую точку. Для мирового обзора — [20, 0], zoom 2.

    Zoom 2 — мировой обзор. Для детального — увеличьте.

    autoClose: false — аналитик может держать несколько попапов открытыми. Это важно для сравнения.

    Цветовые иконки — стандартный набор pointhi/leaflet-color-markers. Не изобретайте свои: они уже проверены.

    OpenStreetMap — бесплатно, но может быть медленным. Для продакшена — свой тайл-сервер (например, Mapbox).

    Кластеризация — при 500+ маркерах карта тормозит. Используйте Leaflet.markercluster.

    Не все статьи имеют координаты. Если у статьи нет latitude/longitude — маркер не создаётся. Это нормально.

    map.eachLayer — очистка старых маркеров перед перерисовкой. Без этого маркеры накапливаются.

    height: 500px — фиксированная высота контейнера. Без неё карта не отобразится.

    Fallback на ошибки — если API недоступен, показывается сообщение. Страница не падает.

    Тёмная тема — Leaflet по умолчанию светлый. Для тёмной темы — свой CSS или тайлы (например, CartoDB Dark Matter).

    L.tileLayer — стандартный слой. Не используйте L.imageOverlay без необходимости.
