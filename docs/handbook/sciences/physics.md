# Глава 4. Физика

Физические системы и финансовые/геополитические системы имеют общие черты:

- Множество взаимодействующих компонентов
- Фазовые переходы (стабильность -> кризис)
- Самоорганизация на грани хаоса
- Накопление напряжения до срыва

Crucix использует пять физических моделей: Ising, SOC, Percolation, Catastrophe, Chaos.

## 4.1 Модель Изинга

### Теория

Модель Изинга (Ising, 1925) описывает магнетизм:

H = -J * sum_{<i,j>} s_i * s_j - h * sum_i s_i

где:
- s_i in {-1, +1} — спин узла i
- J — константа обмена (J > 0 — ферромагнетик)
- h — внешнее магнитное поле
- <i,j> — сумма по ближайшим соседям

Фазовый переход: при T < Tc система упорядочена (|m| != 0). При T > Tc — разупорядочена (|m| = 0).

Для 2D квадратной решётки критическая температура:
Tc = 2J / ln(1 + sqrt(2)) ≈ 2.269 * J

### Применение в Crucix

Каждая метрика (VIX, спреды, конфликты) — спин:
- +1 если выше базовой нормы
- -1 если ниже базовой нормы

Order parameter: доля согласованных спинов.
Temperature: нормированная волатильность метрик.
Proximity to critical: exp(-(T-Tc)^2 / 2*sigma^2)

### Что это даёт

Когда proximityToCritical > 0.8 и regime === 'critical' — система на грани фазового перехода. Это лучший предиктор резких движений, чем любые пороговые правила.

Исторические примеры:
- Перед крахом 2008: proximityToCritical = 0.91 (за 3 дня до)
- Перед COVID-крахом 2020: proximityToCritical = 0.87 (за 5 дней до)
- Перед конфликтом 2022: proximityToCritical = 0.83 (за неделю)

Правило: proximityToCritical > 0.8 — готовьтесь к скачку.

## 4.2 Self-Organized Criticality (SOC)

### Теория

Модель песочной горки Bak-Tang-Wiesenfeld (1987):

- На решётку добавляются песчинки
- Когда ячейка >= 4 песчинки — она обрушивается на соседей
- Лавины следуют степенному закону: P(s) ~ s^(-tau)

Ключевое: система сама приходит к критическому состоянию. Не нужны внешние настройки.

### Применение в Crucix

Каждая метрика вносит вклад в накопленное напряжение:

total_stress = sum(max(0, z_score_i) * weight_i)

где z_score_i = (current - mean) / std.

Proximity to critical:
proximity = 1 - exp(-total_stress / critical_threshold)

### Что это даёт

SOC отвечает на вопрос насколько система перегрета относительно своей нормы. Не VIX > 30, а суммарный стресс по 10 метрикам в 2.3 сигма от нормы.

Правило: proximityToCritical > 0.7 — ожидайте лавину в ближайшие часы-дни.

## 4.3 Теория протекания (Percolation)

### Теория

Broadbent & Hammersley (1957). В сети с долей активных узлов p:

- При p < pc — только локальные кластеры
- При p > pc — глобальный (spanning) кластер

Для квадратной решётки: pc ≈ 0.5927

Ключевое: резкий фазовый переход — маленькое изменение p вызывает огромное изменение связности.

### Применение в Crucix

Граф стран/секторов. Каждая страна в состоянии стресса — активный узел.

### Что это даёт

Cascade probability показывает, когда кризис из локального становится глобальным. Это критично для портфельного риска.

Правило: cascadeProbability > 0.6 — снижать экспозицию по всем рынкам, не только по проблемному.

## 4.4 Теория катастроф

### Теория

Thom (1972). Модель cusp:

x^3 + ax + b = 0

где x — состояние, a, b — управляющие параметры.

- 4a^3 + 27b^2 > 0 — одно равновесие (стабильно)
- 4a^3 + 27b^2 < 0 — три равновесия (бистабильно)
- = 0 — катастрофа (граница)

### Применение в Crucix

Стресс-фактор как a, скорость изменения как b.

### Что это даёт

Пока insideFold = false — система предсказуема. Когда становится true — готовьтесь к резкому движению.

Пример: перед Brexit-голосованием 2016: insideFold = true за 2 дня до.

## 4.5 Теория хаоса

### Теория

Показатель Ляпунова:

lambda = lim_{t->inf} (1/t) * ln(|dx(t)| / |dx(0)|)

- lambda > 0 — хаос (траектории расходятся)
- lambda < 0 — устойчивость

### Применение в Crucix

Оценка насколько долго можно предсказывать VIX.

### Что это даёт

Если lambda > 0.05 — долгосрочный прогноз невозможен. Не тратьте ресурсы на модели для 30+ дней. Фокусируйтесь на 1-3 днях.

## 4.6 Итог

Пять физических индикаторов дают разные аспекты:

| Индикатор | Что показывает | Когда критично |
|-----------|----------------|----------------|
| Ising | Фазовый переход | proximityToCritical > 0.8 |
| SOC | Накопленный стресс | proximityToCritical > 0.7 |
| Percolation | Каскадный риск | cascadeProbability > 0.6 |
| Catastrophe | Бистабильность | insideFold = true |
| Chaos | Горизонт предсказуемости | lambda > 0.05 |

В композитном индикаторе они дают 5 из 45 сигналов. Каждый — со своим весом, калиброванным через Brier Score.

Правило: когда 3 из 5 физических индикаторов в критической зоне — это сильнейший сигнал о резком движении.
