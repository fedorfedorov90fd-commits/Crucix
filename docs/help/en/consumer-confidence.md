# Consumer Confidence Module

## 📋 Description
**English:**
The **Consumer Confidence** module provides comprehensive data monitoring, analysis and reporting capabilities within the Crucix ecosystem.

## 🎯 Purpose
- Real-time data monitoring and analysis
- Integration with external data sources
- Automated reporting and visualization
- Risk assessment and early warning
- Multi-source data aggregation

## 🚀 How to Use
1. Access the module via: `/consumer-confidence`
2. Use REST API: `/api/consumer-confidence`
3. Configure via: `/config/consumer-confidence.json`
4. Monitor status: `/api/consumer-confidence/status`
