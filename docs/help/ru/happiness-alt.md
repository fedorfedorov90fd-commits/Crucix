# Happiness Index Alternative Module

## 📋 Описание
**Русский:**
Модуль **Happiness Index Alternative** предоставляет альтернативные версии индекса счастья: с коррекцией на неравенство, экологический след, уровень преступности, цифровизацию. Используется для более комплексной оценки благополучия.

**English:**
The **Happiness Index Alternative** module provides alternative versions of the happiness index: adjusted for inequality, ecological footprint, crime rate, digitalization. Used for more comprehensive well-being assessment.

## 🎯 Назначение
- Альтернативные расчёты счастья
- Комплексная оценка благополучия
- Социальный анализ

## 🚀 Использование
1. Страница: `/happiness-alt`
2. API: `/api/happiness-alt`
3. Параметры: `?adjustment=inequality&country=US`
