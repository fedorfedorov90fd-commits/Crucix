# WHO — Всемирная организация здравоохранения

## Что это

WHO (World Health Organization) — специализированное учреждение ООН по здравоохранению. Предоставляет данные о: вспышках инфекционных заболеваний (эпидемии, пандемии), вакцинации, смертности, системах здравоохранения, питании, санитарных условиях.

## Как пользоваться

1. Запустите сборщик: `node scripts/collectors/collect-who.mjs`
2. Сборщик парсит WHO API и веб-страницы
3. Данные сохраняются в `/basket/health/who/`
4. Используйте `http://localhost:3117/api/who?disease=COVID-19&country=RU`

## Профессиональное использование

- **Министерства здравоохранения** координируют ответы
- **Фармацевтические компании** планируют производство
- **Страховые компании** оценивают риски
- **Исследователи** отслеживают новые инфекции

## ❓ Часто задаваемые вопросы

**Вопрос:** Бесплатно ли?
**Ответ:** Да, данные WHO открыты и бесплатны.

**Вопрос:** Какие данные доступны?
**Ответ:** Случаи заболеваний, смерти, вакцинация, системы здравоохранения.

**Вопрос:** Как часто обновляются данные?
**Ответ:** Ежедневно для COVID-19, ежемесячно для остальных.

## 🎯 Интерактивный туториал

**Шаг 1:** Запустите сборщик

```
node scripts/collectors/collect-who.mjs
```

**Шаг 2:** Получите данные по COVID-19 в России

```
curl "http://localhost:3117/api/who?disease=COVID-19&country=RU"
```

