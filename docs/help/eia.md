# eia

## 📋 О МОДУЛЕ / ABOUT

**Русский:**
Мониторинг цен на энергоносители через EIA (Energy Information Administration).

**English:**
Energy price monitoring via EIA (Energy Information Administration).

## 🚀 КАК ИСПОЛЬЗОВАТЬ / HOW TO USE

**Русский:**
1. Модуль доступен через API: `/api/eia/`
