# Lenses Module

## 📋 Description
**English:**
The **Lenses** module provides comprehensive data monitoring, analysis and reporting capabilities within the Crucix ecosystem.

## 🎯 Purpose
- Real-time data monitoring and analysis
- Integration with external data sources
- Automated reporting and visualization
- Risk assessment and early warning
- Multi-source data aggregation

## 🚀 How to Use
1. Access the module via: `/lenses`
2. Use REST API: `/api/lenses`
3. Configure via: `/config/lenses.json`
4. Monitor status: `/api/lenses/status`
