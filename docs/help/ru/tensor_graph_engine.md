# Тензорный анализ и гиперграфы: tensor_graph_engine.py

## Простое объяснение (для новичков)

Этот файл — «сканер скрытых структур». Обычный граф видит только пары: «источник А связан с темой Б». Гиперграф видит группы: «источник А, тема Б и локация В образуют единый треугольник, который рассыпается, если убрать любой угол».

**Что он делает:**

1. **Строит гиперграф** — узлы (источники, темы, локации, время) и гиперрёбра (группы из нескольких узлов).
2. **Обучает нейросеть** (Graph Neural Network) на этом гиперграфе — ищет паттерны координации.
3. **Классифицирует** — каждый гиперграф получает вероятность: «норма» или «скоординированная структура».
4. **Находит ядра** — плотные кластеры без внешних связей. Кандидаты в «штабы» информационных операций.

**Зачем это нужно:**

Обычный анализ видит только парные связи. Но реальная координация часто выглядит как треугольник: «источник А», «тема Б» и «локация В» появляются вместе. По отдельности — ничего особенного. Вместе — паттерн. Гиперграф ловит такие паттерны.

**Аналогия:**

Представьте, что вы ищете сообщников. Обычный граф видит: «А знаком с Б», «Б знаком с В». Гиперграф видит: «А, Б и В собираются в одном кафе каждый вторник». Это уже не просто знакомства — это группа.

## Научная база (для специалистов)

Модуль реализует **гиперграфовую нейронную сеть** (Hypergraph Neural Network) для обнаружения скрытых структур координации.

**Гиперграфы:**

В обычном графе ребро соединяет два узла: `(u, v)`. В гиперграфе гиперребро соединяет произвольное число узлов: `(u_1, u_2, ..., u_k)`. Это позволяет моделировать связи, которые имеют смысл только в группе.

**Формально:**

Гиперграф `H = (V, E)`, где:
- `V` — множество узлов.
- `E` — множество гиперрёбер, каждое `e ⊆ V`.

Матрица инцидентности `H` размера `|V| × |E|`: `H[v][e] = 1`, если `v ∈ e`, иначе `0`.

**HypergraphConv (PyTorch Geometric):**

Обобщение графовых свёрток на гиперрёбра. Формула:

**X' = D_v^(-1/2) · H · W · D_e^(-1) · H^T · D_v^(-1/2) · X · Θ**

где:
- `X` — матрица признаков узлов.
- `H` — матрица инцидентности.
- `D_v`, `D_e` — диагональные матрицы степеней узлов и гиперрёбер.
- `W` — веса гиперрёбер.
- `Θ` — обучаемые параметры.

**Архитектура:**

1. `conv1` — первый слой `HypergraphConv`. Извлекает локальные паттерны.
2. `ReLU` — активация.
3. `conv2` — второй слой. Извлекает глобальные паттерны.
4. `log_softmax` — классификация (`норма` / `скоординированная структура`).

**Почему гиперграфы, а не обычные графы:**

Обычный граф теряет информацию о группах. Если «А, Б, В» появляются вместе, граф покажет три ребра: `(А, Б)`, `(Б, В)`, `(А, В)`. Но это не то же самое, что «А, Б, В вместе». Гиперграф сохраняет эту информацию.

**Ограничения:**

- Гиперрёбра нужно строить осмысленно. Например, «источник × тема × регион × сутки». Иначе модель найдёт случайные совпадения.
- Обучение требует размеченных примеров. При их отсутствии — используйте как unsupervised-поиск аномалий.
- `num_classes = 2` — упрощение. Для тонкой классификации добавьте классы.
- GPU ускоряет обучение, но инференс можно делать на CPU для небольших графов.

## Как работает (пошагово)

1. Строится `hyperedge_index` — список групп узлов (гиперрёбер).
2. Матрица признаков `features` (автор, тональность, охват) и связи подаются в `HypergraphConv`.
3. `conv1` извлекает локальные паттерны.
4. `conv2` извлекает глобальные паттерны.
5. `log_softmax` классифицирует гиперграф как «норму» или «аномалию».
6. `detect_core_groups` ищет плотные кластеры без внешних связей — кандидаты в «ядра».
7. Тензоры обрабатываются на GPU при наличии.

**Формат ответа:**

```python
{
    'probabilities': [0.85, 0.15],  # [норма, аномалия]
    'predicted_class': 'normal',
    'confidence': 0.85
}

Формат ядра:
python

{
    'nodes': ['ТАСС', 'энергетика', 'Москва'],
    'density': 0.92,
    'is_core': True
}

Пример использования
python

from services.tensor_graph_engine import HypergraphOSINT, detect_core_groups
import torch

# Признаки узлов: [автор, тональность, охват]
features = torch.tensor([[1, 0.5, 100], [2, -0.3, 50], [3, 0.0, 75]], dtype=torch.float)

# Гиперрёбра: группы узлов
# [0, 1] — узлы 0 и 1 в одном гиперребре
# [1, 2] — узлы 1 и 2 в одном гиперребре
hyperedge_index = torch.tensor([[0, 1, 1, 2], [0, 0, 1, 1]], dtype=torch.long)

# Классификация
model = HypergraphOSINT(num_features=3, num_classes=2)
probs = model(features, hyperedge_index)
print(probs)  # [[0.85, 0.15], [0.72, 0.28], [0.90, 0.10]]

# Поиск ядер
cores = detect_core_groups(probs, threshold=0.8)
print(cores)  # [{ nodes: [...], density: 0.92, is_core: True }]

Практические рекомендации

    Гиперрёбра нужно строить осмысленно. Например, «источник × тема × регион × сутки». Иначе модель найдёт случайные совпадения.

    Обучение требует размеченных примеров. При их отсутствии — используйте как unsupervised-поиск аномалий.

    num_classes = 2 — упрощение. Для тонкой классификации добавьте классы: «естественный всплеск», «скоординированная кампания», «шум».

    GPU ускоряет обучение, но инференс можно делать на CPU для небольших графов.

    Интерпретируйте результаты вместе с контекстом. Гиперграф указывает на структуру, а не на мотив.

    Не используйте для простых задач. Если достаточно парных связей — обычный граф проще и быстрее.

    detect_core_groups — ищет плотные кластеры без внешних связей. Это кандидаты в «штабы» информационных операций.

    Для больших гиперграфов — используйте torch_geometric.loader для батчей. Иначе не хватит памяти.

    log_softmax — для многоклассовой классификации. Для бинарной можно sigmoid.

    ReLU — стандартная активация. Не заменяйте на tanh без необходимости.

    PyTorch Geometric — стандарт для графовых сетей. pip install torch-geometric.

    Комбинируйте с tqft_invariants.py. Гиперграфы дают «кто с кем», TQFT — «кто с кем квантово спутан». Вместе — полная картина.
