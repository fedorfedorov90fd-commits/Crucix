# Scan Module

## 📋 Описание
**Русский:**
Модуль **Scan** предоставляет инструменты для сканирования сетей, портов, систем на наличие уязвимостей. Используется для оценки кибербезопасности и обнаружения угроз в инфраструктуре.

**English:**
The **Scan** module provides tools for scanning networks, ports, systems for vulnerabilities. Used for cybersecurity assessment and threat detection in infrastructure.

## 🎯 Назначение
- Сканирование уязвимостей
- Оценка кибербезопасности
- Обнаружение угроз

## 🚀 Использование
1. Страница: `/scan`
2. API: `/api/scan`
3. Параметры: `?target=192.168.1.1&ports=1-1024`
