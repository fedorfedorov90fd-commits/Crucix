# Yield Curve Module

## 📋 Description
**English:**
The **Yield Curve** module provides comprehensive data monitoring, analysis and reporting capabilities within the Crucix ecosystem.

## 🎯 Purpose
- Real-time data monitoring and analysis
- Integration with external data sources
- Automated reporting and visualization
- Risk assessment and early warning
- Multi-source data aggregation

## 🚀 How to Use
1. Access the module via: `/yield-curve`
2. Use REST API: `/api/yield-curve`
3. Configure via: `/config/yield-curve.json`
4. Monitor status: `/api/yield-curve/status`
