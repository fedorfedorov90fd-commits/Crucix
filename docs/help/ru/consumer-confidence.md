# Consumer Confidence Module

## 📋 Описание
**Русский:**
Модуль **Consumer Confidence** отслеживает индексы потребительского доверия (CCI) по странам. Показывает оптимизм/пессимизм потребителей относительно экономики, занятости и личных финансов. Данные от The Conference Board, University of Michigan и других.

**English:**
The **Consumer Confidence** module tracks Consumer Confidence Index (CCI) by country. Shows consumer optimism/pessimism regarding economy, employment and personal finances. Data from The Conference Board, University of Michigan and others.

## 🎯 Назначение
- Анализ потребительских настроений
- Прогнозирование экономической активности
- Оценка розничных продаж

## 🚀 Использование
1. Страница: `/consumer-confidence`
2. API: `/api/consumer-confidence`
3. Параметры: `?country=US&period=12m`
