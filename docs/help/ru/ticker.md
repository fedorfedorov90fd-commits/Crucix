# Бегущая строка: ticker.js

## Простое объяснение (для новичков)

Этот файл — «бегущая строка» на дашборде. Он показывает критические алерты в виде горизонтальной ленты, которая прокручивается. Как в выпусках новостей: внизу экрана бежит строка «СРОЧНО: ...».

**Что он делает:**

1. **Запрашивает данные** у API `/api/layers/alerts?severity=high`.
2. **Строит бегущую строку** — горизонтальную ленту с сообщениями.
3. **Раскрашивает сообщения** по уровню серьёзности: красный — `critical`, оранжевый — `high`, жёлтый — `medium`.
4. **Анимирует** — строка прокручивается справа налево.
5. **Останавливается при наведении** — можно прочитать сообщение.

**Как читать:**

- Красное сообщение — критический алерт. Что-то важное произошло.
- Оранжевое — высокий уровень. Стоит обратить внимание.
- Жёлтое — средний. Фон.

**Зачем это нужно:**

Вы открываете дашборд и сразу видите: что произошло, что важно, на что обратить внимание. Не нужно кликать по вкладкам — всё на виду.

**Аналогия:**

Это как лента новостей в аэропорту. Вы идёте по терминалу и краем глаза читаете: «Рейс SU123 задерживается», «Погода в Москве —10°». Не нужно останавливаться — информация сама «бежит» к вам.

## Научная база (для специалистов)

Виджет реализует **ticker / marquee** — горизонтальную прокручиваемую ленту для отображения критических событий.

**Архитектура:**

- **Технология:** Vanilla JS, CSS-анимация (`@keyframes`, `transform: translateX`).
- **Данные:** `GET /api/layers/alerts?severity=high` — критические алерты.
- **Формат:** `{ alerts: [{ alert_type, severity, title, message }] }`.
- **Цвета:** `critical` — `#ef4444` (красный), `high` — `#f59e0b` (оранжевый), `medium` — `#fbbf24` (жёлтый).
- **Анимация:** CSS `@keyframes ticker { from { transform: translateX(100%); } to { transform: translateX(-100%); } }`. Длительность зависит от длины текста: `duration = total_width / speed`.

**Формально:**

1. **Сборка контента:** для каждого алерта создаётся `<span class="ticker-item">`.
2. **Измерение ширины:** `total_width = sum(item_width_i)`.
3. **Скорость:** `speed = 100 px/s`.
4. **Длительность анимации:** `duration = total_width / speed`.
5. **Запуск:** `element.style.animation = 'ticker ${duration}s linear infinite'`.

**Почему CSS-анимация, а не JS:**

CSS-анимации выполняются на GPU, не блокируют главный поток. Это важно для дашборда, где много виджетов.

**Почему `pause on hover`:**

Пользователь должен иметь возможность прочитать сообщение. Если строка бежит слишком быстро — он не успевает. Пауза при наведении решает проблему.

**Ограничения:**

- Длинные сообщения могут занимать много места. Ограничьте длину `title` до 80 символов.
- При большом количестве алертов (> 20) строка становится очень длинной. Ограничьте количество.
- Анимация может тормозить на слабых устройствах. Отключите её для мобильных.

## Как работает (пошагово)

1. При загрузке страницы (`DOMContentLoaded`) вызывается `mountTicker()`.
2. `mountTicker()` находит контейнер по `id` (по умолчанию `'ticker'`).
3. Отправляет `fetch('/api/layers/alerts?severity=high')`.
4. Получает JSON, извлекает `data.alerts`.
5. Если массив пуст — показывает «Нет активных алертов».
6. Если не пуст — для каждого алерта создаёт `<span class="ticker-item">`:
   - Цвет по `severity`.
   - Текст: `title` + `message` (сокращённый до 80 символов).
   - Разделитель `•` между сообщениями.
7. Собирает все `<span>` в один контейнер.
8. Вычисляет `total_width` — общую ширину контента.
9. Вычисляет `duration = total_width / speed`.
10. Запускает CSS-анимацию.
11. Добавляет обработчик `mouseenter` — пауза, `mouseleave` — продолжение.

**Структура HTML:**

```html
<div id="ticker">
  <div class="ticker-content">
    <span class="ticker-item critical">🚨 КРИТ: Тема ЭНЕРГЕТИКА замолчала</span>
    <span class="ticker-sep">•</span>
    <span class="ticker-item high">⚡ ВЫСОКИЙ: 5 источников синхронно</span>
  </div>
</div>

CSS:
css

#ticker {
  overflow: hidden;
  background: #0a0a1a;
  border: 1px solid rgba(255,255,255,0.05);
  border-radius: 8px;
  padding: 10px 0;
}

.ticker-content {
  display: inline-block;
  white-space: nowrap;
  animation: ticker 60s linear infinite;
}

@keyframes ticker {
  from { transform: translateX(100%); }
  to { transform: translateX(-100%); }
}

.ticker-item.critical { color: #ef4444; font-weight: 600; }
.ticker-item.high { color: #f59e0b; }
.ticker-item.medium { color: #fbbf24; }

Практические рекомендации

    Цвета серьёзности — critical (красный), high (оранжевый), medium (жёлтый). Интуитивно и совпадает с другими виджетами.

    pause on hover — обязателен. Пользователь должен иметь возможность прочитать сообщение.

    Ограничение длины сообщения — 80 символов. Длинные сообщения занимают много места и замедляют анимацию.

    Ограничение количества алертов — 10–20. При большем строка становится очень длинной.

    CSS-анимация, а не JS — выполняется на GPU, не блокирует главный поток.

    linear infinite — линейная бесконечная анимация. Не используйте ease-in-out: это замедляет строку.

    Скорость 100 px/s — оптимально для читаемости. Медленнее — скучно, быстрее — не успеваешь прочитать.

    overflow: hidden — скрывает лишний контент. Без этого строка будет вылезать за пределы контейнера.

    white-space: nowrap — не позволяет тексту переноситься на новую строку. Всё в одну линию.

    Fallback на ошибки — если API недоступен, показывается «Нет активных алертов». Страница не падает.

    Тёмная тема — background: #0a0a1a. Стандарт для профессиональных терминалов.

    border-radius: 8px — скруглённые углы. Мягче, чем острые.

    Не используйте для обычных сообщений. Только для критических. Если всё критическое — ничего не критическое.

    Пустой массив — показывайте «Нет активных алертов». Не оставляйте пустой блок без сообщения.

    Для мобильных — отключите анимацию (@media (prefers-reduced-motion)). Батарея важнее.
