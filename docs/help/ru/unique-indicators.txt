ОПИСАНИЕ
--------------------------------------------------------------------------------
Слой «Уникальные косвенные индикаторы» отслеживает неочевидные сигналы
активности в стратегически важных точках США. Исторически всплески заказов
пиццы и такси в районах правительственных объектов коррелируют с кризисными
событиями — подготовкой операций, экстренными совещаниями, ночной работой
штабов.

Два индикатора:

  1. «Пицца Пентагона» (pentagon-pizza)
     Рост заказов пиццы в радиусе 5 км от Пентагона.
     Локация: 38.8719, -77.0563 (Арлингтон, Вирджиния)
     Пороги: норма < 50, предупреждение 50-100, критический > 100
     Источники: Google Maps / Yelp

  2. «Такси в Лэнгли» (langley-taxis)
     Рост заказов такси в радиусе 5 км от штаб-квартиры ЦРУ.
     Локация: 38.9519, -77.1467 (Лэнгли, Вирджиния)
     Пороги: норма < 20, предупреждение 20-50, критический > 50
     Источники: Uber / Lyft / Google Maps

МЕТОДОЛОГИЯ
--------------------------------------------------------------------------------
Индикаторы собираются сборщиком collect-unique-indicators.mjs и сохраняются
в basket-файлы:
  - data/basket/pentagon-pizza.json  (legacy-массив 31 точка)
  - data/basket/langley-taxis.json   (legacy-массив 31 точка)

Каждая точка: { date, value, trend }

API-модуль читает basket через basket-loader v2.0.0 и отдаёт клиенту
нормализованные данные с расчётом режима (regime) по порогам.

ЭНДПОИНТ
--------------------------------------------------------------------------------
GET /api/layers/unique-indicators

ОСНОВНЫЕ ПОДПУТИ
--------------------------------------------------------------------------------
  /                       — сводка (FeatureCollection + series + stats)
  /health                 — состояние (basket_source, points, mtime)
  /status                 — статус по каждому индикатору
  /config                 — конфигурация (пороги, локации, мета)
  /indicators             — оба индикатора с описанием
  /indicator/:id          — конкретный индикатор
  /pentagon-pizza         — только Пицца Пентагона
  /langley-taxis          — только Такси в Лэнгли
  /stats                  — статистика по обоим
  /latest                 — последние значения
  /series                 — временной ряд
  /top /bottom            — топы по значению
  /regimes                — распределение по режимам
  /current-regime         — текущий режим каждого
  /normal /warning /critical — фильтр по режиму
  /trends                 — тренды (7/14 дней)
  /timeline               — временная шкала
  /anomalies              — аномалии (z-score > 2)
  /signals                — сигналы (критическая активность, быстрый рост)
  /compare                — сравнение индикаторов
  /search                 — поиск по точкам
  /export                 — текстовый отчёт
  /featurecollection      — GeoJSON-заглушка (без координат)
  /render                 — конфигурация рендера
  /builtin                — встроенный fallback (15+15 точек)
  /reset-cache            — сброс кэша

ПАРАМЕТРЫ
--------------------------------------------------------------------------------
  ?indicator=             — pentagon-pizza | langley-taxis
  ?regime=                — normal | warning | critical
  ?since=                 — дата с (YYYY-MM-DD)
  ?until=                 — дата по (YYYY-MM-DD)
  ?min_value=             — минимум значения
  ?max_value=             — максимум значения
  ?limit=                 — последние N точек
  ?top=                   — первые N точек
  ?sort=                  — date-asc | date-desc | value-desc | value-asc | severity
  ?format=                — json | csv | series | stats | raw | report

ФОРМАТЫ ОТВЕТА
--------------------------------------------------------------------------------
  json (по умолчанию)     — FeatureCollection + series + stats + signals
  csv                     — плоская таблица (date, indicator, value, regime)
  series                  — только временной ряд
  stats                   — только статистика
  raw                     — сырые данные
  report                  — текстовый отчёт

ПОЛЯ ОТВЕТА
--------------------------------------------------------------------------------
  type                    — 'FeatureCollection'
  features                — GeoJSON-маркеры в Пентагоне и Лэнгли
  indicators              — мета + stats + current по каждому индикатору
  series                  — плоский массив {date, indicator, value, regime}
  stats                   — общая статистика
  signals                 — сигналы (critical-activity, rapid-rise)
  meta.fallback           — true, если использован BUILTIN_DATA
  meta.indicators_count   — количество индикаторов (2)
  meta.total_points       — общее число точек
  meta.generated_at       — время генерации

ЗАГОЛОВКИ
--------------------------------------------------------------------------------
  X-Module                — unique-indicators-api
  X-Module-Version        — 3.0.0
  X-Basket-Source         — basket-v1 | basket-legacy | fallback | corrupted | error
  X-Basket-Shape          — v1.series | v1.points | array | unknown
  Cache-Control           — public, max-age=300

СТРАНИЦА

  /unique-indicators      — визуализация (2 карточки индикаторов, шкалы порогов)
