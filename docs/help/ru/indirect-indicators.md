# Indirect Indicators Module

## 📋 Описание
**Русский:**
Модуль **Indirect Indicators** отслеживает косвенные индикаторы экономической и социальной активности: спутниковые ночные огни, мобильность населения, потребление энергии, транспортные потоки. Используется для верификации официальной статистики.

**English:**
The **Indirect Indicators** module tracks indirect indicators of economic and social activity: satellite night lights, population mobility, energy consumption, transport flows. Used for official statistics verification.

## 🎯 Назначение
- Верификация статистики
- Альтернативные индикаторы
- Мониторинг активности

## 🚀 Использование
1. Страница: `/indirect-indicators`
2. API: `/api/indirect-indicators`
3. Параметры: `?type=mobility&region=EU`
