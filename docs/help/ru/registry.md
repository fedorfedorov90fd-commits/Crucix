# Registry Module

## 📋 Описание
**Русский:**
Модуль **Registry** предоставляет единый реестр всех страниц, API-эндпоинтов и модулей Crucix. Показывает статус, доступность, версии и зависимости. Используется для навигации и управления системой.

**English:**
The **Registry** module provides a unified registry of all pages, API endpoints and Crucix modules. Shows status, availability, versions and dependencies. Used for navigation and system management.

## 🎯 Назначение
- Навигация по системе
- Мониторинг статуса
- Управление модулями

## 🚀 Использование
1. Страница: `/registry`
2. API: `/api/registry`
3. Параметры: `?type=pages&status=active`
