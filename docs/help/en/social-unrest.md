# Social Unrest Module

## 📋 Description
**English:**
The **Social Unrest** module provides comprehensive data monitoring, analysis and reporting capabilities within the Crucix ecosystem.

## 🎯 Purpose
- Real-time data monitoring and analysis
- Integration with external data sources
- Automated reporting and visualization
- Risk assessment and early warning
- Multi-source data aggregation

## 🚀 How to Use
1. Access the module via: `/social-unrest`
2. Use REST API: `/api/social-unrest`
3. Configure via: `/config/social-unrest.json`
4. Monitor status: `/api/social-unrest/status`
