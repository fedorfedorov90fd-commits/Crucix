# Air Quality Module

## 📋 Description
**English:**
The **Air Quality** module provides comprehensive data monitoring, analysis and reporting capabilities within the Crucix ecosystem.

## 🎯 Purpose
- Real-time data monitoring and analysis
- Integration with external data sources
- Automated reporting and visualization
- Risk assessment and early warning
- Multi-source data aggregation

## 🚀 How to Use
1. Access the module via: `/air-quality`
2. Use REST API: `/api/air-quality`
3. Configure via: `/config/air-quality.json`
4. Monitor status: `/api/air-quality/status`
