# Crucix Dashboard Module

## 📋 Описание
**Русский:**
Модуль **Crucix Dashboard** является главной страницей системы, агрегирующей ключевые индикаторы со всех модулей: геополитика, экономика, энергетика, безопасность. Предоставляет общий обзор состояния мира в реальном времени.

**English:**
The **Crucix Dashboard** module is the main page of the system, aggregating key indicators from all modules: geopolitics, economy, energy, security. Provides a real-time overview of the world state.

## 🎯 Назначение
- Главный обзор системы
- Агрегация ключевых индикаторов
- Быстрый доступ к модулям

## 🚀 Использование
1. Страница: `/crucix-dashboard`
2. API: `/api/crucix-dashboard`
3. Параметры: `?view=global&period=24h`
