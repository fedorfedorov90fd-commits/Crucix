=== ЖУРНАЛ РЕШЕНИЙ ===
Дата: 2026-08-09

1. Архитектура драйверов (base.mjs)
   - Все драйверы наследуют BaseDriver
   - Единый формат данных: { id, title, date, url, summary, source }

2. Использование Tor для Telegram
   - Telegram в России заблокирован
   - Драйвер использует SocksProxyAgent через Tor

3. AI-фильтр через Ollama
   - Локальная оценка новостей (0-10)
   - Поддержка тем (геополитика, роботоиндустрия, биотех, кибер)

4. Адаптивный шлюз (router.mjs)
   - Автоматический выбор драйвера
   - Ручное переопределение
   - Отказоустойчивость

5. Координатор проекта
   - coordinator.mjs — однопроходный анализ
   - interactive.mjs — диалоговый режим

6. RSS-система
   - Сбор из OPML-файла
   - Ежедневная ротация
   - Автоочистка (7 дней)

7. Git-инфраструктура
   - Локальный репозиторий
   - .gitignore для данных и логов
