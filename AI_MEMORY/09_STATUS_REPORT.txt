=== ПРОЕКТ CRUCIX — СТАТУС НА 2026-08-12 ===

=== ОБЩАЯ ЦЕЛЬ ===
Создать независимую, полностью бесплатную OSINT-платформу с открытым кодом, работающую на Debian. Модульная архитектура, локальный AI, прозрачная аналитика.

=== ТЕХНИЧЕСКАЯ СРЕДА ===
- Debian (AMD64) | Node.js 20.x | Ollama (deepseek-r1:7b / 1.5b) | Tor

=== ВЫПОЛНЕННЫЕ МОДУЛИ ===

1. RSS ИНТЕРФЕЙС (ГОТОВ 100%)
   - Панель управления RSS (/rss-dashboard)
   - Лента новостей с AI-оценками (/rss-feed)
   - Добавление/удаление RSS-лент через интерфейс
   - Импорт/экспорт OPML-файлов
   - Кнопка "Обновить все ленты"
   - Статистика по лентам (Всего/Доступные/Недоступные/Не проверено)
   - Региональные фильтры (11 кнопок)
   - Фильтры по странам (13 кнопок: Россия, Китай, Индия, Япония, Корея, Сев. Корея, Иран, Израиль, Турция, Украина, Великобритания, Германия, Франция)
   - Фильтр "ТОЛЬКО ВАЖНЫЕ" (оценка 7+)
   - Переключение языков (RU/EN/ZH/HI)
   - Реальные AI-оценки через Ollama
   - Клик по новости → открытие статьи
   - Счётчик новостей за сегодня
   - Настройка хранения новостей (1-730 дней)
   - Автоматическая очистка старых новостей

2. AI ЧАТ (ГОТОВ 100%)
   - Графический интерфейс (/ai-chat)
   - Поддержка моделей DeepSeek 1.5B и 7B
   - База знаний о проекте
   - Быстрые вопросы (5 кнопок)
   - Ярлык на рабочем столе (ai-coordinator.desktop)
   - Интеграция с Ollama через HTTP API

3. ГЕОПОЛИТИЧЕСКАЯ КАРТА (ГОТОВА 100%)
   - Отдельная страница (/geo-map)
   - 2D-карта на основе Leaflet
   - Цветная подсветка стран по статусу:
     * Красный (#ff1744) — критический (война)
     * Красно-оранжевый (#ff7d0b) — высокий (подготовка)
     * Жёлтый (#ffeb3b) — средний (напряжение)
     * Зелёный (#4caf50) — нормальный
   - Подписи стран (белые, тонкие, с тенью)
   - Маркеры новостей (29 демо-маркеров)
   - Кнопка "Копировать данные" (JSON со всеми маркерами и странами)
   - Клик по карте → показывает координаты
   - Клик по маркеру → показывает новость
   - Клик по стране → показывает статус
   - Статусы 24 стран

4. ОРИГИНАЛЬНЫЙ ИНТЕРФЕЙС CRUCIX (СОХРАНЁН)
   - Кнопки в шапке: HIGH ALERT, RSS 30, 🧠 AI Чат, 📡 КАРТА
   - 3D-глобус
   - Все оригинальные панели

=== API ===
- /api/rss/* — управление RSS
- /api/news/* — новости
- /api/ai/rate — AI оценка новостей
- /api/ai/chat — AI чат помощник
- /api/storage/* — управление хранением
- /api/geo/status — статусы стран
- /api/geo/markers — маркеры новостей

- /rss-feed — лента новостей
