# Economy Dashboard Module

## 📋 Description
**English:**
The **Economy Dashboard** module provides comprehensive data monitoring, analysis and reporting capabilities within the Crucix ecosystem.

## 🎯 Purpose
- Real-time data monitoring and analysis
- Integration with external data sources
- Automated reporting and visualization
- Risk assessment and early warning
- Multi-source data aggregation

## 🚀 How to Use
1. Access the module via: `/economy-dashboard`
2. Use REST API: `/api/economy-dashboard`
3. Configure via: `/config/economy-dashboard.json`
4. Monitor status: `/api/economy-dashboard/status`
