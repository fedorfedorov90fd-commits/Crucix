# Матрица источников: source-matrix.js

## Простое объяснение (для новичков)

Этот файл — «таблица сопоставления» источников и тем. Он показывает, какой источник о чём пишет: сколько статей по каждой теме у каждого источника. Это визуальная матрица, где строки — источники, столбцы — темы, а в ячейках — количество статей.

**Что он делает:**

1. **Запрашивает данные** у API `/api/layers/sources` и `/api/layers/articles?limit=500`.
2. **Строит матрицу** — для каждого источника считает, сколько у него статей по каждой теме.
3. **Рисует таблицу** — строки — источники, столбцы — темы, ячейки — количество.
4. **Раскрашивает ячейки** — чем больше статей, тем интенсивнее цвет.

**Как читать матрицу:**

- Яркая ячейка — источник активно пишет об этой теме.
- Бледная ячейка — источник тему почти не освещает.
- Пустая ячейка — источник о теме не пишет вообще.
- Если вся строка яркая — источник «универсальный», пишет обо всём.
- Если вся строка бледная — источник «узкий специалист».

**Зачем это нужно:**

Вы сразу видите специализацию источников: кто пишет об экономике, кто о военных действиях, кто обо всём подряд. Это помогает понять редакционную политику и не путать «универсальный агрегатор» с «узким экспертом».

**Аналогия:**

Это как таблица школьных оценок. Строки — ученики, столбцы — предметы, в ячейках — оценки. Вы сразу видите, кто силён в математике, кто в литературе, а кто — хорошист по всем предметам.

## Научная база (для специалистов)

Виджет реализует **матричную визуализацию** (matrix plot) для отображения распределения статей по источникам и темам.

**Архитектура:**

- **Технология:** Vanilla JS, HTML-таблица (`<table>`). Без D3.js — для простоты и скорости.
- **Данные:** `GET /api/layers/sources` (список источников) + `GET /api/layers/articles?limit=500` (статьи).
- **Группировка:** для каждого источника считается количество статей по каждой теме.
- **Темы:** извлекаются из поля `category` статей (например, `economy`, `military`, `cyber`).
- **Цветовая шкала:** интенсивность цвета пропорциональна количеству статей. От бледно-жёлтого (мало) до ярко-красного (много).

**Формально:**

Пусть `S = {s_1, s_2, ..., s_n}` — множество источников, `T = {t_1, t_2, ..., t_m}` — множество тем.

Матрица `M` размера `n × m`, где `M[i][j]` = число статей источника `s_i` по теме `t_j`.

**Нормализация:**

Для цветовой шкалы используется нормализация по максимуму:

**intensity(i, j) = M[i][j] / max(M)**

где `max(M)` — максимальное значение в матрице.

**Цвет:**

`rgb(r, g, b)` вычисляется по формуле:

**r = 255**
**g = 255 - intensity · 200**
**b = 100 - intensity · 100**

Это даёт переход от бледно-жёлтого (низкая интенсивность) к ярко-красному (высокая).

**Ограничения:**

- При большом количестве источников (> 30) и тем (> 10) — таблица становится нечитаемой.
- Темы извлекаются из `category`. Если категория не указана — статья попадает в `general`.
- Нормализация по максимуму: если один источник имеет 100 статей, а остальные — 5, то все остальные будут выглядеть бледно.

## Как работает (пошагово)

1. При загрузке страницы (`DOMContentLoaded`) вызывается `mountSourceMatrix()`.
2. `mountSourceMatrix()` находит контейнер по `id` (по умолчанию `'source-matrix'`).
3. Отправляет два запроса параллельно: `fetch('/api/layers/sources')` и `fetch('/api/layers/articles?limit=500')`.
4. Получает JSON, извлекает `sources` и `items`.
5. Строит множество тем из `item.category`.
6. Для каждого источника считает количество статей по каждой теме.
7. Вычисляет `max(M)` для нормализации.
8. Создаёт HTML-таблицу: заголовки строк — источники, заголовки столбцов — темы.
9. Заполняет ячейки: количество статей + цвет по интенсивности.
10. Вставляет таблицу в контейнер.

**Структура HTML:**

```html
<table>
  <thead>
    <tr>
      <th>Источник</th>
      <th>economy</th>
      <th>military</th>
      <th>cyber</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>ТАСС</td>
      <td style="background: rgba(255, 200, 100, 0.8)">15</td>
      <td style="background: rgba(255, 100, 50, 0.9)">25</td>
      <td style="background: rgba(255, 250, 100, 0.3)">3</td>
    </tr>
  </tbody>
</table>

Пример использования

В HTML-странице:
html

<div id="source-matrix"></div>
<script type="module" src="/widgets/source-matrix.js"></script>

В другом виджете (программно):
javascript

import { mountSourceMatrix } from '/widgets/source-matrix.js';

mountSourceMatrix('my-matrix-container');

Что появится на экране:

    Таблица с источниками по строкам и темами по столбцам.

    В ячейках — количество статей.

    Цвет ячеек: от бледно-жёлтого (мало) до ярко-красного (много).

Пример данных от API:
json

{
  "sources": [
    { "source": "ТАСС" },
    { "source": "Reuters" }
  ],
  "items": [

    { "source": "ТАСС", "category": "economy" },

  ]

Практические рекомендации

    limit=500 — компромисс между полнотой и скоростью. Больше — тормозит.

    Нормализация по максимуму — может давать искажённые проценты при малом числе статей. Для устойчивости используйте процентили.

    Категории — из item.category. Если категория не указана — general. Убедитесь, что статьи имеют категорию.

    Цветовая шкала — от бледно-жёлтого к ярко-красному. Интуитивно.

    Ограничение на количество источников — 30. При большем — таблица нечитаема. Агрегируйте.

    Ограничение на количество тем — 10. При большем — столбцы не влезают. Агрегируйте.

    Fallback на ошибки — если API недоступен, показывается сообщение. Страница не падает.

    overflow-x: auto — при большом количестве столбцов таблица не влезает в экран. Горизонтальный скролл спасает.

    Сортировка — по количеству статей (убывание). Это делает таблицу читаемой.

    Заголовки — жирным шрифтом. Это визуально отделяет заголовки от данных.

    <table> вместо SVG — проще, быстрее, доступнее. Для матрицы — идеально.

    Не используйте для динамики — матрица показывает только срез. Для динамики — линейный график.
