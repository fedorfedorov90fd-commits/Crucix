# Registry V2 Module

## 📋 Описание
**Русский:**
Модуль **Registry V2** является улучшенной версией системы реестров Crucix. Добавляет автоматическое сканирование, кэширование, версионирование и улучшенный поиск по всем модулям и страницам.

**English:**
The **Registry V2** module is an improved version of the Crucix registry system. Adds automatic scanning, caching, versioning and enhanced search across all modules and pages.

## 🎯 Назначение
- Автоматическое сканирование
- Кэширование
- Версионирование

## 🚀 Использование
1. Страница: `/registry-v2`
2. API: `/api/registry-v2`
3. Параметры: `?type=all&cache=true`
