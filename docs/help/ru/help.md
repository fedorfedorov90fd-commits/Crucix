# Help System Module

## 📋 Описание
**Русский:**
Модуль **Help** предоставляет централизованную систему справки для всех модулей Crucix. Содержит документацию, примеры использования, FAQ и руководства. Интегрируется со всеми страницами для контекстной помощи.

**English:**
The **Help** module provides a centralized help system for all Crucix modules. Contains documentation, usage examples, FAQ and guides. Integrates with all pages for contextual help.

## 🎯 Назначение
- Централизованная справка
- Контекстная помощь
- Документация и руководства

## 🚀 Использование
1. Страница: `/help`
2. API: `/api/help`
3. Параметры: `?module=collector-monitor`
