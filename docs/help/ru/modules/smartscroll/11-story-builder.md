# 11. Построитель сюжетов

## Расположение

/home/ta8_/Рабочий стол/Crucix/apis/sources/smartscroll-local/processing/story-builder.mjs

## Назначение

Кластеризация событий в сюжеты по метрике сходства.

## Класс

StoryBuilder

## Метрика сходства

- Сходство сущностей (вес 0.5)
- Сходство заголовков (вес 0.3)
- Сходство тел (вес 0.2)

## Порог

По умолчанию 0.45. Настраивается в конфигурации.

## Метод

addToStories(newEvents, existingStories) — распределяет события по существующим сюжетам или создаёт новые.

## Связи между сюжетами

При 3 и более общих сущностях между двумя сюжетами создаётся связь related_stories.
