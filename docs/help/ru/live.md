# Live Feed Module

## 📋 Описание
**Русский:**
Модуль **Live** предоставляет живую ленту событий в реальном времени. Отображает новости, уведомления, изменения данных и системные события. Используется для мониторинга текущей ситуации.

**English:**
The **Live** module provides a real-time live event feed. Displays news, notifications, data changes and system events. Used for current situation monitoring.

## 🎯 Назначение
- Живая лента событий
- Мониторинг в реальном времени
- Уведомления

## 🚀 Использование
1. Страница: `/live`
2. API: `/api/live`
3. Параметры: `?category=events&limit=50`
