### 4.1. `server.mjs` — ТОЧКА ВХОДА

**Задача:** Запустить HTTP-сервер на порту 3117, раздавать статику и обрабатывать API-запросы.

**Требования:**
- Отдавать `dashboard/public/jarvis.html` по адресу `/`

```javascript
import express from 'express';
import { fileURLToPath } from 'url';
import { dirname, join } from 'path';

const __dirname = dirname(fileURLToPath(import.meta.url));
const app = express();
const PORT = 3117;

app.use(express.static(join(__dirname, 'dashboard/public')));

app.get('/', (req, res) => {
  res.sendFile(join(__dirname, 'dashboard/public/jarvis.html'));
});

app.get('/api/health', (req, res) => {

});

});

10. ПРАВИЛА РАБОТЫ С ПРОЕКТОМ (ЧТОБЫ НЕ ПОВТОРЯТЬ ОШИБОК)
10.1. Правило №1: Никогда не редактировать server.mjs без крайней необходимости
Почему: Мы 5 раз переписывали server.mjs, и каждый раз ломали работающий сервер.

Решение: Есть только одна рабочая версия server.mjs:

javascript
import express from 'express';
import { fileURLToPath } from 'url';
import { dirname, join } from 'path';

const __dirname = dirname(fileURLToPath(import.meta.url));
const app = express();
const PORT = 3117;

app.use(express.static(join(__dirname, 'dashboard/public')));

app.get('/', (req, res) => {
  res.sendFile(join(__dirname, 'dashboard/public/jarvis.html'));
});

app.get('/api/health', (req, res) => {
  res.json({ status: 'ok', uptime: process.uptime() });
});

app.listen(PORT, () => {
  console.log(`Server running on http://localhost:${PORT}`);
});
Этот файл НИКОГДА не менять. Если нужно добавить API — добавлять в новый файл, а не в server.mjs.

10.2. Правило №2: ВСЕ изменения — только в jarvis.html и geopolitical-reports.mjs
Почему: Эти два файла отвечают за 90% функционала. Остальное — только если критично.

Что можно менять:

jarvis.html — стили, расположение панели, кнопки, язык

geopolitical-reports.mjs — список RSS-лент, логика AI, формат данных

10.3. Правило №3: Проверять изменения через тестовый скрипт
Перед тем как открывать браузер, запустить:

bash
node test-geopolitical.mjs
Если скрипт выдаёт ошибки — не открывать браузер, сначала исправить.

10.4. Правило №4: Не использовать Яндекс Браузер для отладки
Яндекс Браузер имеет свои блокировки, которые не имеют отношения к коду. Для проверки использовать:

Firefox (основной)

Chromium (если есть)

10.5. Правило №5: Все изменения — только через полную замену файла
Никаких "найди строку и замени". Только полная замена файла командой cat > файл << 'EOF' ... EOF.

10.6. Правило №6: Резервное копирование перед изменениями
Перед любыми изменениями делать бэкап:

bash
cp file.mjs file.mjs.bak
10.7. Правило №7: Не смешивать логику сервера и логику интерфейса
server.mjs — только сервер

jarvis.html — только интерфейс
