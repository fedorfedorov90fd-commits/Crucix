ДИАГНОСТИКА И ОТЛАДКА
Запустить сервер с полной отладкой (все ошибки в консоль):

text
node --trace-warnings --unhandled-rejections=strict server.mjs
Проверить синтаксис server.mjs без запуска:

text
node --check server.mjs
Запустить с увеличенной памятью (если сервер падает из-за нехватки памяти):

text
node --max-old-space-size=4096 server.mjs
Узнать, сколько памяти потребляет Crucix:

text
ps aux | grep node | grep server.mjs | awk '{print $6/1024 " MB"}'

text

text
sudo ss -tulpn | grep node

text
pkill -9 -f "node.*server.mjs"

ПРОДВИНУТЫЕ НАСТРОЙКИ
Создать кастомный конфиг для запуска:

text

Запустить в режиме только для чтения (не сохранять состояние):

text
