## Что такое Crucix predict-extensions

Crucix — открытая прогностическая система геополитических и экономических событий.

**Задача:** каждые 15 минут собирать данные из 40+ источников, прогонять через 16-фазный конвейер, публиковать распределение вероятностей по 6 отслеживаемым событиям, объяснять и калибровать.

**Конкуренты:** Palantir, Recorded Future, Seldon Vault.

**Отличие:** zero dependencies (чистый Node.js), мультидисциплинарность (45+ сигналов из 30 наук), калибровка через Brier Score, полная открытость кода.

## Принципы

1. **Zero dependencies** — только стандартная библиотека Node.js 20+.
2. **Graceful degradation** — падение одного модуля не блокирует конвейер.
3. **Circuit breaker** — 3 падения подряд → 5 пропусков.
4. **Timeout** — на каждый модуль.
5. **Brier Score** — калибровка весов модулей.
6. **Открытость** — каждая строка читается.
7. **Мультидисциплинарность** — 45+ сигналов из 30 наук.
