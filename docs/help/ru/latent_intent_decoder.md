# Декодер скрытых намерений: latent_intent_decoder.py

## Простое объяснение (для новичков)

Этот файл — «рентген намерений». Он смотрит на текст новости и отвечает на вопрос не «о чём это?», а «зачем это написано?».

**Пример:**

Источник пишет 100 новостей про курс доллара. Формально это «экономика». Но зачем? Возможно, чтобы отвлечь внимание от готовящейся военной эскалации. Обычный категоризатор скажет: «экономика». Этот модуль скажет: «латентная переменная А — отвлечение внимания».

**Как это работает:**

Вариационный автокодировщик (VAE) — это нейросеть, которая сжимает текст в компактный «код» (несколько чисел), а затем пытается восстановить текст из этого кода. В процессе сжатия сеть вынуждена оставить только самое важное — «суть» или «намерение» автора.

**Что делает модуль:**

1. **Сжимает текст** в 5 чисел (латентный вектор).
2. **Восстанавливает текст** из этих чисел — если восстановленный текст похож на оригинал, значит, 5 чисел действительно передают «суть».
3. **Возвращает латентный вектор** — координаты в «пространстве намерений». Например: ось 1 — «отвлечение внимания», ось 2 — «подготовка почвы», ось 3 — «тревожность».

**Зачем это нужно:**

Стандартные категории («экономика», «политика») слишком грубые. Одна и та же новость может быть «экономикой» в одном контексте и «отвлечением» в другом. VAE позволяет уйти от жёстких категорий к плавающим смыслам.

**Аналогия:**

Представьте, что вы пересказываете фильм пятью предложениями. Чтобы пересказ остался узнаваемым, вы должны схватить самое главное — не «там были машины», а «это история о предательстве». VAE учится находить такие «пять предложений» автоматически.

## Научная база (для специалистов)

Модуль реализует **вариационный автокодировщик (VAE)** — генеративную модель, которая учится сжимать данные в латентное пространство и восстанавливать их обратно.

**Архитектура:**

1. **Энкодер:** текст → параметры распределения `(mu, logvar)`.
2. **Сэмплирование:** `z = mu + eps * std`, где `eps ~ N(0, 1)`.
3. **Декодер:** `z` → восстановленный текст.
4. **Функция потерь:** `reconstruction_loss + KL_divergence`.

**Ключевые компоненты:**

- **`latent_dim = 5`** — размер латентного пространства. Узкое «горлышко» вынуждает модель сохранять только самые информативные факторы.
- **`chunk(2, dim=1)`** — разделяет выход энкодера на `mu` (среднее) и `logvar` (логарифм дисперсии).
- **`std = exp(0.5 * logvar)`** — стандартное отклонение.
- **`z = mu + eps * std`** — репараметризация (трюк, позволяющий обучать VAE через обратное распространение).
- **`ReLU` и `Sigmoid`** — активационные функции. `ReLU` для скрытых слоёв, `Sigmoid` для выхода.

**Формально:**

VAE максимизирует нижнюю оценку правдоподобия (ELBO):

**ELBO = E[log p(x|z)] - KL(q(z|x) || p(z))**

где:
- `E[log p(x|z)]` — ошибка реконструкции (насколько хорошо декодер восстанавливает текст).
- `KL(q(z|x) || p(z))` — KL-дивергенция (насколько распределение латентных переменных близко к нормальному).

**Почему VAE, а не обычный автокодировщик:**

Обычный автокодировщик просто сжимает текст. VAE добавляет регуляризацию: латентное пространство становится гладким, что позволяет интерполировать между точками. Это важно для поиска «скрытых осей» (намерений).

**Ограничения:**

- VAE требует обучения на вашем корпусе. Без этого латентные оси неинтерпретируемы.
- 5 измерений — компромисс. Для больших корпусов можно увеличить, но интерпретируемость упадёт.
- Оси нужно называть вручную по результатам анализа корреляций — не ожидайте «самоназваний».
- Модель чувствительна к языку и стилю. Обучайте отдельно для каждого языка или используйте многоязычные эмбеддинги как вход.

## Как работает (пошагово)

1. Текст проходит через энкодер.
2. Выход энкодера разделяется `chunk(2, dim=1)` на `mu` и `logvar`.
3. Вычисляется `std = exp(0.5 * logvar)`.
4. Сэмплируется `eps ~ N(0, 1)`.
5. Формируется `z = mu + eps * std`.
6. Декодер восстанавливает текст из `z`.
7. Функция потерь: `reconstruction_loss + KL_divergence`.
8. После обучения `mu` используется как латентный вектор намерения для новых текстов.
9. Оси латентного пространства интерпретируются аналитиком (например, через корреляцию с экспертными метками).

**Формат ответа:**

```python
{
    'z': [0.5, -0.3, 1.2, 0.0, -0.8],   # 5-мерный латентный вектор
    'mu': [0.5, -0.3, 1.2, 0.0, -0.8],  # среднее
    'logvar': [0.1, 0.2, 0.0, 0.1, 0.3], # логарифм дисперсии
    'reconstructed': "..."               # восстановленный текст
}

Пример использования
python

from services.latent_intent_decoder import IntentVAE, encode_intent

# Загрузка обученной модели
model = IntentVAE.load("models/intent_vae.pt")

# Кодирование текста
z = encode_intent(model, "Курс валют обновил минимум")
print(z)
# z = [0.5, -0.3, 1.2, 0.0, -0.8]

# Интерпретация осей (после анализа корреляций)
# Ось 1: отвлечение внимания (0.5 — умеренное)
# Ось 2: подготовка почвы (-0.3 — слабая)
# Ось 3: тревожность (1.2 — высокая)
# Ось 4: экономическое давление (0.0 — нейтральное)
# Ось 5: военная угроза (-0.8 — низкая)

Что происходит:

    Текст «Курс валют обновил минимум» формально про экономику.

    Но латентный вектор показывает высокую «тревожность» (ось 3 = 1.2).

    Это сигнал: текст может быть частью кампании по созданию тревожного фона.

Практические рекомендации

    VAE требует обучения на вашем корпусе. Без этого латентные оси неинтерпретируемы. Обучайте на исторических данных (10 000+ текстов).

    5 измерений — компромисс. Для больших корпусов можно увеличить до 10–20, но интерпретируемость упадёт. Начните с 5.

    Оси нужно называть вручную. После обучения проанализируйте корреляции между латентными переменными и экспертными метками (например, «тревожность», «отвлечение»). Присвойте имена.

    Модель чувствительна к языку и стилю. Обучайте отдельно для каждого языка или используйте многоязычные эмбеддинги как вход.

    Используйте латентные векторы как признаки для кластеризации. Не как окончательные ярлыки.

    Для инференса (предсказания) достаточно CPU. Для обучения — GPU.

    reconstruction_loss — ошибка реконструкции. Если она высокая, значит, 5 чисел не передают «суть» текста. Увеличьте latent_dim.

    KL_divergence — регуляризация. Если она слишком низкая, латентное пространство «схлопывается». Увеличьте вес KL в функции потерь.

    Не интерпретируйте латентные оси без анализа. «Ось 1» — это не «отвлечение», пока вы не доказали корреляцию.

    Комбинируйте с nlp_semantic_core.py. Эмбеддинги дают «понимание», VAE — «намерения». Вместе — полная картина.
