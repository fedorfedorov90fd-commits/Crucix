# Google Trends Module

## 📋 Description
**English:**
The **Google Trends** module provides comprehensive data monitoring, analysis and reporting capabilities within the Crucix ecosystem.

## 🎯 Purpose
- Real-time data monitoring and analysis
- Integration with external data sources
- Automated reporting and visualization
- Risk assessment and early warning
- Multi-source data aggregation

## 🚀 How to Use
1. Access the module via: `/google-trends`
2. Use REST API: `/api/google-trends`
3. Configure via: `/config/google-trends.json`
4. Monitor status: `/api/google-trends/status`
