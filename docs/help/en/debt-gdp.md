# Debt Gdp Module

## 📋 Description
**English:**
The **Debt Gdp** module provides comprehensive data monitoring, analysis and reporting capabilities within the Crucix ecosystem.

## 🎯 Purpose
- Real-time data monitoring and analysis
- Integration with external data sources
- Automated reporting and visualization
- Risk assessment and early warning
- Multi-source data aggregation

## 🚀 How to Use
1. Access the module via: `/debt-gdp`
2. Use REST API: `/api/debt-gdp`
3. Configure via: `/config/debt-gdp.json`
4. Monitor status: `/api/debt-gdp/status`
