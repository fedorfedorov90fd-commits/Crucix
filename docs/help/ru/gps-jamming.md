# GPS Jamming Module

## 📋 Описание
**Русский:**
Модуль **GPS Jamming** отслеживает случаи глушения GPS-сигналов по всему миру. Показывает зоны сбоев, источники помех и их влияние на авиацию, судоходство и военные операции. Данные от спутниковых группировок и наземных станций.

**English:**
The **GPS Jamming** module tracks GPS signal jamming incidents worldwide. Shows disruption zones, interference sources and impact on aviation, shipping and military operations. Data from satellite constellations and ground stations.

## 🎯 Назначение
- Мониторинг GPS-помех
- Безопасность навигации
- Анализ военных действий

## 🚀 Использование
1. Страница: `/gps-jamming`
2. API: `/api/gps-jamming`
3. Параметры: `?region=Europe&days=7`
