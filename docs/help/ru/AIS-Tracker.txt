AIS TRACKER — ОТСЛЕЖИВАНИЕ СУДОВ
============================================================
Версия: 1.0.0
Порт: 3190
Статус: ✅ РАБОТАЕТ

ОПИСАНИЕ
---------
Отслеживание морских судов через AIS-данные. Расширение модуля
dark-ships. Показывает позиции судов, статус и движение через
узкие места.

ФУНКЦИИ
--------
- Отслеживание судов в реальном времени (из basket)
- Фильтрация по географической области
- Интеграция с данными dark-ships
- Статус узких мест с количеством судов

API ЭНДПОИНТЫ
-------------
GET    /ais/snapshot            - Снимок AIS-данных (с фильтром)
GET    /ais/vessels             - Список всех судов
GET    /ais/chokepoints         - Узкие места с судами

ПРИМЕРЫ ЗАПРОСОВ
----------------
# Список судов
curl http://localhost:3190/ais/vessels

# Узкие места с судами
curl http://localhost:3190/ais/chokepoints

# Снимок по области (Ормузский пролив)
curl "http://localhost:3190/ais/snapshot?sw_lat=25.5&sw_lon=55.5&ne_lat=27.2&ne_lon=57.5"

ЗАВИСИМОСТИ
-----------
- Node.js v22+
- Данные dark-ships в корзине (/data/basket/)
