Инструкция по использованию OPML-файла:

Скопируйте весь текст из блока OPML выше.

Откройте текстовый редактор (Блокнот, Notepad++ и т.д.).

Вставьте текст и сохраните файл с именем, например, my_feeds.opml. Важно: в имени файла должно быть расширение .opml.

Откройте ваш RSS-ридер (например, QuiteRSS, Feedly, Inoreader, Liferea).

Найдите функцию «Импорт OPML» или «Import» и выберите только что сохраненный файл.

Все каналы будут загружены в ваш ридер с сохранением категорий.

Все готово для вашего проекта! Если понадобится отфильтровать что-то еще или добавить конкретные источники, дайте знать.

Инструменты для «превращения» сайтов в RSS
Вы можете сами создать RSS-ленту практически для любого сайта. Вот два подхода:

Проект rss-feeds: Он использует ИИ для автоматического создания RSS-лент по HTML-коду блога.

Сервис RSSHub: Популярный инструмент, позволяющий создавать RSS-ленты для сайтов, у которых их нет. Например, для Twitter-аккаунта DeepSeek можно использовать адрес: https://rsshub.app/twitter/user/deepseek_ai.

AI-агрегаторы новостей
Это готовые сервисы, которые сами собирают новости со множества источников и выдают их в виде RSS или подкаста.

AI Daily Digest: Ежедневный дайджест на GitHub, который собирает новости об ИИ из ~60 источников (включая TechCrunch, 36Kr, HuggingFace). Итоговый набор новостей и даже подкаст доступны по RSS.

AI RSS Feeds: Репозиторий на GitHub 0xSMW/rss-feeds, который агрегирует новости из всех значимых AI-исследовательских блогов.
