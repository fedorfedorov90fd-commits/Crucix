# Информационная геометрия: info_geometry.py

## Простое объяснение (для новичков)

Этот файл измеряет «расстояние между смыслами». Не между словами, а между картинами мира. Он отвечает на вопрос: «Насколько далеко расходятся нарративы двух источников по одной теме?»

**Пример:**

Слово «мир» и слово «перемирие» — близко по смыслу. Слово «мир» и слово «бомба» — далеко. Но обычная линейка (евклидово расстояние) плохо измеряет такие расстояния, потому что смыслы живут не на плоскости, а на искривлённой поверхности — как на глобусе.

**Что делает модуль:**

1. **Берёт два вектора** (эмбеддинга) — числовые представления двух нарративов.
2. **Нормализует их** — приводит к единичной длине. Теперь важно только направление (смысл), а не длина (объём текста).
3. **Вычисляет геодезическое расстояние** — длину дуги большого круга между двумя точками на сфере смыслов.
4. **Возвращает результат** — в радианах и с интерпретацией: `CRITICAL` (принципиальное расхождение) или `STABLE` (близкие нарративы).

**Зачем это нужно:**

Это математическое измерение дивергенции нарративов. Если расстояние между нарративами по теме «энергетика» резко сократилось — это признак подготовки сделки. Если резко выросло — признак разрыва. Даже если в текстах об этом ни слова.

**Аналогия:**

Представьте глобус. Два города на нём — Москва и Пекин. Кратчайший путь между ними — дуга, а не прямая линия сквозь землю. Обычная линейка (евклидово расстояние) покажет расстояние «сквозь землю», а геодезическое — реальный путь по поверхности. Модуль измеряет именно «путь по поверхности смыслов».

## Научная база (для специалистов)

Модуль реализует методы **информационной геометрии** (Амари, Нагаока) — раздела математической статистики, изучающего статистические многообразия.

**Формально:**

1. **Нормализация векторов:** `v_norm = v / ||v||`. После нормализации все векторы лежат на поверхности единичной гиперсферы `S^(n-1)`.
2. **Геодезическое расстояние:** для двух нормализованных векторов `a` и `b` расстояние вычисляется как:

   **d(a, b) = arccos(⟨a, b⟩)**

   где `⟨a, b⟩` — скалярное произведение. Это длина дуги большого круга — кратчайший путь по поверхности сферы.

3. **Пороги:**
   - `d < 0.5` — близкие нарративы (смыслы почти совпадают).
   - `0.5 ≤ d < 1.5` — умеренное расхождение.
   - `d ≥ 1.5` — `CRITICAL` (принципиальное расхождение). В радианах 1.5 ≈ 86°.

**Почему не евклидово расстояние:**

Евклидово расстояние `||a - b||` на векторах эмбеддингов **некорректно** по двум причинам:

1. Оно зависит от длины векторов, а длина зависит от объёма текста, а не от смысла.
2. Оно не учитывает кривизну пространства смыслов.

Геодезическое расстояние на гиперсфере решает обе проблемы: оно зависит только от направления (смысла) и учитывает кривизну.

**Библиотека `geomstats`:**

Предоставляет операции на сферах и гиперболоидах. Для гиперсферы используется `Hypersphere(dim).metric.dist(a, b)`.

**Матрица расстояний:**

Для набора нарративов строится матрица попарных расстояний — основа для визуализации «карты смыслов» (MDS, UMAP).

**Ограничения:**

- Геодезическое расстояние корректно только для нормализованных векторов. Не пропускайте нормализацию.
- Пороги в радианах неинтуитивны: переводите в градусы для отчётов (`d * 180 / π`).
- Сравнивайте нарративы, построенные одной моделью эмбеддингов: разные модели дают несопоставимые пространства.

## Как работает (пошагово)

1. `compute_narrative_distance(a, b)` принимает два вектора.
2. Нормализует их: `a / np.linalg.norm(a)`, `b / np.linalg.norm(b)`.
3. Вычисляет скалярное произведение: `dot(a, b)`.
4. Берёт `arccos` — геодезическое расстояние в радианах.
5. Сравнивает с порогами:
   - `< 0.5` — `STABLE`.
   - `0.5–1.5` — умеренное.
   - `≥ 1.5` — `CRITICAL`.
6. Возвращает результат: `{ geodesic_distance, narrative_divergence }`.

**Формат ответа:**

```python
{
    'geodesic_distance': 1.62,
    'narrative_divergence': 'CRITICAL'
}

Пример использования
python

from services.info_geometry import compute_narrative_distance, distance_matrix
from services.nlp_semantic_core import get_semantic_signature

# Получаем эмбеддинги двух нарративов
vec_a = get_semantic_signature("Переговоры по энергетике возобновились")
vec_b = get_semantic_signature("Энергетический шантаж продолжается")

# Вычисляем расстояние
d = compute_narrative_distance(vec_a, vec_b)
print(d)
# {'geodesic_distance': 1.62, 'narrative_divergence': 'CRITICAL'}

# Матрица расстояний для нескольких нарративов
m = distance_matrix({
    'russian': vec_a,
    'western': vec_b,
    'neutral': get_semantic_signature("Энергетика: нейтральный обзор")
})

Что означает результат:

    geodesic_distance = 1.62 — расстояние в радианах. В градусах: 1.62 * 180 / π ≈ 93°. Нарративы почти перпендикулярны.

    narrative_divergence = 'CRITICAL' — принципиальное расхождение. Стороны оперируют в разных системах координат.

Практические рекомендации

    Нормализация обязательна. Без неё геодезическое расстояние некорректно: длина вектора (объём текста) будет влиять на расстояние.

    Пороги в радианах неинтуитивны. Для отчётов переводите в градусы: d * 180 / π. 1.5 радиан ≈ 86°.

    Сравнивайте нарративы, построенные одной моделью эмбеддингов. Разные модели (например, all-MiniLM-L6-v2 и all-mpnet-base-v2) дают несопоставимые пространства.

    Отслеживайте динамику расстояния во времени. Тренд информативнее одного среза: если расстояние между нарративами сокращается — стороны сближаются, если растёт — расходятся.

    Матрицу расстояний удобно визуализировать как heatmap или проекцию (MDS/UMAP). Это даёт «карту смыслов».

    Не интерпретируйте CRITICAL как «война». Это «принципиальное расхождение в картинах мира». Причины могут быть разными.

    Для многоязычных корпусов используйте многоязычные эмбеддинги (например, paraphrase-multilingual-MiniLM-L12-v2). Тогда вектор «собака» и dog будут в одной точке сферы.

    geomstats — не единственная библиотека. Можно использовать scipy.spatial.distance.cosine для косинусного расстояния (это тоже геодезическое на сфере, но без нормализации). geomstats удобнее для матриц и проекций.

    Для больших корпусов — вычисляйте матрицу расстояний батчами, а не за один проход. Иначе не хватит памяти.
