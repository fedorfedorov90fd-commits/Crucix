# Модуль Agents (Агенты)

## Описание
Модуль **Agents** управляет автономными AI-агентами в системе Crucix. Агенты выполняют фоновые задачи: мониторинг источников, анализ данных, генерация отчётов и автоматические реакции на события.

## API Endpoints

| Метод | Путь | Описание |
|-------|------|----------|
| GET | `/api/agents` | Список всех зарегистрированных агентов |
| GET | `/api/agents/:id` | Информация о конкретном агенте |
| POST | `/api/agents/:id/start` | Запуск агента |
| POST | `/api/agents/:id/stop` | Остановка агента |
| GET | `/api/agents/:id/status` | Текущий статус агента |
| GET | `/api/agents/:id/logs` | Логи выполнения агента |

## Пример запроса
```bash
curl -X GET http://localhost:3117/api/agents
Формат ответа
json
{
  "agents": [
    {
      "id": "monitor-agent-01",
      "name": "Монитор GDELT",
      "status": "running",
      "type": "collector",
      "lastRun": "2026-09-01T22:30:00Z",
      "interval": 300
    }
  ]
}
Конфигурация
Агенты настраиваются в /config/agents.json. Поддерживаются:

cron — расписание запуска

collectors — список сборщиков для мониторинга

actions — действия при срабатывании триггеров

Логирование
Логи агентов сохраняются в /logs/agents/<agent-id>.log
