# Таблица источников: sources-table.js

## Простое объяснение (для новичков)

Этот файл — «список источников» на дашборде. Он показывает таблицу, где для каждого источника видно: имя, группу (russian/western/neutral), количество статей и время последней публикации.

**Что он делает:**

1. **Запрашивает данные** у API `/api/layers/sources?limit=30`.
2. **Строит HTML-таблицу** с колонками: `Источник`, `Группа`, `Статей`, `Last seen`.
3. **Раскрашивает группы** — синий для `russian`, красный для `western`, зелёный для `neutral`.
4. **Форматирует даты** — в локали `ru-RU` (например, «02.11.2026, 08:32»).
5. **Обрабатывает пустой результат** — показывает «Нет источников».

**Как читать таблицу:**

- Верхняя строка — самый активный источник (сортировка по количеству статей).
- Цветной ярлык группы — сразу видно, откуда источник.
- `Last seen` — когда была последняя публикация. Если давно — источник «спит».

**Зачем это нужно:**

Это «сводка» по всем источникам. Вы сразу видите: какие источники активны, какие — нет, кто доминирует в потоке.

**Аналогия:**

Это как список контактов в телефоне. Вы открываете и видите: имя, группа (семья, работа, друзья), количество звонков, последний звонок. Только вместо контактов — источники новостей.

## Научная база (для специалистов)

Виджет реализует **табличное представление** данных об источниках через HTML-таблицу.

**Архитектура:**

- **Технология:** Vanilla JS, HTML-таблица (`<table>`). Без библиотек — для простоты и скорости.
- **Данные:** `GET /api/layers/sources?limit=30` — список источников.
- **Формат:** `{ sources: [{ source, group, count, last_seen }] }`.
- **Сортировка:** по количеству статей (убывание) — на стороне API.
- **Цвета групп:** `russian` — `#3b82f6` (синий), `western` — `#ef4444` (красный), `neutral` — `#10b981` (зелёный).
- **Форматирование:** `new Date(last_seen).toLocaleString('ru-RU')` — локаль `ru-RU`, формат `DD.MM.YYYY, HH:MM`.

**Структура таблицы:**

| Источник | Группа | Статей | Last seen |
|---|---|---|---|
| ТАСС | `russian` | 120 | 02.11.2026, 08:32 |
| Reuters | `western` | 45 | 02.11.2026, 08:30 |

**Стилизация:**

- Заголовки — `#8899aa`, uppercase, мелкий шрифт.
- Строки — `border-bottom: 1px solid rgba(255,255,255,0.03)`.
- Цветной ярлык группы — `display: inline-block`, `padding: 1px 6px`, `border-radius: 3px`.
- `max-height: 500px`, `overflow-y: auto` — таблица скроллится, не растягивает страницу.

**Ограничения:**

- `limit=30` — максимум 30 источников. Если больше — не влезают в экран.
- Не поддерживает сортировку по клику. Сортировка — на стороне API.
- Не поддерживает фильтрацию. Для фильтрации — используйте `sources-api.mjs` напрямую.

## Как работает (пошагово)

1. При загрузке страницы (`DOMContentLoaded`) вызывается `mountSourcesTable()`.
2. `mountSourcesTable()` находит контейнер по `id` (по умолчанию `'sources-table'`).
3. Отправляет `fetch('/api/layers/sources?limit=30')`.
4. Получает JSON, извлекает `data.sources`.
5. Если массив пуст — показывает «Нет источников».
6. Если не пуст — строит HTML-таблицу:
   - Заголовок (`<thead>`) с колонками `Источник`, `Группа`, `Статей`, `Last seen`.
   - Тело (`<tbody>`) с строками для каждого источника.
7. Для каждой строки:
   - Имя источника — `#e0e0e0`.
   - Группа — цветной ярлык.
   - Количество статей — `#fbbf24` (жёлтый), жирный.
   - `Last seen` — `#4a5a6a`, мелкий шрифт.
8. Вставляет таблицу в контейнер.
9. Применяет стили (фон, граница, скролл).

**Структура HTML:**

```html
<table>
  <thead>
    <tr>
      <th>Источник</th>
      <th>Группа</th>
      <th>Статей</th>
      <th>Last seen</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>ТАСС</td>
      <td><span style="background: #3b82f6">russian</span></td>
      <td>120</td>
      <td>02.11.2026, 08:32</td>
    </tr>
  </tbody>
</table>

Практические рекомендации

    limit=30 — максимум 30 источников. Если больше — таблица становится нечитаемой. Для полного списка — используйте API напрямую.

    Цветовые ярлыки — russian (синий), western (красный), neutral (зелёный). Интуитивно и совпадает с другими виджетами.

    Форматирование дат — toLocaleString('ru-RU'). Для других локалей — замените локаль.

    max-height: 500px — таблица скроллится. Если хотите видеть больше — увеличьте, но следите, чтобы не ломать сетку дашборда.

    Сортировка по количеству — на стороне API. Не сортируйте на клиенте — это лишняя нагрузка.

    Fallback на ошибки — если API недоступен, показывается сообщение. Страница не падает.

    Тёмная тема — background: #0d0d1a. Стандарт для профессиональных терминалов.

    Не используйте для > 30 источников — таблица не влезает. Для больших списков — пагинация или фильтры.

    last_seen — полезно для мониторинга «мёртвых» источников. Если last_seen давно — источник не публикует.

    count — количество статей. Не путать с total_articles (в /stats).

    HTML-таблица, а не SVG — проще, быстрее, доступнее. Для таблицы — идеально.

    border-collapse: collapse — убирает двойные границы между ячейками.
