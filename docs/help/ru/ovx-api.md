# ovx-api API Module

## 📋 Описание
**Русский:**
API-модуль **ovx-api** предоставляет REST API для работы с данными в системе Crucix.

## 🎯 Назначение
- Обработка API-запросов
- Валидация данных
- Формирование ответов

## 🚀 Использование
- GET `/api/ovx-api` — получить данные
- POST `/api/ovx-api` — создать запись
- PUT `/api/ovx-api/:id` — обновить запись
- DELETE `/api/ovx-api/:id` — удалить запись
