# Loading Module

## 📋 Описание
**Русский:**
Модуль **Loading** управляет состоянием загрузки в Crucix. Отображает прогресс загрузки данных, индикаторы выполнения задач и анимации ожидания. Используется для улучшения пользовательского опыта.

**English:**
The **Loading** module manages loading states in Crucix. Displays data loading progress, task execution indicators and waiting animations. Used for improving user experience.

## 🎯 Назначение
- Индикация загрузки
- Прогресс выполнения
- Улучшение UX

## 🚀 Использование
1. Страница: `/loading`
2. API: `/api/loading`
3. Параметры: `?task=data-fetch&progress=45`
