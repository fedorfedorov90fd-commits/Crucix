# Geo Map Simple Module

## 📋 Описание
**Русский:**
Модуль **Geo Map Simple** предоставляет упрощённую версию географической карты для быстрого просмотра ключевых точек и событий. Оптимизирован для работы на мобильных устройствах и при низкой скорости интернета.

**English:**
The **Geo Map Simple** module provides a simplified version of the geographic map for quick viewing of key points and events. Optimized for mobile devices and low internet speeds.

## 🎯 Назначение
- Быстрый просмотр карты
- Мобильная оптимизация
- Базовый геомониторинг

## 🚀 Использование
1. Страница: `/geo-map-simple`
2. API: `/api/geo-map-simple`
3. Параметры: `?lat=55.75&lon=37.62&zoom=4`
