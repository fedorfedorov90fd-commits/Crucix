# Unique Indicators Module

## 📋 Описание
**Русский:**
Модуль **Unique Indicators** предоставляет набор уникальных индикаторов, разработанных специально для Crucix: индекс напряжения, коэффициент неопределённости, мультифакторные модели. Позволяет создавать собственные индикаторы.

**English:**
The **Unique Indicators** module provides a set of unique indicators developed specifically for Crucix: tension index, uncertainty coefficient, multi-factor models. Allows creating custom indicators.

## 🎯 Назначение
- Уникальные аналитические индикаторы
- Кастомизация показателей
- Расширенный анализ

## 🚀 Использование
1. Страница: `/unique-indicators`
2. API: `/api/unique-indicators`
3. Параметры: `?indicator=tension&region=Europe`
