
Модуль Emotion (Эмоциональный анализ)
Описание
Модуль Emotion выполняет анализ эмоциональной окраски текстов. Определяет 8 базовых эмоций в тексте: радость, печаль, гнев, страх, удивление, отвращение, доверие, предвкушение. Используется для анализа новостей, социальных сетей и пользовательских сообщений.

API Endpoints
Метод	Путь	Описание
GET	/api/emotion/status	Статус модуля
GET	/api/emotion/analyses	Список выполненных анализов
GET	/api/emotion/trends	Тренды эмоций за период
POST	/api/emotion/analyze	Анализ одного текста
POST	/api/emotion/analyze-all	Массовый анализ текстов
Пример запроса
bash
curl -X POST http://localhost:3117/api/emotion/analyze \
  -H "Content-Type: application/json" \
  -d '{"text": "Сегодня отличный день! Я так рад этому событию."}'
Формат ответа
json
{
  "text": "Сегодня отличный день! Я так рад этому событию.",
  "emotions": {
    "joy": 0.85,
    "sadness": 0.02,
    "anger": 0.01,
    "fear": 0.03,
    "surprise": 0.20,
    "disgust": 0.00,
    "trust": 0.70,
    "anticipation": 0.45
  },
  "dominant": "joy",
  "timestamp": "2026-09-01T22:30:00Z"
}
Интерфейс
Веб-интерфейс доступен по адресу /emotion с карточками эмоций, списком анализов и графиками трендов.

Модель анализа
Используется модель на базе трансформеров (BERT fine-tuned on GoEmotions) с точностью ~85% на тестовом наборе.

Логирование
Все анализы сохраняются в /data/emotion/analyses.json
