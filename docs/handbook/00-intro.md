# Введение

> «Не существует чёрного ящика. Есть математика, которую можно понять, проверить и улучшить.»

## О чём эта книга

Crucix Handbook — открытая платформа прогностической аналитики, объединяющая **45+ моделей из 30 наук**. Каждая модель читается в 100 строк, каждая формула проверяется, каждое предсказание калибруется.

Эта книга — не справочник API и не туториал. Это **трактат о том, как строить прогностические системы нового поколения**:

- **Мультидисциплинарность** вместо одной модели
- **Открытость** вместо чёрных ящиков
- **Калибровка** вместо голословных предсказаний
- **Zero dependencies** вместо стека из 500 npm-пакетов
- **Локальное выполнение** вместо облачных API

## Для кого

- **Инженеры данных**, которые хотят понять, как работают современные прогностические системы
- **Аналитики**, которым нужен инструмент для оценки рисков в реальном времени
- **Исследователи**, интересующиеся применением математики из смежных наук
- **Разработчики**, которые ценят открытый код и воспроизводимость
- **Скептики**, которые не верят в «AI-магию» и хотят видеть формулы

## Философия

Crucix построен на трёх принципах:

### 1. Открытость важнее удобства

Мы не используем TensorFlow, PyTorch или XGBoost. Не потому что они плохие — а потому что **понимание важнее удобства**. Каждый алгоритм в Crucix можно прочитать, проверить, изменить.

### 2. Мультидисциплинарность важнее эффективности

Одна модель никогда не победит ансамбль. Crucix использует 45+ сигналов из 30 наук, потому что **разные науки видят разные аспекты реальности**.

### 3. Калибровка важнее точности

Мы не стремимся к идеальным предсказаниям. Мы стремимся к **честной оценке неопределённости**. Brier Score показывает, насколько каждая модель заслуживает доверия.
