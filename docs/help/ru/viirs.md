# VIIRS Module

## 📋 Описание
**Русский:**
Модуль **VIIRS** отображает данные о ночных огнях со спутников Suomi NPP и NOAA-20. Показывает экономическую активность, городское освещение, пожары, рыболовство и военную активность. Используется для экономического и экологического мониторинга.

**English:**
The **VIIRS** module displays night lights data from Suomi NPP and NOAA-20 satellites. Shows economic activity, urban lighting, fires, fishing and military activity. Used for economic and environmental monitoring.

## 🎯 Назначение
- Мониторинг экономической активности
- Экологический мониторинг
- Анализ урбанизации

## 🚀 Использование
1. Страница: `/viirs`
2. API: `/api/viirs`
3. Параметры: `?region=Europe&date=2026-09-01`
