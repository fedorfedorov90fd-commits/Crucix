# Dark Ships Module

## 📋 Description
**English:**
The **Dark Ships** module provides comprehensive data monitoring, analysis and reporting capabilities within the Crucix ecosystem.

## 🎯 Purpose
- Real-time data monitoring and analysis
- Integration with external data sources
- Automated reporting and visualization
- Risk assessment and early warning
- Multi-source data aggregation

## 🚀 How to Use
1. Access the module via: `/dark-ships`
2. Use REST API: `/api/dark-ships`
3. Configure via: `/config/dark-ships.json`
4. Monitor status: `/api/dark-ships/status`
