# Trust Module

## 📋 Описание
**Русский:**
Модуль **Trust** оценивает доверие к источникам данных и СМИ. Анализирует репутацию, историю, достоверность и политическую ориентацию. Используется для фильтрации и оценки качества информации.

**English:**
The **Trust** module assesses trust in data sources and media. Analyzes reputation, history, reliability and political orientation. Used for filtering and assessing information quality.

## 🎯 Назначение
- Оценка достоверности источников
- Борьба с дезинформацией
- Фильтрация данных

## 🚀 Использование
1. Страница: `/trust`
2. API: `/api/trust`
3. Параметры: `?source=Reuters&metric=reliability`
