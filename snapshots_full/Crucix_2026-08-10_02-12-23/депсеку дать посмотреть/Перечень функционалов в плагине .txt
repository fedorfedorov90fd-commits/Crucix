Что сделано для проекта «Геополитика + AI» для Crucix
Полностью реализованные функции
Создана полная структура папок проекта — все необходимые директории для хранения данных, скриптов, отчётов и логов

Файл со всеми RSS-лентами — создан файл data/feeds/feeds.opml, в который внесены 400+ адресов из открытых источников: основные мировые агентства, американские и канадские СМИ, европейские издания, российские ленты, азиатские источники, африканские медиа, венгерские и центральноевропейские каналы, греческие и балканские ресурсы, турецкие издания, ближневосточные источники, оборонные и разведывательные ленты, правительственные ведомства, аналитические центры, медицинские и эпидемиологические ресурсы, испанские и латиноамериканские СМИ, а также технологические и бизнес-издания

Скрипт-сборщик RSS-лент — написан файл scripts/collect-feeds.mjs, который умеет парсить OPML-файл, загружать каждую RSS-ленту, извлекать заголовки, ссылки, даты и описания, удалять дубликаты по уникальному идентификатору, сохранять данные с ротацией по дням в папку data/raw/, а также обрабатывает ошибки загрузки и не падает при недоступности отдельных источников

Скрипт для ежедневного отчёта — создан файл scripts/daily-report.mjs, который собирает все данные за текущий день, формирует краткую сводку с общим количеством новостей и количеством уникальных источников, сохраняет сырые данные в папку для ИИ data/ai_raw/geopolitical-reports/, создаёт текстовый отчёт с топ-10 заголовков в папку reports/

Скрипт для очистки старых файлов — написан scripts/clean-old.mjs, который автоматически удаляет файлы старше 7 дней из папок с сырыми данными, отчётами и данными для ИИ

Настройка package.json — в файл добавлены команды npm run collect, npm run report и npm run clean для удобного запуска всех скриптов

Настройка cron-расписания — созданы правила для автоматического сбора данных каждые 6 часов, ежедневного формирования отчёта в 8:00 утра и ночной очистки старых файлов в 3:00

Папка для логов — создана директория logs/, куда записываются все логи работы системы

Тестовый скрипт — написан файл test-geopolitical.mjs для проверки работы модуля через терминал без запуска всего Crucix

Серверная точка входа — создан рабочий файл server.mjs, который запускает HTTP-сервер на порту 3117 и раздаёт статику из папки dashboard/public/

Интерфейсная часть — создан файл dashboard/public/jarvis.html с 3D-глобусом, боковыми панелями и нижней сеткой, куда встроена панель «Геополитика + AI»

Панель в интерфейсе — написаны файлы dashboard/panels/geopolitical-reports/index.mjs для логики панели и style.css для её стилей

Регистрация панели — в файле dashboard/inject.mjs прописана регистрация панели «Геополитика + AI» в общем списке панелей Crucix

Модуль сбора данных — создан основной модуль apis/sources/geopolitical-reports.mjs, который отвечает за парсинг RSS, сохранение в корзину и отправку запросов к AI-провайдерам

Настройки через интерфейс — реализована возможность выбирать AI-провайдера из списка (DeepSeek, OpenRouter, Ollama, Авто), вводить API-ключ, выбирать модель, регулировать температуру, включать авто-анализ и устанавливать срок хранения новостей в днях

Поддержка двух языков — добавлена кнопка переключения между русским и английским языками интерфейса, все надписи и подписи дублируются на обоих языках

Сворачиваемая панель — панель можно свернуть и развернуть кликом по заголовку, что экономит место на экране

Инструкция по использованию — создан файл с подробной инструкцией на двух языках, объясняющей что это за модуль, как его установить, настроить и пользоваться, а также как решать возможные проблемы

Документация по проекту — написан файл инструктаж.txt с полным техническим заданием, структурой проекта, правилами работы и пошаговым планом действий

Идея программы поддержки open-source разработчиков — сформулировано и передано команде DeepSeek предложение о создании специальной программы для разработчиков, которые создают бесплатные открытые проекты, с автоматической публикацией кода и защитой от коммерциализации

Функции, которые запланированы, но пока не сделаны
Интеграция с MAX — не подключена возможность сбора статей из российского мессенджера MAX, хотя технические средства для этого существуют в виде MCP-серверов и SDK

Подключение Telegram-каналов — не настроен сбор данных из публичных Telegram-каналов, особенно OSINT-источников, хотя такой функционал есть в альтернативных проектах

Автоматическая отправка в DeepSeek через API — нет скрипта, который бы брал сжатый дайджест из локальной модели и отправлял его в DeepSeek для глубокого анализа с последующим сохранением результата

Локальная фильтрация через Ollama — не настроена автоматическая фильтрация сырых данных локальной моделью перед отправкой в большую модель, хотя технически это возможно

Модуль «Аналитические центры» — не реализован сбор RSS-лент от RAND, CSIS, IISS, ISW, Chatham House и других аналитических центров для получения готовых аналитических отчётов

Модуль «Критическая инфраструктура» — не добавлены GeoJSON-слои с подводными кабелями, нефтегазопроводами и стратегическими проливами на карту

Модуль «Индекс нестабильности» — не написан алгоритм для расчёта индекса нестабильности стран на основе военных полётов, протестов и экономических сигналов

Модуль «Сравнительный анализ» — не создан инструмент для сравнения сегодняшних событий с прошлыми периодами и выявления новых трендов

Модуль «Живые новостные потоки» — не встроены плееры с live-каналами типа BBC, Al Jazeera, France 24 в интерфейс

Модуль «Киберугрозы» — не подключены ленты Feodo Tracker, AbuseIPDB, AlienVault OTX для мониторинга C2-серверов и вредоносной активности

Модуль «Аномалии морского трафика» — не реализован алгоритм выявления судов с выключенным AIS и обнаружения аномальных маршрутов

Интеграция OpenRouter — не настроена поддержка OpenRouter как единого шлюза для бесплатных AI-моделей, хотя есть запрос от сообщества на эту функцию

Модуль «Векторная память» — не подключена векторная база данных ChromaDB для хранения истории и организации поиска по прошлым отчётам

Модуль «Цифровой двойник пользователя» — не реализована возможность загружать свои документы (контракты, отчёты) для персонализированного анализа событий

Модуль «Симулятор сценариев» — не создан инструмент для моделирования «что-если» с изменением ключевых параметров (цена нефти, военная активность)

Модуль «Многоязычный мост» — не реализован смысловой анализ новостей на языке оригинала с учётом культурных и политических нюансов

Модуль «Честная метрика» — не написан инструмент для разделения реальных и синтетических прогнозов при оценке точности системы

Модуль «Детектор белого шума» — не создан анализатор, который выявляет зоны информационной тишины при аномальной военной активности

Автоматический запуск всех скриптов в правильной последовательности — нет единого скрипта-оркестратора, который бы запускал сбор, фильтрацию, анализ и сохранение отчёта одной командой

Интерфейс для просмотра старых отчётов — не реализована возможность открывать и просматривать отчёты за прошлые дни прямо из интерфейса Crucix

Автоматическое обновление данных на карте — собранные данные пока не отображаются на 3D-глобусе как события на карте

Поддержка локального DeepSeek — не настроена возможность использовать локальную версию DeepSeek через Ollama вместо облачного API

Программа поддержки open-source разработчиков — не создана официальная программа DeepSeek для разработчиков, хотя предложение сформулировано и передано

Автоматическая публикация кода в открытые репозитории — не настроен механизм, который бы автоматически публиковал созданный с помощью AI код в публичные репозитории GitHub

Защита кода от коммерциализации — не реализована юридическая и техническая система для предотвращения закрытия кода, созданного в рамках open-source инициативы
