# Scenario Engine Module

## 📋 Описание
**Русский:**
Модуль **Scenario Engine** позволяет создавать и моделировать сценарии развития событий на основе текущих данных. Использует AI для генерации прогнозов, оценки рисков и выработки рекомендаций. Поддерживает "what-if" анализ.

**English:**
The **Scenario Engine** module allows creating and modeling event scenarios based on current data. Uses AI for forecasting, risk assessment and recommendations. Supports "what-if" analysis.

## 🎯 Назначение
- Моделирование сценариев
- Прогнозирование рисков
- Поддержка принятия решений

## 🚀 Использование
1. Страница: `/scenario-engine`
2. API: `/api/scenario-engine`
3. Параметры: `?scenario=geopolitical&model=bert`
