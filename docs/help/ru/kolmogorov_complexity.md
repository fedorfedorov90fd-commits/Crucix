# Алгоритмическая сложность: kolmogorov_complexity.py

## Простое объяснение (для новичков)

Этот файл — «детектор штампов». Он смотрит на текст новости и отвечает на вопрос: «Это живой текст или шаблон?» И делает это очень простым способом — сжимает текст архиватором.

**Как это работает:**

Возьмите архиватор (например, WinRAR или zip). Дайте ему рассказ Чехова — он сожмёт его процентов на тридцать. Текст сложный, живой, с деталями, его трудно сжать.

А теперь дайте ему текст, написанный роботом: «Слава... Слава... Слава...». Он сожмёт его в сто раз. Текст шаблонный, повторяющийся, его легко сжать.

Модуль делает то же самое: сжимает новость и смотрит на результат. Если текст «схлопнулся» слишком сильно — значит, внутри мало настоящей информации. Перед нами шаблон, методичка или дешёвая генерация.

**Зачем это нужно:**

Пропаганда и боты всегда пишут шаблонно. Их тексты «пустые» внутри. Модуль ловит это без тяжёлых нейросетей — за миллисекунды.

**Аналогия:**

Представьте, что вы проверяете монету на подлинность. Настоящая монета имеет сложный рельеф, её трудно подделать. Фальшивая — гладкая, простая. Модуль «взвешивает» текст: если он слишком «лёгкий» (легко сжимается) — вероятно, фальшивка.

## Научная база (для специалистов)

Модуль реализует практическую оценку **колмогоровской сложности** строки через коэффициент сжатия.

**Формально:**

Колмогоровская сложность `K(s)` строки `s` — длина кратчайшей программы, которая порождает `s`. Точное вычисление невозможно (теорема Чейтина), поэтому используется практический прокси — **сжимаемость**.

**Прокси:**

**K(s) ≈ |C(s)|**

где `C(s)` — сжатая версия строки `s` (например, через DEFLATE). Чем сильнее сжимается текст, тем ниже его алгоритмическая сложность.

**Метрики:**

- **`ratio = |C(s)| / |s|`** — коэффициент сжатия. Чем меньше, тем сложнее текст.
- **`synthetic_probability`** — `HIGH`, если `ratio < 0.2`, иначе `LOW`.
- **`narrative_rigidity = 1 - ratio`** — «жёсткость» нарративной формы. Чем выше, тем более шаблонный текст.

**Почему DEFLATE:**

- **Стандарт.** Встроен в `zlib`, доступен в любом Python.
- **Быстрый.** Не требует GPU, работает за миллисекунды.
- **Достаточно точный.** Для оценки «шаблонности» DEFLATE даёт хорошую корреляцию с истинной сложностью.

**Ограничения:**

- Короткие тексты сжимаются иначе, чем длинные. Порог 0.2 эмпирический — калибруйте отдельно по длине.
- Метод чувствителен к языку и кодировке. Для смешанных языков делайте поправку.
- Высокая сжимаемость бывает и у legit-текстов с формулами и повторами (например, официальные пресс-релизы). Не используйте как единственный критерий.

## Как работает (пошагово)

1. `calculate_kolmogorov_complexity(text)` принимает строку.
2. Кодирует в байты: `text.encode('utf-8')`.
3. Сжимает через `zlib.compress(data)`.
4. Вычисляет `ratio = len(compressed) / len(original)`.
5. Если `ratio < 0.2` — `synthetic_probability = 'HIGH'`.
6. Вычисляет `narrative_rigidity = 1 - ratio`.
7. Возвращает результат.

**Формат ответа:**

```python
{
    'ratio': 0.18,
    'synthetic_probability': 'HIGH',
    'narrative_rigidity': 0.82
}

Интерпретация:

    ratio = 0.18 — текст сжался в 5.5 раз. Очень шаблонный.

    synthetic_probability = 'HIGH' — вероятно, бот или методичка.

    narrative_rigidity = 0.82 — жёсткая форма, мало информации.

Пример использования
python

from services.kolmogorov_complexity import calculate_kolmogorov_complexity

# Живой текст (рассказ)
living_text = "Вчера вечером на площади произошёл взрыв. Очевидцы рассказывают..."
result = calculate_kolmogorov_complexity(living_text)
print(result)
# {'ratio': 0.42, 'synthetic_probability': 'LOW', 'narrative_rigidity': 0.58}

# Шаблонный текст (пропаганда)
template_text = "Слава нашему лидеру! Слава нашей партии! Слава нашему народу!"
result = calculate_kolmogorov_complexity(template_text)
print(result)
# {'ratio': 0.15, 'synthetic_probability': 'HIGH', 'narrative_rigidity': 0.85}

Что происходит:

    Живой текст сжимается умеренно (ratio ≈ 0.42). Это норма: текст сложный, энтропийно богатый.

    Шаблонный текст сжимается сильно (ratio ≈ 0.15). Это сигнал: текст пустой внутри.

Практические рекомендации

    Порог 0.2 — эмпирический. Для коротких текстов (< 200 символов) сжимаемость выше, поэтому порог нужно снизить. Для длинных (> 2000) — можно оставить 0.2.

    Метод чувствителен к языку. Для русского языка сжимаемость выше, чем для английского (больше длинных слов, больше повторяемости). Калибруйте отдельно.

    Не используйте как единственный критерий. Высокая сжимаемость бывает и у legit-текстов с формулами и повторами (например, официальные пресс-релизы). Комбинируйте с другими сигналами (задержка публикации, синхронность).

    Модуль очень быстрый. Не требует GPU. Хороший кандидат для первой линии фильтрации.

    narrative_rigidity — «жёсткость» формы. Чем выше, тем более шаблонный текст. Полезно для сортировки: сначала проверять самые «жёсткие».

    Не путайте с «фейком». Высокая сжимаемость — это не «фейк», это «шаблон». Фейк может быть сложным, а правда — шаблонной (например, официальные заявления).

    Для больших корпусов — вычисляйте батчами, а не за один проход. Иначе не хватит памяти.

    zlib.compress — стандарт. Не используйте gzip или bz2: они дают другие коэффициенты, несопоставимые с калибровкой.

    Для смешанных языков — делайте поправку. Например, если текст на русском и английском, сжимаемость может быть ниже, чем для чистого русского.

    Комбинируйте с nlp_semantic_core.py. Эмбеддинги дают «понимание», а сжатие — «шаблонность». Вместе — полная картина.
