=== ПРОЕКТ CRUCIX — СТАТУС НА 2026-08-09 ===

=== ОБЩАЯ ЦЕЛЬ ===
Создать независимую, полностью бесплатную OSINT-платформу (аналог WorldMonitor) с открытым кодом, работающую на Debian. Ключевое отличие: модульная архитектура, локальный AI, прозрачная аналитика.

=== ТЕХНИЧЕСКАЯ СРЕДА ===
- Debian (AMD64)
- Node.js 20.x
- Ollama + deepseek-r1:7b (для сложных задач) и deepseek-r1:1.5b (для быстрых)
- Tor для обхода блокировок (Telegram)

=== ВЫПОЛНЕННЫЕ ЗАДАЧИ (9 АВГУСТА 2026) ===

1. СТРУКТУРА ДРАЙВЕРОВ
   - base.mjs — базовый класс для всех драйверов
   - max-driver.mjs — драйвер для MAX (требуется API-ключ)
   - telegram-driver.mjs — драйвер для Telegram (работает через Tor)
   - router.mjs — адаптивный шлюз (автоматический выбор драйвера)

2. AI-ФИЛЬТР НОВОСТЕЙ
   - ai-filter.mjs — фильтр с поддержкой тем (геополитика, роботоиндустрия, биотех, кибер)
   - Интеграция с Ollama для оценки новостей по шкале 0-10
   - Автоматическая фильтрация по ключевым словам и AI-оценка

3. КООРДИНАТОР ПРОЕКТА
   - coordinator.mjs — однопроходный анализ состояния
   - interactive.mjs — диалоговый режим с уточняющими вопросами

4. RSS-СИСТЕМА
   - collect-feeds.mjs — сбор из 400+ лент
   - daily-report.mjs — ежедневный отчёт с AI-фильтрацией
   - clean-old.mjs — автоматическая очистка старых файлов (7 дней)

5. TELEGRAM-ДРАЙВЕР
   - Через Tor, ручная обработка редиректов (301/302)
   - Поддерживает парсинг HTML, JSON и регулярных выражений
   - Протестирован на каналах: durov, bbc_news, reuters, apnews

6. ГИТ-ИНФРАСТРУКТУРА
   - Локальный репозиторий инициализирован
   - .gitignore создан
