=== COLLECTOR MONITOR ===
URL: /collector-monitor
Module: #22 — Collector Monitor
Category: System
Icon: 📊

DESCRIPTION:
Centralized monitoring of all Crucix data collectors status.

FUNCTIONALITY:

- List of all collectors with their statuses
- Record count in basket for each collector
- Data age (time since last update)
- Data size in basket
- Log errors
- Last run time
- View collector logs on click
