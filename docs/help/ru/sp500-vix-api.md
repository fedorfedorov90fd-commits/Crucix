# sp500-vix-api API Module

## 📋 Описание
**Русский:**
API-модуль **sp500-vix-api** предоставляет REST API для работы с данными в системе Crucix.

## 🎯 Назначение
- Обработка API-запросов
- Валидация данных
- Формирование ответов

## 🚀 Использование
- GET `/api/sp500-vix-api` — получить данные
- POST `/api/sp500-vix-api` — создать запись
- PUT `/api/sp500-vix-api/:id` — обновить запись
- DELETE `/api/sp500-vix-api/:id` — удалить запись
