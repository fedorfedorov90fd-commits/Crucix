## 1. PURPOSE AND PLACE IN THE CRUCIX ECOSYSTEM

# # # 1.1. What is the Crucix ecosystem of 5 maps?

Crucix is a geopolitical OSINT platform. It consists of * * 5 standalone maps**, each visualizing its own data class:

1. * * Event Map** (`/event-map/`) — point events on the map (rallies, attacks, incidents). 84 layers, markers.
2. * * Metrics Map** (`/metrics-map/`) — quantitative indicators by country (economy, finance, ESG, cyber, energy). ** 75 layers**, choropleth.
3. * * Semantic Map** (`/semantic-map/`) — semantic analysis of texts (tonality, narratives, misinformation). 35 layers.
4. * * Forecast Map** (`/forecast-map/`) — probabilistic forecasts (recession, conflicts, risks). 16 layers.
5. * * Network Map** (`/network-map/`) - connection graphs (cyber networks, trade, finance, migration). 12 layers, SVG graph.

### 1.2. Why exactly 5 cards, and not just one

Five maps are an implementation of the principle of **Separation of Concerns** (Dijkstra 1974). Each data class requires its own visualization model:

- **Events * * → position + color (point markers). Channel: Position. Capacity: high for localization.
- **Quantitative indicators * * → position (country) + color intensity (choropleth). Channel: Position + Color intensity. Munzner 2014, Table 5.3-fully separable.
- **Semantics* * → position + categorical color + shape. Channel: Position + Hue + Shape.
- **Probabilities * * → position + color + opacity. Канал: Position + Color intensity + Transparency.
- **Links** → graph topology (force-directed). Channel: Position (force) + Shape.

Trying to combine everything into a single map would violate * * the principle of channel separability* * (Munzner 2014). The user would not be able to perceive 5 different encodings at the same time without cognitive interference. Splitting into 5 maps is a science-based decision, not an organizational convenience.

# # # 1.3. What does Metrics Map do?

Metrics Map visualizes * * numeric indicators for 90 countries around the world**. Each layer is a single indicator:

- Economics: PMI, Inflation, GDP, Unemployment, Trade balance, consumer confidence, business optimism, consumer expectations, probability of recession, debt/GDP
- Finance: Dollar Index, Spreads, Copper/Gold, Gold / Oil, Gold/Silver, Yield Curve, Big Mac, Uranium, HY OAS, OVX, S&P / VIX, VXX, Crypto Fear, Rouble-in-Dubai, WTI/Brent
- ESG: happiness, population density, refugees, urbanisation, WHO, COVID-19, HDI
- Cyber: CVE vulnerabilities, composite index of cyber threats
- Energy: EIA, Nuclear, Renewable, Oil / Gas, WTI/Brent spread
- Health: WHO, COVID-19, medical infrastructure
- Social: population displacement, refugees, phone activity
- Geopolitics: social tensions, corruption, democracy, instability, sustainability, strategic risk
- Military: expenses, preparation for war
- Threats: CVE vulnerabilities
- Intelligence: patterns of behavior
- News: Google Trends
- Other: Internet, mobile communication

Total: * * 75 layers in 13 categories**.

Each layer when activated:
1. Gets data from the `/api/layers/<layerId>` API (or `/api/layers/<layerId>/featurecollection`).
2. If the API is unavailable (404) - triggers * * offline fallback**: data is generated locally from `countries.js ' using a deterministic generator with correlation by country status (critical → higher, normal → lower).
3. Classifies values using one of 5 methods: Jenks DP, Quantile, Equal Interval, Standard Deviation, Manual (domain thresholds).
4. Applies the ColorBrewer palette (sequential or diverging).
5. Paints over 90 countries on the map using 'applyChoropleth'.
6. Draws a legend with class thresholds, classification method and quality (GVF).
7. Logs the result: `[Choropleth] method=jenks, breaks= [...], GVF=0.9199`.

### 1.4. Differences from Event Map

Event Map and Metrics Map differ in the visualization class:

- **Event Map:** each point is a separate event (incident, rally). Thousands of markers. `vizType='marker'`.
- **Metrics Map:** each country is an aggregate of a numeric indicator. 90 countries. `vizType='choropleth'` или `'series'`.

Event Map generates data from events, Metrics Map-from indicators. These are different data models, and both do not reduce to each other without losing meaning.

## 6. HOW EACH LAYER TYPE WORKS

### 6.1. Choropleth (56 layers)

When you click on a layer:
1. `loadLayer(layerId)'called from `layers.js`.
2. `MetricsMap.interceptLoad(layerId)'intercepts.
3. `vizType === 'choropleth'` → `loadChoroplethLayer(layer)`.
4. `fetch('/api/layers/<id>/featurecollection')`.
5. If 404 → ' renderFallback(layer)`:
 - Deterministic seed by `layer.id`.
 - For each of the 90 countries, value = base (status) + noise(seed).
 - Jenks classification (or manual for PMI/recession).
   - `applyChoropleth()` paints over countries.
 - Logs GVF (usually 0.90–0.93).
6. If the API works, the data is applied directly.

### 6.2. Series (14 layers)

When you click:
1. `interceptLoad` → `loadSeriesLayer(layer)`.
2. `fetch('/api/layers/<route>')`.
3. If 404 → 'renderFallback' (as for choropleth).
4. If the API works — ' SeriesAdapter. convert(layerId, SeriesData, countries)`:
 - Selects the spatial proxy (us_market, oil_producers, financial_centers, etc.).
 - Applies transformation (weighted_value, stress_indicator, ratio_indicator).
 - Classifies (jenks / manual).
 - Returns features for choropleth.

### 6.3. Marker (6 layers)

When you click:
1. `interceptLoad` → `loadMarkerLayer(layer)`.
2. `fetch('/api/layers/<id>')`.
3. If 404 → ' renderMarkerFallback(layer)`:
 - 2 markers for each of the 90 countries = 180 markers.
 - Position = country coordinates + deterministic shift.
 - Added to 'window. markerData'.
 - Redrawn via 'updateMarkers'.

Total when all 6 marker layers are fully activated: 6x180 = * * 1080 markers**.

## 16. CONTRACTS BETWEEN CARDS
18.1. The principle of autonomy
Each map is completely offline. Zero cross-map dependencies in scripts and data. The only allowed form of communication is navigation links in the UI (switching between maps).

18.2. Navigation (5 switches)
In each index.html the .map-switcher block contains 5 links:

html
<a class="map-switch-btn" data-map="events" href="../event-map/">Events</a>
<a class="map-switch-btn active" data-map="metrics" href="../metrics-map/">Metrics</a>
<a class="map-switch-btn" data-map="meanings" href="../semantic-map/">Semantic</a>
<a class="map-switch-btn" data-map="relations" href="../network-map/">Network</a>
<a class="map-switch-btn" data-map="forecasts" href="../forecast-map/">Forecast</a>
The active map has the active class.

18.3. mapType format
Each map declares its own type in an inline script:

html
<script>window.CrucixMap = { mapType: 'metrics', name: 'Crucix — Metrics Map' };</script>
Types:

events — Event Map

metrics — Metrics Map

meanings — Semantic Map

relations — Network Map

forecasts — Forecast Map

18.4.manifest. json format
Each map has a manifest.json with the schema:

json
{
  "mapType": "metrics",
  "version": "1.1",
  "autonomous": true,
  "principle": "FULL_ISOLATION",
  "layers": 75,
  "categories": [...],
  "local_cross_map": 0,
  "failure_domain": 1,
  "scripts": { ... },
  "data": { "world_geojson": "data/world.geojson" }
}
Common fields: mapType, version, autonomous, principle, local_cross_map, failure_domain.

18.5. What is NOT a contract
Not a contract:

Shared JS files (core.js, countries.js, map-controls.js) — each map has its own copy.

Shared world.geojson — each map has its own copy in data/.

General CSS — each map has its own metrics-map.css or event-map. css.

Shared APIs — each map accesses its own endpoints.

Contract:

Navigation links in .map-switcher.

Window. CrucixMap format.

The manifest.json schema.

Naming convention: event-map, metrics-map, semantic-map, network-map, forecast-map.

18.6. Failure domain = 1
A crash in one map doesn't affect the other 4. This is guaranteed by three conditions:

No <script> is loaded from ../other-map/js/.

No map does fetch ('../other-map/data/...').

Navigation links are normal <a href>, not fetch.

If the neighbor map is broken, navigation will not work, but the current map will continue to work.

## 19. CHANGE HISTORY

### 21.1. Version 1.0 → 1.1 — 28.09.2026

* * File `js/layers.js`:**

- **What happened:** 'enableAllLayers' added all layers to` activeLayerIds ' before the loop. Then `loadLayer (id) ' for each layer. But 'loadLayer' first checks `if (activeLayerIds.has(layerId)) ' - > toggle-off. Bottom line: the loop didn't load layers, but turned them off.
- **What happened:** removed the `activeLayerIds.add () ' preview. Before `loadLayer(id)` — force ' activeLayerIds. delete(layerId)`. `loadLayer 'follows the' enable 'branch, calls' interceptLoad` → fallback → loading data.
- **Logs:** added to each iteration: `[enableAllLayers] Start`, count `ok/empty/fail/skipped`, final line `[enableAllLayers] Total: 75, with data: N, empty: N, errors: N, omitted: N`.
- **Rational:** toggle logic defect (Martin 2003: Single Responsibility broken — the upload function did both upload and toggle).

* * File `js/metrics-map.js`:**

- **What happened:** 'interceptLoad' only handled 'vizType=' choropleth 'and `vizType= 'series'. For 'vizType=' marker 'returned' false '— control was given `layers.js`, which did a ' fetch('/api/layers/<id>')` and got a 404. No data appeared.
- **What happened:** added `loadMarkerLayer(layer)` + `renderMarkerFallback(layer) ' method`. Now 6 marker layers (`vix-futures`,` cftc-cot`,` insider-trading`,` sec-filings`,` short-interest`,` bankruptcy-filings') get fallback: 2 markers for each of 90 countries = 180 markers per layer.
- **Rational:** the processing space is closed. Marker layers now work offline.

* * File `js/copy-data.js`:**

- **What happened:** snapshot of ~40 KB. Collected statistics, layers, markers, and DOM structure.
- **What happened:** extended version. 15 sections: full configuration of 75 layers, layer matrix, diagnostics by vizType and categories, data of active layers (all 90 countries × N layers), choropleth legend, countries with coordinates, DOM layer panels, map, palettes, status panel.
- **Target size:** 300-500 KB with 75 data layers.

28.3. Bottlenecks and optimization
Bottleneck 1: 75 separate loadlayers with a 30 ms delay.

Formula: T = 75 × (t_load + t_delay), where t_delay = 30 ms (zachardkozheno in setTimeout).

With t_load ≈ 5 ms, the result is 75x35 = 2625 ms.

Optimization:

Reduce t_delay from 30 ms to 10 ms — T = 75 × 15 = 1125 ms.

Use Promise. all for parallel loading — but be careful, it may kill the rate limit API.

Use batch processing: upload 10 layers in parallel, then pause for 50 ms.

Bottleneck 2: applyChoropleth iterates through 90 countries in each iteration.

For each layer: 90 × find (90) = 8100 comparison operations. For 75 layers: 607,500 operations.

Optimization:

Use Map to map country names-O(1) instead of O (n).

Pre-create a lookup table {countryName → layer}.

Bottleneck 3: 6 marker layers × 180 markers = 1080 markers.

Each marker is a separate L. circleMarker with a popup handler.

Optimization:

Use L. MarkerClusterGroup for clustering — already enabled in index.html.

Limit the display to 500 markers (as in Event Map) — but for metrics, 1080 is enough.

Bottleneck 4: logger.js intercepts console. log.

Each console line is recorded in window. crucixLogger. logs, updates the UI panel, and saves it to localStorage.

With 75 layers × ~5 rows = 375 log entries. Each one is JSON. stringify + DOM update + localStorage.

Optimization:

Disable console. log interception in production: if (window. CrucixConfig?.debug). Now the logger always works.

Use debounce to update the log panel.

Store in localStorage not all 375 records, but only the last 100.

Bottleneck 5: copy-data.js with 75 data layers.

Collects 75x90 = 6750 rows of data + configuration + legend + DOM.

Optimization:

Serialize data without formatting (JSON instead of strings with padEnd).

Use Blob to build large strings (faster than concat).

## 26. safety
29.1. Content Security Policy (CSP)
Current status: CSP is not installed. This is acceptable for a local project, but it will be required for publishing on the Internet.

Recommended CSP for Metrics Map:

html
<meta http-equiv="Content-Security-Policy" content="
    default-src 'self';
    script-src 'self' 'unsafe-inline' https://unpkg.com https://cdnjs.cloudflare.com;
    style-src 'self' 'unsafe-inline' https://unpkg.com https://cdnjs.cloudflare.com;
    img-src 'self' data: https://*.tile.openstreetmap.org https://*.basemaps.cartocdn.com;
    font-src 'self';
    connect-src 'self' https://unpkg.com https://cdnjs.cloudflare.com;
    frame-ancestors 'none';
    base-uri 'self';
    form-action 'self';
">
What it allows:

default-src 'self' — all resources by default only from the same domain.

script-src — local scripts + Leaflet CDN.

style-src — local CSS + inline styles (needed for dynamic legend) + CDN.

img-src — local images, data: URIs, OpenStreetMap tiles.

connect-src-fetch only to the same domain and CDN.

What prohibits:

Loading scripts from custom domains.

Insert via <iframe> (frame-ancestors 'none').

Sending forms to external servers (form-action 'self').

Application: insert <meta> in the < head> of a file index.html.

29.2. XSS protection in popups
Threat: XSS (Cross-Site Scripting) - embedding malicious JavaScript through user data in popups.

Implementation points:

Popup for markers. Formed from feature.properties. label, feature.properties.region, and feature.properties.value. If the API returns label: '<script>alert(1)</script>' — the script is executed.

Popup for choropleth countries. Formed from feature.properties.name.

The CII panel. Formed from data.countries[].country.

The layers panel. Formed from layer.name, layer.id.

Current state: Data is inserted via innerHTML without escaping. This is a vulnerability.

The solution is the escapeHTML function:

javascript
function escapeHtml(str) {
    if (str == null) return '';
    return String(str)
        .replace(/&/g, '&amp;')
        .replace(/</g, '&lt;')
        .replace(/>/g, '&gt;')
        .replace(/"/g, '&quot;')
        .replace(/'/g, '&#39;');
}
Application:

In js/markers.js -popup for markers:

javascript
const popup = '<div>' +
    '<strong>' + escapeHtml(item.title || 'Event') + '</strong><br>' +
    '' + escapeHtml(item.status || '—') + '' +
    '<div>' + escapeHtml(item.countryName || '—') + '</div>' +
    '</div>';
In js / map-controls.js-popup for countries:

javascript
layer.bindPopup('<strong>' + escapeHtml(nameRu) + '</strong><br>' +
                '' + escapeHtml(statusText) + '');
In js/cii.js-CII panel:

javascript
'<span class="cii-name">' + escapeHtml(c.country) + '' +
'<span class="cii-score">' + escapeHtml(String(c.score)) + ''
In js/layers.js -layers panel:

javascript
btn.innerHTML = '<span class="name">' + escapeHtml(layer.name) + '';
Criterion: No custom string is inserted into the DOM without escapeHTML().

29.3. Protection against prototype pollution
Threat: If the API returns JSON with the __proto__ field, the prototype may be contaminated.

Solution: use Object. create (null) instead of {} for objects filled in from data:

javascript
const lookup = Object.create(null);
Application: in map-controls.js when building currentChoroplethData, in the series-adapter.js when building features.

29.4. Protection against open redirect
Threat: If the user passes the ?redirect=... parameter, the attacker can redirect to another site.

Current state: Navigation between maps uses hard-wired <a href= " ../event-map/">. URL parameters are not passed. There is no vulnerability.

Recommendation: if query parameters appear in the future, validate them using the domain whitelist.

29.5. localStorage Protection
Threat: localStorage is readable by any script on the same domain. You can't store tokens.

Current usage:

crucix-lang-language ('ru'/'en'). It's no secret.

crucix-active-layer-ID of the active layer. It's no secret.

crucix-refresh-interval — the refresh interval. It's no secret.

crucix-logs — logs (up to 100 entries). They may contain sensitive data (URLs, API responses).

Recommendation: when publishing on the Internet — clear logs when exiting, do not store URLs with parameters.

29.6. Protection against CORS issues
Current state: fetch to /api/layers/... — same-origin. CORS is not involved.

When integrating with external APIs: the server must return Access-Control-Allow-Origin for the desired domain.

Recommendation: do not make a fetch directly to external APIs from the browser — only through a server proxy (rule # 16 about the bucket).

29.7. Security of fetch requests
Fetch points:

javascript
// js/map-controls.js
await fetch('data/world.geojson'); / / local, safe

// js/cii.js
await fetch ('/api/cii-api'); / / same-origin, safe

// js/metrics-map.js
await fetch(`/api/layers/${layerId}`); // same-origin, safe
All fetch — same-origin. The only exception is OpenStreetMap tiles via Leaflet (loaded as <img>, CSP does not block).

29.8. Validation of input data
layerId: check that it contains only [a-z0-9 -]:

javascript
if (!/^[a-z0-9-]+$/.test(layerId)) {
    console.warn('Invalid layerId:', layerId);
    return;
}
Coordinates: check that lat ∈ [-90, 90], lng ∈ [-180, 180].

Indicator values: check that the number, not NaN, is within reasonable limits.

29.9. CSP-Dynamic style compatibility
Problem: legend in map-controls.js sets the style.background via JavaScript — this is acceptable for CSP.

No problem: inline style="... "in HTML-allowed via' unsafe-inline ' in CSP.

Recommendation: if you tighten CSP by removing 'unsafe-inline', you will need to change dynamic styles to CSS classes.

## 27. GLOSSARY
30.1. Basic terms
API (Application Programming Interface) — a programming interface that allows one module to receive data from another. In Metrics, Map: /api/layers/<id> returns data for a specific layer.

Bulkhead Pattern — an isolation principle in which a failure in one component does not spread to others. In Crucix: 5 offline maps, failure domain = 1.

Choropleth-a visualization method where regions (countries) are colored depending on the indicator value. The main display type is Metrics Map.

Choropleth-legend-a UI block that shows class thresholds, palette, classification method, and quality (GVF).

ColorBrewer is a system of Cindy Brewer palettes optimized for perception. Includes sequential and diverging schemes.

CII (Country Instability Index) — country Instability Index. Calculated as a weighted function of country statuses (critical → 100, normal → 10).

Column-oriented data-organizing data by columns, used in LAYER_CLASSIFICATION.

Cross-map dependency — a link from one map file to another map file via ../other-map/. Prohibited by the R1 rule.

DAG (Directed Acyclic Graph) — directed acyclic graph. Used to describe the order in which scripts are loaded: each script depends on the previous ones, but there are no loops.

Diverging (Divergent palette) — a color scheme where the extreme values of different characters (for example, -10 and +10) are colored in contrasting colors (red ↔ blue), and the middle — in neutral. Used for indicators with domain zero (PMI 50, spreads).

escapeHTML-function for escaping HTML characters (<, >, &, ", '). Protects against XSS.

Failure domain — multiple components affected by a single failure. In Crucix: failure domain = 1 (failure in one map does not affect others).

Fallback — a fallback mechanism when the main data source is unavailable. In Metrics Map: with the 404 API, data is generated locally.

Fresh-data — data received in the current session without a cache.

GVF (Goodness of Variance Fit) - a quality metric for the Jenks classification. The formula is: GVF = (SDAM-SDCM) / SDAM, where SDAM is the sum of squared deviations from the mean, and SDCM is the sum of squared deviations within classes. Domain: 0-1, > 0.7 — good.

Hue (Hue) — color coordinate (red, blue). In Metrics, Map is only used as an auxiliary channel.

Jenks (The Jenks Method — is a natural discontinuity algorithm for classifying data. Minimizes SDCM, complexity O(k·n2). Developed by George Jenks in 1963.

Layer — one indicator in the Metrics Map. Example: pmi, inflation, copper-gold. There are 75 layers in total.

Leaflet is a JavaScript library for interactive maps. Used in 4 out of 5 Crucix maps (except Network Map).

Manual breaks — classification thresholds set by the expert. Example: PMI [42, 47, 53, 58], where 50 is the ISM domain threshold.

MAP_TYPES-configuration of map types in maps-config.js. Defines which layer categories belong to the Metrics Map.

Marker — a placemark on the map. Metrics Map is used for 6 layers (vix-futures, insider-trading, etc.).

manifest.json passport of the card. Contains: mapType, version, number of layers, and autonomy status.

Munzner 2014-Tamara Munzner's academic paper "Visualization Analysis and Design". Defines the perception channels and their separability.

Node.js — the JavaScript runtime environment outside the browser.

Opacity — alpha channel, value from 0 (fully transparent) to 1 (fully opaque). Used in Forecast Map to encode model confidence.

PWA (Progressive Web App) — an offline web application. Possible expansion in the future.

Quantile-a classification method where classes contain an equal number of observations.

R1–R6 — rules for map autonomy (see AUTONOMY-CHARTER.md).

Saturation — the color coordinate. In Metrics Map — via the ColorBrewer palette.

SDAM (Sum of Deviations from the Array Mean) — sum of squared deviations from the mean.

SDCM (Sum of Deviations from Class Means) — sum of squared deviations within classes.

Sequential (Sequential palette) — a color scheme with a gradual change from light to dark. Used for indicators without a domain zero (inflation, unemployment).

Series — a type of layer where data comes as a time series of a single indicator (for example, the US PMI), rather than a distribution by country. Converted to choropleth via series-adapter.js.

SeriesAdapter-transformation module series → choropleth. Uses spatial proxy and transformations.

Spatial proxy — a map of weights that distributes the global indicator by country. Example: for pmi — all_countries (all countries are equal), for ovx — oil_producers (weights depend on oil production).

SSI (Strategic Stress Index) — an index of strategic tension. In Metrics Map = 42%.

Toggle-a mechanism for switching the layer on / off when it is clicked again.

VizType — layer property: choropleth, series, marker. Defines how the layer is displayed on the map.

window. CrucixMap — a global object declared in the first inline script. Contains mapType and name.

XSS (Cross-Site Scripting) is an attack in which an attacker injects JavaScript through the data displayed on the page.

## 5. DATA FLOW: CLICK ON THE LAYER BUTTON

# # # 5.1. Sequence

The user clicks on the " PMI " button.

1. **`layers.js`** → `btn.onclick = () => loadLayer('pmi')`.
2. **`loadLayer('pmi')`** — проверяет `activeLayerIds.has('pmi')`.
 - If yes → toggle-off: removes from the set, removes the `.active 'class, cleans 'activeLayers', updates markers.
 - If not - > adds to `activeLayerIds', calls 'MetricsMap.interceptLoad'.
3. ** ' MetricsMap.interceptLoad ('pmi')`** - searches for a layer in `allLayers`, reads 'vizType'.
   - `choropleth` → `loadChoroplethLayer`
   - `series` → `loadSeriesLayer`
   - `marker` → `loadMarkerLayer`
4. **`loadChoroplethLayer('pmi')`**:
   - Вызывает `fetchWithTimeout('/api/layers/pmi/featurecollection', 8000)`.
 - If` resp.ok `and` data.features.length > 0 '— passes to 'applyChoropleth`, writes to' layerCache ['pmi'] = data.features`.
   - Если 404 или timeout (`signal is aborted without reason`) — `renderFallback(layer)`.
5. **`renderFallback('pmi')`**:
 - Takes `ALL_COUNTRIES[90]`, generates a value for each country ` ' base(status) + noise(seed('pmi'), i)`.
 - Classifies: if 'config. method = = = 'manual' - uses 'config.manualBreaks', otherwise `jenksBreaks(values, 5)`.
   - Вызывает `applyChoropleth({features, breaks, palette, method, gvf:0.85}, {...})`.
 - Writes ' layerCache ['pmi'] = features` (flat array).
6. **`map-controls.js` → `applyChoropleth(data, layer)`**:
   - Читает `window.MetricsMapConfig.getLayerConfig('pmi')` → `{method, palette, manualBreaks, numClasses}`.
 - Retrieves `values 'from `data. features'.
 - Classifies: 'classifyValues(values, method, numClasses, manualBreaks)` → `breaks`.
 - Counts ' computeGVF(values, breaks)` → `gvf`.
 - Saves in 'currentChoroplethConfig' and 'window.currentChoroplethConfig':
     `{method, palette, numClasses, breaks, gvf, stats: {count, min, max, mean}, layerId, layerName}`.
 - Iterates through 'currentGeoJsonLayer. eachLayer`, searches for each country in `data.features` by name (Russian or English), sets the color via' getColorForValue(value, breaks, palette)`.
 - Calls ' renderChoroplethLegend(breaks, config, gvf)`.
7. **`layers.js ' → ' loadLayer ('pmi')`* * continues:
 - 'updateActiveCount () — - the counter in `#active-layers-count`.
 - 'updateLegend()` — SSI legend.
   - `localStorage.setItem('crucix-active-layer', 'pmi')`.

## 6. CHIEF ORCHESTRATOR — `metrics-map.js ' v1. 4

### 6.1. Methods

| Method | What it does |
|-------|-----------|
| 'init()` | Idempotent initialization, distribution log by vizType |
| `fetchWithTimeout(url, ms = 8000)'/Fetch with AbortController, timeout 8 sec |
| `interceptLoad(layerId, markerAccumulator)` | Decision tree по `vizType` |
| `loadSeriesLayer(layer)` | Fetch → `SeriesAdapter.convert` → `applyChoropleth` |
| `loadChoroplethLayer(layer)` | Fetch → `applyChoropleth` |
| `loadMarkerLayer(layer, markerAccumulator)` | Fetch → `renderMarkerFallback` |
| `renderFallback(layer)` | Local generation of 90 countries |
| `renderMarkerFallback(layer, markerAccumulator)` | Local generation of 180 markers |
| `resolveApiUrl(layerId)` | Routes map for 14 series layers |
| 'stats()` | Summary by vizType |

### 6.2 ` ' fetchWithTimeout — - critical element

* * Issue (v1. 2 and earlier):** 'await fetch (url)' * * hangs indefinitely** if the server is silent. Chrome doesn't throw an error after N seconds. Only if the TCP connection is terminated. Because of this, `enableAllLayers` ended in the middle.

* * Solution (v1. 3+):** `AbortController` + `setTimeout(controller.abort, ms)`. After `ms` milliseconds, fetch throws ' DOMException: signal is aborted without reason`. 'catch' in`loadChoroplethLayer`/`loadSeriesLayer`/` loadMarkerLayer 'intercepts and calls `renderFallback' /`renderMarkerFallback`.

* * Version v1. 4 * * optional * * eliminates duplicate** 'fetchWithTimeout' (in v1. 3 it was defined twice in a row-an artifact of applying the patch).

### 6.3 ` ' markerAccumulator — - preparing for concurrency

`renderMarkerFallback(layer, markerAccumulator)`:
- If 'markerAccumulator' is passed-markers are written **to it**, `window.markerData ' **is not touched**.
- If not passed — the old path: 'window.markerData = window. markerData. concat(markers)`.

**Why:** when loading 5 marker layers in parallel (for example, 'vix-futures` `' cftc-cot`, 'insider-trading`,` sec-filings`,` short-interest')** simultaneously * * do 'read → concat → write' in ' window.markerData`. This is * * race condition** (lost update): the first wrote 180 markers, the second reads an outdated array, loses 180 from the first.

* * Solution:** coordinator `enableAllLayers ' (in a future version v1.5) creates * * one* * `markerAccumulator', passes it to all 5 parallel calls, after` Promise.all ` — merge in` window.markerData ' **atomically**.

Compatibility check :

## 7. layers.js v1. 4-UNIFIED enableAllLayers
7.1. Purpose
Upload all 75 layers to layerCache, mark them as active, and display the latest choropleth.

7.2. Architectural principles
Direct call to MetricsMap.interceptLoad(layer.id) - not via loadLayer. Reason: loadLayer has toggle logic (checks activeLayerIds.has(layerId)). If the layer is there, it turns it off. This is not true for batch downloads.

Block for jamming visualizations. For the duration of the cycle:

window.applyChoropleth = no-op

window.updateMarkers = no-op

window.renderLayerPanel = no-op

Reason: Without jamming, each of the 75 layers would redraw the map (75 × 200 ms = 15 sec) and the layers panel (75 × 50 ms = 3.75 sec). Total — +20 seconds.

Critical: Disabled applyChoropleth — full no-op. It doesn't write to layerCache. The cache only fills the renderFallback inside interceptLoad.

Cache — flat arrays. Array.isArray(layerCache[id] — - invariant.

The final render is the last choropleth. After the loop, we search from the end of allLayers for the first choropleth with data in the cache. This is usually mobile (the last layer by number). Calling the saved origApplyChoropleth({features: cached}, layer).

7.3. Re-entrancy guard
javascript
if (window._enableAllInProgress) return;
window._enableAllInProgress = true;
// ...
window. _enableAllInProgress = false; // at the end
When trying to run in parallel — the second call is canceled.

7.4. await Promise. resolve () instead of setTimeout(30)
It was (v1. 0–v1.3): await new Promise(r => setTimeout(r, 30)). Problem: in the background tab of Chrome, trottlits setTimeout to 1000 ms. 75 × 1000 = 75 sec, instead of the expected 2.5 sec.

Now (v1. 4): await Promise. resolve (). Microtask will not be trottled. Event loop handles the pause, but the loop doesn't slow down.

## 12. KNOWN RAKES AND SOLUTIONS
12.1. await fetch (url) without timeout-hangs
Symptom: enableAllLayers breaks off in the middle. Logs end with N / 75: <id> without the final line.

Reason: a layer where the server is silent (not 404, but no response). Chrome doesn't throw an error.

Solution: fetchWithTimeout (url, 8000) via AbortController. Layers with a timeout go into fallback.

History: first diagnosed on 28.09.2026, applied in metrics-map.js v1. 3.

12.2. Duplicate fetchWithTimeout
Symptom: grep-c "fetchWithTimeout:" returns 2.

Reason: applying patch to patch — the second definition was inserted on top of the first one.

Solution: v1. 4 is the only definition.

History: discovered on 29.09.2026. It didn't have any functional impact (the last definition wins), but it violated rule # 36.

12.3. Race condition in markerData for concurrency
Symptom (potential): when loading 5 marker layers in parallel, markers are lost.

Reason: read → concat → write without blocking.

Solution: markerAccumulator in renderMarkerFallback. Done in v1. 4, will be activated in v1. 5 layers.js.

History: the groundwork was laid on 29.09.2026.

12.4. Toggle-loadLayer logic in enableAllLayers
Symptom: enableAllLayers disables layers instead of loading them.

Reason: loadLayer when activeLayerIds.has(layerId) goes toggle-off. If all layers are already in the set at the beginning of the loop, the loop turns them off.

Solution: In v1.4, enableAllLayers calls interceptLoad directly, bypassing loadLayer. Plus-force activeLayerIds. delete (layerId) before uploading.

History: v1. 1 first fix, v1.4 final.

12.5. setTimeout(30) in the background tab
Symptom: enableAllLayers takes 75 seconds instead of 2.5.

Reason: Chrome throttles setTimeout to 1000 ms in the background tab.

Solution: await Promise.resolve () instead of setTimeout. Microtask is not throttled.

History: v1. 2.

12.6. Parallel loadLayer calls from init.js
Symptom: after F5, the layerCache composition is strange — allLayers are out of order.

Reason: init.js v1. 0 called loadLayer(saved) from localStorage after 2 seconds. The second thread wrote to layerCache in parallel.

Solution: init.js v1. 1 — the block was deleted.

History: 29.09.2026.

12.7. Offset of activeLayerIds when toggling
Symptom: after enableAllLayers, all 76 buttons are active, but when you click on any of them, the layer turns off, not on.

Reason: correct toggle behavior. If the layer is already active, a second click disables it.

Solution: not a bug, but a feature. To reload a single layer — first turn it off, then turn it on.

12.8. currentChoroplethConfig is not available from copy-data.js
Symptom: the "CHOROPLETH-PARAMETERS" section in the snapshot is empty.

Reason: map-controls.js v4. 0 stored currentChoroplethConfig as a local variable of the module, did not export it to window.

Solution: v4. 1-added window.currentChoroplethConfig = config and window.currentChoroplethData = data.

History: 28.09.2026.
