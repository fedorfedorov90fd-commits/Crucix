# Indicator Template Module

## 📋 Описание
**Русский:**
Модуль **Indicator Template** предоставляет шаблоны для создания новых индикаторов в Crucix. Позволяет быстро настраивать отображение данных, графики и дашборды без программирования.

**English:**
The **Indicator Template** module provides templates for creating new indicators in Crucix. Allows quick configuration of data display, charts and dashboards without programming.

## 🎯 Назначение
- Шаблоны индикаторов
- Быстрая настройка
- Кастомизация дашбордов

## 🚀 Использование
1. Страница: `/indicator-template`
2. API: `/api/indicator-template`
3. Параметры: `?template=economic&type=chart`
