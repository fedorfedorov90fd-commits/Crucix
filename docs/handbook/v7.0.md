**Версия:** 7.0.0
**Расположение:** apis/predict/v7/
**Назначение:** пять модулей, дающих системе способность «воображать» будущее, работать в непрерывном времени и делать counterfactual-анализ.

## 1. World Model

**Файл:** apis/predict/v7/world_model.mjs
**Строк:** ~1182
**Экспорт:** WorldModel, VAE, MDNRNN, Controller, crucixWorldModel

### Задача

Агент учится «воображать» будущее в сжатом латентном пространстве. Не нужно ждать реальных данных — можно развернуть симуляцию на N шагов вперёд.

### Три компонента

1. **VAE (Variational Autoencoder)**:
   - Encoder: x (11 признаков) → h (hiddenDim) → (mu, logvar) → z (latentDim)
   - Decoder: z → h → x_hat
   - Reparameterization: z = mu + exp(0.5·logvar)·epsilon
   - Option deterministic=true для gradient evaluation

2. **MDN-RNN** (Mixture Density Network RNN):
   - LSTM cell с gates i/f/o/g
   - MDN head: h → (pi, mu, sigma) — смесь K гауссов на каждый latent dim
   - P(z_{t+1} | h_t) = sum_k pi_k · N(mu_k, sigma_k^2)

3. **Controller** — линейная политика a = tanh(W·[z;h] + b)

### Imagination

Функция imagine(z0, horizon) разворачивает N шагов:
1. Controller выбирает action.
2. RNN forward: sample z_{t+1} из mixture.
3. Сохраняем (z_t, a_t, z_{t+1}, h_t).

### Выход

crucixWorldModel(history) возвращает: training (vae metrics, rnnTrained), quality (avgReconError, reconQuality), imagination (trajectory, trend, imaginedFeatures), direction (escalation/deescalation/stable).

## 2. Neural ODE

**Файл:** apis/predict/v7/neural_ode.mjs
**Строк:** ~729
**Экспорт:** NeuralODEFunc, NeuralODETrainer, rk4Solve, counterfactual, rewind, escalationRate, crucixNeuralODE

### Задача

Вместо дискретной последовательности z_{t+1} = f(z_t) — непрерывная динамика dz/dt = f_theta(z, t). Состояние определено для любого t, не только на сетке sweep'ов.

### Метод

1. **NeuralODEFunc** — MLP, параметризующий dz/dt = f_theta(z, t).
2. **RK4 solver** — метод Рунге-Кутты 4-го порядка. Точность ~1e-4 при 100 шагах на интервале длиной 1.
3. **NeuralODETrainer** — обучение через finite differences (вместо полного adjoint method Chen 2018).

### Counterfactual

- **counterfactual(f, z0, intervention)** — сравнение с вмешательством.
- **rewind(f, z0, stepsBack)** — решить ODE назад во времени (t < 0).
- **escalationRate(f, trajectory)** — скорость |dz/dt| в каждой точке.

### Выход

crucixNeuralODE(history) возвращает: training (lossBefore, lossAfter, lossReduction), forecast (trajectory, trend, direction, initialRate, finalRate), counterfactual, rewind.

## 3. Dreamer

**Файл:** apis/predict/v7/dreamer.mjs
**Строк:** ~838
**Экспорт:** Dreamer, Actor, Critic, computeReward, crucixDreamer

### Задача

Actor-Critic обучение полностью в latent space через imagination World Model. Никаких реальных взаимодействий — всё внутри «сна».

### Три компонента

1. **Actor** — политика pi(a|z), softmax over actions.
2. **Critic** — value V(z), MLP.
3. **Dreamer** — оркестратор:
   - rollout(z0) → траектория через world_model
   - computeLambdaReturns(trajectory) — TD(lambda)
   - trainStep: actor update с advantage, critic update с MSE
   - normalizeReturns — критично для сходимости

### Reward

computeReward(decoded, prevDecoded):
- -2·tension - 1·vix - 1.5·conflicts - 0.5·sanctions
- Штраф за рост (dTension, dConflicts)

### Выход

crucixDreamer(history) возвращает: evaluation (before/after meanReturn, improvement), bestAction (name + actionDistribution), finalRollout, training metrics.

### Замечание

На синтетике за 10-15 шагов политика почти не улучшается — это ожидаемо. Hafner обучает DreamerV3 на 100k+ шагов. Для production нужны большие эпизоды.

## 4. Continuous Causal

**Файл:** apis/predict/v7/continuous_causal.mjs
**Строк:** ~755
**Экспорт:** CausalDAG, ContinuousSCM, crucixContinuousCausal

### Задача

Синтез Neural ODE (B2) + причинного вывода (Pearl). Динамика не просто непрерывная — она подчинена причинной структуре. Counterfactual через do-operator.

### Структурное уравнение

    dz_i/dt = f_i( {z_j : j ∈ parents(i)}, t ) + epsilon_i

Родители определяются из DAG. Do-operator: зафиксировать z_j = value на [t0, t1], разорвав входящие стрелки.

### Два ключевых компонента

1. **CausalDAG**:
   - parents/children/descendants/ancestors
   - topologicalOrder
   - **induceFromData** — через lag-correlation + time-precedence

2. **ContinuousSCM**:
   - initFunctions: per-node MLP
   - forward: динамика только от parents
   - solve: RK4 с intervention
   - counterfactual: baseline vs intervention
   - estimateATE: Average Treatment Effect

### Важное открытие

Для observational данных направление причинности без времени определить НЕЛЬЗЯ. Поэтому induceFromData использует **time-precedence**: ребро i→j только если max_lag corr(x_i[t], x_j[t+lag]) > обратного.

### Выход

crucixContinuousCausal(history) возвращает: dag (nodes, edges, topologicalOrder), training (lossBefore, lossAfter), forecast (trajectory, trend, direction), counterfactual, ate (perVar с ate/std/sign).

## 5. Simulation Engine

**Файл:** apis/predict/v7/simulation_engine.mjs
**Строк:** ~523
**Экспорт:** crucixSimulationEngine, synthesize, extractDirections, consensusDirection, answerQuestions

### Задача

Оркестратор: запускает все 4 модуля и синтезирует результат. Отвечает на вопросы оператора.

### Синтез

extractDirections(v7Results) — извлекает направление из каждого модуля:
- world_model → direction (escalation/deescalation/stable)
- neural_ode → знак trend.tension.delta
- dreamer → bestAction → интерпретация
- continuous_causal → forecast.direction

consensusDirection — доминирующее направление + agreement (доля согласных).

Confidence = 0.7·agreement + 0.3·coverage:
- agreement — доля модулей с одним направлением
- coverage — доля активных модулей от 4

### Q&A

answerQuestions генерирует ответы на 5 предопределённых вопросов:
1. Что будет через N часов?
2. Как быстро меняется состояние?
3. Что если ввести санкции?
4. Какое действие оптимально?
5. Какие переменные — настоящие причины?

Каждый ответ включает confidence (high/moderate/low) и source (какой модуль).

### Выход

crucixSimulationEngine(history) возвращает: moduleStatus, activeModules/totalModules, synthesis (consensus, confidence, reasoningSteps), answers, results (сырые результаты 4 модулей), interpretation.

## Интеграция в engine

Фаза U в engine_v7_patch.mjs.

### API

    import { runV7Phase, applyV7ToSnapshot } from './engine_v7_patch.mjs';
    const v7Phase = await runV7Phase(history, {
      horizon: 12,
      modules: {
        worldModel: { vaeEpochs: 3, rnnEpochs: 2, latentDim: 8, hiddenDim: 16 },
        neuralODE: { epochs: 3, hiddenDim: 16 },
        dreamer: { trainSteps: 10, horizon: 8 },
        continuousCausal: { epochs: 3, hiddenDim: 16 },
      },
    });

### Timeout

180 секунд (4 модуля последовательно). Circuit breaker 3 падения → 5 пропусков.

### Расширение snapshot

applyV7ToSnapshot(snapshot, v7Phase) добавляет:
- snapshot.v7_extensions.synthesis
- snapshot.v7_extensions.answers
- snapshot.explanation.reasoning_steps — шаги от v7
- snapshot.explanation.summary — дополняется сводкой v7
