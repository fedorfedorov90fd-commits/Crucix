# Crypto Fear Module

## 📋 Описание
**Русский:**
Модуль **Crypto Fear** отслеживает индекс страха и жадности на криптовалютном рынке. Показывает настроения инвесторов на основе волатильности, объёмов, соцсетей и доминирования BTC. Используется для оценки рыночных настроений.

**English:**
The **Crypto Fear** module tracks the Fear and Greed Index for the crypto market. Shows investor sentiment based on volatility, volumes, social media and BTC dominance. Used for market sentiment assessment.

## 🎯 Назначение
- Оценка настроений на крипторынке
- Торговые сигналы
- Индикатор перегретости

## 🚀 Использование
1. Страница: `/crypto-fear`
2. API: `/api/crypto-fear`
3. Параметры: `?interval=30d`
