# Глава 11. Теория информации

Информационная теория (Shannon, 1948) — язык, на котором описываются зависимости между сигналами. Это фундамент для причинного анализа.

Crucix использует пять методов:

1. Transfer Entropy — направленная причинность
2. KL divergence — различие распределений
3. Fisher information — чувствительность параметров
4. Wasserstein distance — оптимальный транспорт
5. Renyi divergence — обобщение KL

## 11.1 Transfer Entropy

### Теория

Schreiber (2000). Направленная причинность через информацию:

TE(X->Y) = sum p(y_{t+1}, y_t, x_t) * log2 [ p(y_{t+1} | y_t, x_t) / p(y_{t+1} | y_t) ]

Интерпретация: сколько информации прошлое X добавляет к предсказанию Y, сверх того, что даёт прошлое Y.

Свойства:
- TE(X->Y) не равно TE(Y->X) — направленность
- TE(X->Y) = 0 — X не помогает предсказывать Y
- TE(X->Y) > 0 — X полезен для прогноза Y

### Применение в Crucix

Из истории строим причинный граф: какие метрики влияют на какие.

### Что это даёт

Направленный граф причинности:

conflict_count -> VIX: TE = 0.18
VIX -> hy_spread: TE = 0.22
VIX -> conflict_count: TE = 0.04

Это данные, а не экспертные догадки. Композитный граф causal в Crucix строится автоматически из TE.

Правило: если TE(A->B) > TE(B->A), значит A причинно влияет на B.

## 11.2 KL divergence

### Теория

Kullback-Leibler (1951):

D_KL(P || Q) = sum P(i) * log(P(i) / Q(i))

Свойства:
- D_KL(P || Q) >= 0
- D_KL(P || Q) = 0 iff P = Q
- Не симметрична: D_KL(P || Q) не равно D_KL(Q || P)

### Применение в Crucix

Сравнение распределения VIX в разные эпохи.

### Что это даёт

JS-divergence (Jensen-Shannon) — симметричная версия:

- JS < 0.03 — распределение стабильно
- JS 0.03-0.1 — умеренный сдвиг
- JS > 0.1 — существенный сдвиг режима

Правило: JS > 0.1 — это смена режима, не шум. Система работает по-новому.

## 11.3 Fisher Information

### Теория

Fisher (1925):

I(theta) = E[(d log p(x | theta) / d theta)^2]

Свойства:
- Мера чувствительности распределения к параметру
- Обратная к дисперсии оценки (Cramer-Rao bound): Var(theta_hat) >= 1/I(theta)

### Применение в Crucix

Оценка уверенности в параметре модели.

### Что это даёт

Для нормального распределения:

- При sigma = 1: I(mu) = 1, Var(mu_hat) >= 1
- При sigma = 2: I(mu) = 0.25, Var(mu_hat) >= 4

Чем больше sigma (волатильность), тем меньше информации о среднем. Это фундаментальный предел прогноза.

Правило: если Cramer-Rao bound для VIX > 5, прогноз бессмысленен.

## 11.4 Wasserstein Distance

### Теория

Villani (2003). Оптимальный транспорт:

W_p(P, Q) = (inf int |x - y|^p d_gamma(x, y))^(1/p)

где инфимум по всем связкам gamma с маргиналами P и Q.

Интуиция: сколько работы нужно, чтобы переделать распределение P в Q.

Свойства:
- Симметрично
- Учитывает геометрию распределений (KL — нет)
- W_1 (Earth Mover's Distance) — самый распространённый

### Применение в Crucix

Сравнение сдвига распределений VIX.

### Что это даёт

W_1 divergence в единицах измерения:

W_1 = 2 для VIX — распределение сдвинулось на 2 пункта
Нормированное: W_1 / std — на сколько сигм сдвинулось

Правило: W_1 / std > 0.5 — существенный сдвиг. Режим изменился.

## 11.5 Renyi Divergence

### Теория

Renyi (1961) — обобщение KL с параметром alpha:

D_alpha(P || Q) = 1/(alpha-1) * log sum P(i)^alpha * Q(i)^(1-alpha)

Свойства:
- alpha -> 1: сходится к KL
- alpha = 2: квадратичная дивергенция
- alpha -> inf: максимальное отклонение

### Применение в Crucix

Более чувствительна к хвостам, чем KL.

### Что это даёт

alpha = 2 — обнаруживает изменения в хвостах, которые KL может пропустить.

Правило: если Renyi_2 > 2 * KL, значит изменение в хвостах — готовьтесь к экстремальным событиям.

## 11.6 Итог

| Метод | Что показывает | Когда критично |
|-------|----------------|----------------|
| Transfer Entropy | Направленная причинность | TE(A->B) >> TE(B->A) |
| KL / JS | Различие распределений | JS > 0.1 |
| Fisher | Чувствительность параметра | CR bound > 5 |
| Wasserstein | Оптимальный транспорт | W1/std > 0.5 |
| Renyi | Хвостовое различие | Renyi2 > 2*KL |

Композитная логика: когда несколько информационных метрик одновременно показывают сдвиг — система переходит в новый режим.

Правило: 3+ информационных метрик в критической зоне — сигнал о смене режима.
