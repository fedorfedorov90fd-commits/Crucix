# Lenses Module

## 📋 Описание
**Русский:**
Модуль **Lenses** предоставляет тематические "линзы" для фильтрации и отображения данных по определённым темам: экономика, безопасность, энергетика, экология. Позволяет быстро переключать контекст анализа.

**English:**
The **Lenses** module provides thematic "lenses" for filtering and displaying data by specific topics: economy, security, energy, ecology. Allows quick context switching in analysis.

## 🎯 Назначение
- Тематическая фильтрация
- Быстрый контекстный анализ
- Настройка отображения

## 🚀 Использование
1. Страница: `/lenses`
2. API: `/api/lenses`
3. Параметры: `?lens=security&region=Europe`
