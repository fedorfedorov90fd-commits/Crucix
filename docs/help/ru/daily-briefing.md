# Daily Briefing Module

## 📋 Описание
**Русский:**
Модуль **Daily Briefing** генерирует ежедневную аналитическую сводку по ключевым индикаторам: геополитика, экономика, энергетика, безопасность. Объединяет данные со всех сборщиков в единый отчёт с графиками и выводами.

**English:**
The **Daily Briefing** module generates a daily analytical summary of key indicators: geopolitics, economy, energy, security. Combines data from all collectors into a single report with charts and conclusions.

## 🎯 Назначение
- Ежедневный мониторинг
- Резюмирование ключевых событий
- Подготовка отчётов

## 🚀 Использование
1. Страница: `/daily-briefing`
2. API: `/api/daily-briefing`
3. Параметры: `?date=2026-09-02`
