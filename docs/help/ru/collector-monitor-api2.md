# collector-monitor-api2 API Module

## 📋 Описание
**Русский:**
API-модуль **collector-monitor-api2** предоставляет REST API для работы с данными в системе Crucix.

## 🎯 Назначение
- Обработка API-запросов
- Валидация данных
- Формирование ответов

## 🚀 Использование
- GET `/api/collector-monitor-api2` — получить данные
- POST `/api/collector-monitor-api2` — создать запись
- PUT `/api/collector-monitor-api2/:id` — обновить запись
- DELETE `/api/collector-monitor-api2/:id` — удалить запись
