# Scatter-график нарративов: narrative-scatter.js

## Простое объяснение (для новичков)

Этот файл — «карта смыслов». Он рисует точки в двумерном пространстве: по горизонтали — западный охват темы, по вертикали — российский. Каждая точка — это тема.

**Как читать график:**

- **Точка в правом верхнем углу** — тему освещают обе стороны (много статей и у российских, и у западных).
- **Точка в левом верхнем углу** — тему освещают только российские источники.
- **Точка в правом нижнем углу** — только западные.
- **Точка на диагонали** — паритет: обе стороны пишут одинаково.

**Что делает модуль:**

1. **Запрашивает данные** у API `/api/layers/narrative-framing/topics?limit=50`.
2. **Строит SVG-график** с осями, сеткой, диагональю паритета.
3. **Рисует точки** — каждая тема как круг. Цвет — `severity` (красный/зелёный/оранжевый), размер — `total_events`.
4. **Добавляет подсказки** — при наведении на точку видно название темы и числа.

**Зачем это нужно:**

Вы сразу видите, где нарративы совпадают, а где — расходятся. Если тема «энергетика» — в левом верхнем углу (только российские), а «кибер» — на диагонали (обе стороны), это уже сигнал: одна тема активно освещается, другая — игнорируется.

**Аналогия:**

Это как карта звёздного неба. Точки — темы. Расстояние между ними — разница в нарративах. Если две точки рядом — нарративы похожи. Если далеко — расходятся.

## Научная база (для специалистов)

Виджет реализует **scatter plot** на SVG для визуализации двумерного пространства «западный охват × российский охват».

**Архитектура:**

- **Технология:** Vanilla JS, SVG. Без D3.js — для простоты и портативности.
- **Оси:** X — `western_count`, Y — `russian_count`.
- **Диагональ паритета:** линия `y = x`. Если точка выше диагонали — российский охват больше. Если ниже — западный.
- **Цвет точки:** `severity`. `high` — красный (`#ef4444`), `normal` — зелёный (`#4ade80`), `critical` — оранжевый (`#f59e0b`).
- **Размер точки:** `4 + min(total_events, 20) * 0.5`. Чем больше событий, тем крупнее точка. Ограничение сверху — 20, чтобы точки не перекрывались.

**Масштабирование:**

- `maxX = max(western_count)`, `maxY = max(russian_count)`.
- `maxN = max(maxX, maxY)` — единая шкала для обеих осей.
- `scaleX(x) = PAD + (x / maxN) * (W - PAD * 2)`.
- `scaleY(y) = H - PAD - (y / maxN) * (H - PAD * 2)`.

Это позволяет сравнивать темы с разным охватом на одном графике.

**Сетка:**

- Линии каждые `maxN / 5`. Помогают оценить масштаб.

**Формат данных:**

```json
{
  "topics": [
    {
      "topic": "энергетика",
      "name": "Энергетика",
      "russian_count": 40,
      "western_count": 2,
      "total_events": 45,
      "severity": "high"
    }
  ]
}

Ограничения:

    Для polarity нужны события с обеими группами. Если western_count = 0, точка уходит на ось Y (не видна на диагонали).

    reaction_gap (разница во времени) не отображается на scatter — только в таблице.

    На текущих данных (мало западных фидов) большинство точек — в левом верхнем углу.

Как работает (пошагово)

    При загрузке страницы (DOMContentLoaded) вызывается mountNarrativeScatter().

    mountNarrativeScatter() находит контейнер по id (по умолчанию 'narrative-scatter').

    Отправляет fetch('/api/layers/narrative-framing/topics?limit=50').

    Получает JSON, извлекает data.topics.

    Если массив пуст — показывает «Нет данных».

    Если не пуст — вычисляет maxN (максимум по обеим осям).

    Создаёт SVG с viewBox="0 0 600 500".

    Рисует сетку: линии каждые maxN / 5.

    Рисует диагональ паритета: пунктирная линия от (0, 0) до (maxN, maxN).

    Рисует оси с подписями: «Западный охват →» и «Российский охват ↑».

    Рисует точки: для каждой темы — круг с цветом и размером.

    Добавляет подсказки: <title> с названием темы и числами.

    Вставляет SVG в контейнер, применяет стили.

Структура SVG:
html

<svg viewBox="0 0 600 500">
  <!-- Сетка -->
  <line x1="..." y1="50" x2="..." y2="50" stroke="#1a1a2e" />
  <!-- Диагональ -->
  <line x1="50" y1="450" x2="550" y2="50" stroke="#fbbf24" stroke-dasharray="6,6" />
  <!-- Оси -->
  <text x="300" y="490">Западный охват →</text>
  <text x="15" y="250" transform="rotate(-90 15 250)">Российский охват ↑</text>
  <!-- Точки -->
  <circle cx="..." cy="..." r="8" fill="#ef4444">
    <title>энергетика: r=40 w=2 (high)</title>
  </circle>
</svg>

Практические рекомендации

    Единая шкала maxN — позволяет сравнивать темы с разным охватом. Не делайте отдельные шкалы для X и Y — это искажает картину.

    Диагональ паритета — визуальный ориентир. Если точка на диагонали — обе стороны пишут одинаково.

    Цвет точки — severity. Красный — high, зелёный — normal, оранжевый — critical. Интуитивно.

    Размер точки — total_events. Чем больше событий, тем крупнее точка. Не делайте слишком крупные — они перекрывают друг друга. Ограничение сверху — 20.

    limit=50 — максимум тем на графике. Больше — визуальный шум.

    Fallback на ошибки — если API недоступен, показывается сообщение. Страница не падает.

    Тёмная тема — background: #0d0d1a. Стандарт для профессиональных терминалов.

    Сетка — линии каждые maxN / 5. Помогают оценить масштаб.

    Оси с подписями — «Западный охват →» и «Российский охват ↑». Не забывайте подписи.

    viewBox — 0 0 600 500. Позволяет масштабировать SVG без потери качества.

    overflow: auto — если точек много, они могут выходить за пределы. Скролл спасает.

    Прозрачность точек — fill-opacity="0.6". Позволяет видеть перекрывающиеся точки.

    <title> — нативная HTML-подсказка. Работает во всех браузерах, не требует JS.
