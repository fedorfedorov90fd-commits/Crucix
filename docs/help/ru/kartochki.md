# Cards Module

## 📋 Описание
**Русский:**
Модуль **Cards** предоставляет универсальный интерфейс для отображения данных в виде карточек. Поддерживает различные типы контента: цифры, графики, тексты, изображения. Используется в дашбордах и отчётах.

**English:**
The **Cards** module provides a universal interface for displaying data as cards. Supports various content types: numbers, charts, text, images. Used in dashboards and reports.

## 🎯 Назначение
- Универсальные карточки
- Отображение данных
- Кастомизация контента

## 🚀 Использование
1. Страница: `/kartochki`
2. API: `/api/kartochki`
3. Параметры: `?type=metric&dataset=economy`
