# File Picker Module

## 📋 Описание
**Русский:**
Модуль **File Picker** предоставляет интерфейс для выбора и загрузки файлов в Crucix. Поддерживает CSV, JSON, Excel, изображения и другие форматы. Используется для импорта данных, загрузки отчётов и конфигураций.

**English:**
The **File Picker** module provides an interface for selecting and uploading files to Crucix. Supports CSV, JSON, Excel, images and other formats. Used for data import, report and configuration uploads.

## 🎯 Назначение
- Загрузка файлов
- Импорт данных
- Выбор конфигураций

## 🚀 Использование
1. Страница: `/file-picker`
2. API: `/api/file-picker`
3. Параметры: `?type=csv&upload=true`
