# 10. Дедупликатор

[← Назад к INDEX](./INDEX.md)

## Расположение

/home/ta8_/Рабочий стол/Crucix/apis/sources/smartscroll-local/processing/dedup.mjs

## Назначение

Трёхуровневая дедупликация событий.

## Класс

Deduplicator

## Уровни

1. Точный хеш контента. Заголовок плюс первые 500 символов тела.
2. Шинглы и Jaccard. Сравнение по 4-словным шинглам.
3. Levenshtein по заголовкам. Для коротких тел менее 200 символов.

## Метод

deduplicate(newEvents, existingEvents) — возвращает только уникальные события.

## Порог

По умолчанию 0.82. Настраивается в конфигурации.
