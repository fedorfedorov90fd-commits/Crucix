АРХИТЕКТУРА ПРОЕКТА: CRUCIX
Версия: 2.1

=== ПРИНЦИПЫ ===
1. ВСЕ модули работают локально
2. ВСЕ данные собираются из открытых источников
3. ВСЯ аналитика выполняется локально (Ollama) или через бесплатные API
4. Модули НЕ зависят друг от друга (слабая связанность)
5. Каждый модуль экспортирует единый интерфейс

=== СТРУКТУРА ===
apis/
├── sources/
│   ├── drivers/       # Драйверы источников (base, max, telegram)
│   ├── router.mjs     # Адаптивный шлюз
│   ├── ai-filter.mjs  # Интеллектуальный фильтр
│   └── *.mjs          # Источники данных

dashboard/
├── panels/            # Панели интерфейса
├── public/            # Статика
└── inject.mjs         # Регистрация панелей

scripts/
├── collect-feeds.mjs  # Сбор RSS
├── daily-report.mjs   # Отчёт с AI-фильтром
├── clean-old.mjs      # Очистка
├── coordinator.mjs    # Координатор
└── interactive.mjs    # Интерактивный координатор

PROJECT/               # Файлы состояния
data/                  # Данные
reports/               # Отчёты
logs/                  # Логи

=== КОНТРАКТЫ ===
1. Драйвер: fetch(), checkAvailability(), getDriverName()
2. Панель: render(), onAction()
3. Данные в корзине: { id, title, date, url, summary, source }

=== СТАНДАРТЫ ===
- ES Modules (import/export)
- fetch для HTTP-запросов
- Логи с префиксом [Модуль]
- Обработка ошибок через try/catch
