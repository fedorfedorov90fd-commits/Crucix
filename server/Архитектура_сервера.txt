1. ОБЩАЯ СТРУКТУРА


server.mjs                    — ТОЛЬКО ЗАПУСК (не трогать!)

├── server/modules.json       — Список всех модулей (176+)
├── server/pages.json         — Список всех страниц (209+)
├── server/routes-pages.json  — Маршруты страниц (путь → файл)
├── server/routes-api.json    — Маршруты API (путь → модуль)
├── server/loader.mjs         — Загрузчик модулей
├── server/router.mjs         — Роутер API (главный)
├── server/api.mjs            — Дополнительные API-обработчики
├── server/pages.mjs          — Управление страницами
└── server/static.mjs         — Раздача статики

2. ПОТОК ЗАПРОСА
================================================================================

ЗАПРОС → server.mjs
    │
    ├── /data/geo/ → отдаём GEOJSON
    │
    ├── /api/ → server/router.mjs → handleAPI()
    │   │
    │   ├── Находит маршрут в routes-api.json
    │   ├── Загружает обработчик из загруженных модулей
    │   └── Выполняет обработчик
    │
    ├── СТАТИКА → server/static.mjs → handleStatic()
    │   │
    │   ├── /geo-map/ → отдаём из public/
    │   ├── Страница из routes-pages.json → отдаём из public/
    │   ├── /css/, /js/, /images/, /fonts/ → отдаём из public/
    │   └── Прямой файл → отдаём из public/
    │
    └── 404 → generate404Page()

================================================================================
3. КЛЮЧЕВЫЕ КОМПОНЕНТЫ
================================================================================

3.1. config.mjs
    - PORT: 3117
    - MIME_TYPES: все поддерживаемые типы файлов

3.2. modules.json
    - 176+ модулей с путями
    - Формат: { "id": "имя", "path": "./apis/sources/..." }
    - Добавляй новые модули сюда!

3.3. routes-api.json
    - 250+ маршрутов API
    - Формат: "/api/путь": "id_модуля"
    - Добавляй новые маршруты сюда!

3.4. routes-pages.json
    - 209+ маршрутов страниц
    - Формат: "/путь": "файл.html"
    - Добавляй новые страницы сюда!

3.5. loader.mjs
    - Загружает все модули из modules.json
    - Создаёт заглушки для недоступных модулей
    - Возвращает объект handlers { id: handler }

3.6. router.mjs
    - Принимает pathname и handlers
    - Ищет совпадение в routes-api.json
    - Вызывает соответствующий обработчик

3.7. static.mjs
    - Раздаёт статику из public/
    - Поддерживает страницы, CSS, JS, изображения
    - Возвращает 404 при отсутствии

================================================================================
4. КАК ДОБАВЛЯТЬ НОВЫЕ КОМПОНЕНТЫ
================================================================================

4.1. НОВЫЙ МОДУЛЬ:
    1. Создать файл в ./apis/sources/
    2. Добавить запись в modules.json
    3. Добавить маршрут в routes-api.json

4.2. НОВАЯ СТРАНИЦА:
    1. Создать файл в ./dashboard/public/
    2. Добавить запись в pages.json
    3. Добавить маршрут в routes-pages.json

4.3. НОВОЕ API (простое):
    1. Добавить обработчик в существующий модуль
    2. Добавить маршрут в routes-api.json

4.4. НОВОЕ API (сложное):
    1. Создать новый модуль в ./apis/sources/
    2. Добавить в modules.json
    3. Добавить в routes-api.json
