# Jarvis Original Module

## 📋 Описание
**Русский:**
Модуль **Jarvis Original** является базовой версией AI-ассистента Jarvis с минимальной конфигурацией. Предоставляет основные функции общения, анализа данных и генерации отчётов без расширенных настроек.

**English:**
The **Jarvis Original** module is the base version of the Jarvis AI assistant with minimal configuration. Provides basic functions of conversation, data analysis and report generation without advanced settings.

## 🎯 Назначение
- Базовая версия Jarvis
- Простое общение с AI
- Генерация отчётов

## 🚀 Использование
1. Страница: `/jarvis-original`
2. API: `/api/jarvis-original`
3. Параметры: `?q=Анализ данных`
