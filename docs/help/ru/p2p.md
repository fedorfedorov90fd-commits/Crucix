# P2P — P2P-обмен и децентрализованные сети

## Что это

P2P-модуль отслеживает активность в децентрализованных сетях: BitTorrent, IPFS, Blockchain, DHT. Анализирует: количество пиров, объём трафика, популярность контента, географическое распределение, аномалии.

## Как пользоваться

1. Запустите сборщик: `node scripts/collectors/collect-p2p.mjs`
2. Сборщик подключается к публичным DHT-сетям
3. Данные сохраняются в `/basket/network/p2p/`
4. Используйте `http://localhost:3117/api/p2p?network=bittorrent`

## Профессиональное использование

- **Интернет-провайдеры** отслеживают пиратский трафик
- **Исследователи** изучают поведение P2P-сетей
- **Правоохранительные органы** выявляют нелегальный обмен
- **Компании** анализируют нагрузку

## ❓ Часто задаваемые вопросы

**Вопрос:** Какие сети поддерживаются?
**Ответ:** BitTorrent, IPFS, DHT, Blockchain, и другие.

**Вопрос:** Безопасно ли это?
**Ответ:** Да, сборщик только анализирует открытые данные.

**Вопрос:** Какие метрики собираются?
**Ответ:** Количество пиров, объём трафика, топ-контент.

## 🎯 Интерактивный туториал

**Шаг 1:** Запустите сборщик

```
node scripts/collectors/collect-p2p.mjs
```

**Шаг 2:** Получите статистику BitTorrent

```

**Шаг 3:** Получите статистику IPFS

```
