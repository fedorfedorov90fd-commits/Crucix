# War Preparation Module

## 📋 Описание
**Русский:**
Модуль **War Preparation** отслеживает индикаторы подготовки к войне: военные учения, переброска войск, накопление ресурсов, пропаганду, экономическую мобилизацию. Интегрируется с OSINT-источниками и спутниковыми данными.

**English:**
The **War Preparation** module tracks war preparation indicators: military exercises, troop deployments, resource accumulation, propaganda, economic mobilization. Integrates with OSINT sources and satellite data.

## 🎯 Назначение
- Раннее предупреждение о конфликтах
- Мониторинг военной активности
- Оценка рисков эскалации

## 🚀 Использование
1. Страница: `/war-preparation`
2. API: `/api/war-preparation`
3. Параметры: `?region=Europe&type=military`
