============================================================
ROUTE EXPLORER — АНАЛИЗ МАРШРУТОВ
============================================================
Версия: 1.0.0
Порт: 3170
Статус: ✅ РАБОТАЕТ

ОПИСАНИЕ
---------
Анализ цепочек поставок и морских маршрутов. Отслеживает узкие
места (chokepoints) и предлагает альтернативные маршруты при
возникновении рисков.

ФУНКЦИИ
--------
- Анализ маршрутов "откуда-куда-что"
- Отслеживание 5 ключевых узких мест
- Оценка рисков для каждого маршрута
- Альтернативные маршруты
- Влияние на страны

УЗКИЕ МЕСТА (CHOKEPOINTS)
-------------------------
1. Ормузский пролив      - риск: высокий
2. Суэцкий канал         - риск: средний
3. Малаккский пролив     - риск: низкий
4. Баб-эль-Мандеб        - риск: высокий
5. Панамский канал       - риск: средний

API ЭНДПОИНТЫ
-------------
POST   /route/analyze           - Анализ маршрута
GET    /route/chokepoints       - Список узких мест

ПРИМЕРЫ ЗАПРОСОВ
----------------
# Список узких мест
curl http://localhost:3170/route/chokepoints

# Анализ маршрута
curl -X POST http://localhost:3170/route/analyze \
  -H "Content-Type: application/json" \
  -d '{"from": "CN", "to": "US", "commodity": "electronics", "cargoType": "container"}'
