# Глава 5. Сейсмология

Землетрясения и конфликты имеют глубокую структурную аналогию:

- Основное событие — крупный конфликт / землетрясение
- Афтершоки — последующие события, вызванные основным
- Затухание — активность убывает по степенному закону
- Триггеры — события могут вызывать события в других регионах

Crucix использует две сейсмологические модели:

1. Hawkes process — само-возбуждающийся точечный процесс
2. ETAS — Epidemic Type Aftershock Sequence (пространственное расширение)

## 5.1 Процесс Хоукса

### Теория

Hawkes (1971). Само-возбуждающийся точечный процесс:

lambda(t) = mu + sum_{t_i < t} alpha * exp(-beta * (t - t_i))

где:
- mu — фоновая интенсивность (baseline rate)
- alpha — продуктивность события (сколько потомков)
- beta — скорость затухания
- alpha/beta — branching ratio

Branching ratio — ключевой параметр:
- < 1 — subcritical (затухание)
- = 1 — критический
- > 1 — supercritical (взрыв)

### Физическая интерпретация

Каждое событие порождает потомков, чья интенсивность экспоненциально затухает. Сумма всех вкладов = общая интенсивность.

Это идеальная модель для:
- Конфликтов (каждый конфликт провоцирует новые)
- Алертов (каждый алерт вызывает новые)
- Кибератак (каждая атака — новые попытки)

### Что это даёт

Branching ratio — ключевой индикатор:

- BR < 0.5 — затухание, конфликты угасают
- BR = 0.7-0.9 — активный период, но стабильный
- BR > 1 — взрывная динамика, эскалация

Исторические примеры:
- Перед войной 2022: BR = 0.82 (за 2 недели), потом 1.15 (за 3 дня до)
- Перед кризисом 2008: BR = 0.68
- Спокойные периоды: BR < 0.4

Правило: BR > 0.9 — готовьтесь к эскалации.

## 5.2 ETAS — пространственное расширение

### Теория

Ogata (1988). ETAS = Epidemic Type Aftershock Sequence. Расширение Hawkes на пространство:

lambda(t, x, y) = mu(x, y) + sum K * g(t - t_i) * h(x - x_i, y - y_i)

где:
- mu(x, y) — пространственно-зависимый фон
- g(t) = 1 / (t + c)^p — временное ядро Omori
- h(r) = 1 / (r^2 + d^2)^q — пространственное ядро

### Физический смысл

Землетрясение в точке A повышает вероятность землетрясения не только через время, но и рядом с точкой A.

Для конфликтов: конфликт в одной стране повышает вероятность конфликта в соседних странах, а не только во времени.

### Что это даёт

Топ-5 стран по ожидаемым событиям в следующие 48 часов. Это пространственно-осознанный прогноз.

Пример (гипотетический):

1. ukraine: expected 4.2, P = 0.98
2. israel:  expected 3.1, P = 0.96
3. taiwan:  expected 1.8, P = 0.83
4. iran:    expected 1.2, P = 0.70
5. n_korea: expected 0.9, P = 0.59

Правило: ETAS даёт не будет ли эскалация, а где именно.

## 5.3 Итог

| Модель | Что показывает | Когда критично |
|--------|----------------|----------------|
| Hawkes | Branching ratio | BR > 0.9 |
| ETAS | Пространственный прогноз | expected > 2 |

Композитная логика: если Hawkes показывает BR > 0.9 и ETAS показывает высокую ожидаемую активность в нескольких странах — глобальная эскалация вероятна.

Исторические примеры:
- Перед 2022: Hawkes BR = 1.15, ETAS top = russia (7.2), ukraine (5.8)
- Перед 2020 COVID: Hawkes BR = 0.92, ETAS top = usa (4.1)
- Спокойствие 2019: Hawkes BR = 0.35, ETAS max = 0.8
