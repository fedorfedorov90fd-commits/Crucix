# Gps Jamming Module

## 📋 Description
**English:**
The **Gps Jamming** module provides comprehensive data monitoring, analysis and reporting capabilities within the Crucix ecosystem.

## 🎯 Purpose
- Real-time data monitoring and analysis
- Integration with external data sources
- Automated reporting and visualization
- Risk assessment and early warning
- Multi-source data aggregation

## 🚀 How to Use
1. Access the module via: `/gps-jamming`
2. Use REST API: `/api/gps-jamming`
3. Configure via: `/config/gps-jamming.json`
4. Monitor status: `/api/gps-jamming/status`
