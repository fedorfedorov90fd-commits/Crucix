Визуализация: Построить карту мира, раскрасив страны по какому-либо признаку (например, по плотности населения, ВВП или типу политического режима).

Фильтрация: Выбрать конкретный регион (например, только страны Европы или только островные государства) для детального изучения.
Агрегация: Объединить данные с другими таблицами (например, со статистикой населения) для создания тематических карт.
