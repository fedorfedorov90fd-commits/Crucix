# Дашборд координации: dashboard-coordination.html

## Простое объяснение (для новичков)

Этот файл — отдельная страница, на которой аналитик видит «рентгеновский снимок» информационного поля: кто с кем синхронен, какие источники «ходят вместе», а какие — одиночки.

**Что на странице:**

1. **Тепловая карта** — матрица, где по одной оси источники, по другой — темы. Цвет ячейки показывает степень синхронности.
2. **Таблица источников** — список всех источников с количеством статей, группой и временем последней публикации.

**Зачем это нужно:**

Вы открываете страницу и сразу видите: вот здесь источники «вспыхивают» вместе, а вот здесь — одинокие точки. Это визуальное доказательство координации: если десять мелких сайтов одновременно краснеют по одной теме — это уже не случайность.

**Как открыть:**

http://127.0.0.1:3117/dashboard-coordination
text


**Аналогия:**

Это как диспетчерская вышка в аэропорту. На экране радара видно, какие самолёты летят вместе, а какие — поодиночке. Только вместо самолётов — источники, а вместо маршрутов — темы.

## Научная база (для специалистов)

Дашборд реализует паттерн **dashboard composition** — сборку из независимых виджетов в единый интерфейс.

**Архитектура:**

- **Статический HTML** — без серверного рендеринга. Открывается локально в браузере.
- **CSS Grid** — `grid-template-columns: 1fr 1fr` для сетки виджетов. Адаптивная вёрстка через `@media (max-width: 992px)`.
- **Тёмная тема** — `background: #0a0a1a`. Стандарт для профессиональных терминалов, снижает нагрузку на глаза при длительной работе.
- **Модули ES6** — каждый виджет подключается через `<script type="module">`. Это обеспечивает изоляцию и ленивую загрузку.
- **Фиксированные панели** — `topbar` (верхняя панель), `nav-dashboards` (навигация по дашбордам). `position: fixed` — чтобы не исчезали при скролле.

**Виджеты:**

1. **`coordination-heatmap.js`** — D3.js heatmap. Матрица «источник × тема». Цвет — `interpolateReds` (от белого к красному). Подсказки при наведении.
2. **`sources-table.js`** — таблица источников. Поля: `source`, `group`, `count`, `last_seen`. Сортировка по количеству.

**Источники данных:**

- `GET /api/layers/sources` — список источников.
- `GET /api/layers/articles?limit=500` — статьи для построения матрицы.

**Fallback:**

Если API недоступен — виджет показывает сообщение об ошибке, страница не падает.

## Как работает (пошагово)

1. Страница загружается в браузере.
2. Подключаются стили (`<style>` в `<head>`).
3. Подключаются библиотеки (Leaflet, Plotly — если нужны).
4. Рендерится `topbar` — верхняя панель с навигацией.
5. Рендерится `nav-dashboards` — список дашбордов.
6. Загружаются виджеты:
   - `coordination-heatmap.js` — рисует матрицу.
   - `sources-table.js` — рисует таблицу.
7. Каждый виджет делает свой `fetch` к API.
8. При ошибке — показывает сообщение, страница продолжает работать.

**Структура HTML:**

```html
<header class="topbar">...</header>
<nav class="nav-dashboards">...</nav>
<main class="main-content">
  <div class="page-title">🔗 Координация источников</div>
  <div class="page-subtitle">Heatmap согласованности...</div>
  <div class="section-title">Heatmap — source × source</div>
  <div id="coordination-heatmap"></div>
  <div class="section-title">Sources Table</div>
  <div id="sources-table"></div>
</main>
<script type="module" src="/widgets/coordination-heatmap.js"></script>
<script type="module" src="/widgets/sources-table.js"></script>

Практические рекомендации

    Тёмная тема — background: #0a0a1a. Стандарт для профессиональных терминалов. Не меняйте на светлую — глаза устают.

    Фиксированные панели — position: fixed. При скролле остаются на месте. Это важно для длинных дашбордов.

    CSS Grid — grid-template-columns: 1fr 1fr. Адаптивность через @media. При ширине < 992px — одна колонка.

    Модули ES6 — <script type="module">. Не используйте <script> без type="module" — не будет изоляции.

    API и static на одном порту — CORS не нужен. Деплой тривиален.

    Fallback на ошибки — каждый виджет обрабатывает ошибки fetch. Страница не падает, если один API недоступен.

    limit=500 — для heatmap нужно много статей. Не уменьшайте без необходимости.

    max-height: 500px — heatmap скроллится, не растягивает страницу.

    Цветовая кодировка — interpolateReds. Интуитивно: белый — нет связи, красный — полная синхронизация.

    Подсказки — append('title'). Нативные HTML-подсказки, работают во всех браузерах.

    d3.min.js локально — dashboard/public/lib/d3.min.js. Не используйте CDN — может быть заблокирован.

    Leaflet и Plotly — подключены через CDN (unpkg.com, cdn.plot.ly). Если они недоступны — виджеты, которые их используют, покажут ошибку. Heatmap работает без них.
