============================================================
SCENARIO ENGINE — МОДЕЛИРОВАНИЕ СЦЕНАРИЕВ
============================================================
Версия: 1.0.0
Порт: 3180
Статус: ✅ РАБОТАЕТ

ОПИСАНИЕ
---------
Моделирование глобальных сценариев: конфликты, санкции,
тарифные шоки, энергетические кризисы, кибератаки.
Оценивает влияние на экономику, безопасность и логистику.

ФУНКЦИИ
--------
- 5 предустановленных сценариев
- Оценка влияния по категориям
- Список затронутых стран
- Вероятность сценария
- Рекомендации по действиям

СЦЕНАРИИ
--------
1. Конфликт          - вероятность: 40%
2. Санкции           - вероятность: 60%
3. Тарифный шок      - вероятность: 30%
4. Энергетический кризис - вероятность: 50%
5. Кибератака        - вероятность: 70%

API ЭНДПОИНТЫ
-------------
GET    /scenario/list           - Список сценариев
POST   /scenario/run            - Запуск сценария

ПРИМЕРЫ ЗАПРОСОВ
----------------
# Список сценариев
curl http://localhost:3180/scenario/list

# Запуск сценария "Санкции"
curl -X POST http://localhost:3180/scenario/run \
  -H "Content-Type: application/json" \
  -d '{"scenario": "sanctions", "parameters": {"country": "RU"}}'

# Запуск сценария "Конфликт"
curl -X POST http://localhost:3180/scenario/run \
  -H "Content-Type: application/json" \
  -d '{"scenario": "conflict", "parameters": {"region": "Middle East"}}'
