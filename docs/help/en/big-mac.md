# Big Mac Module

## 📋 Description
**English:**
The **Big Mac** module provides comprehensive data monitoring, analysis and reporting capabilities within the Crucix ecosystem.

## 🎯 Purpose
- Real-time data monitoring and analysis
- Integration with external data sources
- Automated reporting and visualization
- Risk assessment and early warning
- Multi-source data aggregation

## 🚀 How to Use
1. Access the module via: `/big-mac`
2. Use REST API: `/api/big-mac`
3. Configure via: `/config/big-mac.json`
4. Monitor status: `/api/big-mac/status`
