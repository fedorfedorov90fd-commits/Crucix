# Часть II. Науки

Crucix — не просто набор ML-моделей. Это синтез 30 наук, каждая из которых даёт свой уникальный взгляд на прогнозирование.

## Зачем так много наук

Традиционный подход: одна модель (например, ARIMA или LSTM) учится на исторических данных и делает прогноз.

Проблема: одна модель видит только один аспект. Она не знает про фазовые переходы, эпидемиологию кризисов, причинность, топологию.

Решение: 30 моделей из разных наук. Каждая — со своей специализацией. Ансамбль видит реальность полнее.

## Как читать

Каждая глава состоит из:

1. Теория — что это за наука, откуда пришла модель
2. Формулы — математическая основа
3. Реализация — код на чистом JavaScript
4. Применение в Crucix — как это используется на реальных данных
5. Результаты — что даёт сигнал в композитном индикаторе

Главы независимы — можно читать в любом порядке.

## Принципы

- Мультидисциплинарность важнее эффективности
- Открытость важнее удобства
- Калибровка важнее точности

Одна наука видит один аспект. 30 наук видят реальность.
