# Big Mac Index Module

## 📋 Описание
**Русский:**
Модуль **Big Mac Index** отображает экономический индикатор The Economist, сравнивающий покупательную способность валют через цену Биг-Мака. Показывает переоценённость/недооценённость валют относительно доллара США.

**English:**
The **Big Mac Index** module displays The Economist's economic indicator comparing currency purchasing power through the price of a Big Mac. Shows currency overvaluation/undervaluation relative to the US dollar.

## 🎯 Назначение
- Оценка курсов валют
- Сравнение покупательной способности
- Экономический анализ

## 🚀 Использование
1. Страница: `/big-mac`
2. API: `/api/big-mac`
3. Параметры: `?currency=RUB&compare=USD`
