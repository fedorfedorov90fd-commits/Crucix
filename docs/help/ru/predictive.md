# Predictive — Прогнозная аналитика

## Что это

Predictive — модуль машинного обучения для прогнозирования будущих событий на основе собранных данных. Использует: ARIMA для временных рядов, LSTM для последовательных данных, Gradient Boosting для классификации. Прогнозирует: экономические индикаторы, конфликты, катастрофы, цены на сырьё.

## Как пользоваться

1. Убедитесь, что есть минимум 30 дней исторических данных
2. Запустите: `node scripts/collectors/collect-predictive.mjs`
3. Модель обучается и делает прогноз
4. Прогнозы сохраняются в `/basket/predictive/`
5. Используйте `http://localhost:3117/api/predictive?target=inflation&horizon=30`

## Профессиональное использование

- **Инвесторы** используют прогнозы для торговли
- **Правительства** планируют бюджет
- **Страховые компании** оценивают риски
- **Специалисты по цепочкам** прогнозируют сбои

## ❓ Часто задаваемые вопросы

**Вопрос:** Какие модели используются?
**Ответ:** ARIMA, LSTM, Gradient Boosting, Prophet.

**Вопрос:** Сколько нужно данных?
**Ответ:** Минимум 30 дней, рекомендуется 1 год.

**Вопрос:** Какая точность прогнозов?
**Ответ:** Зависит от данных, 70-95% для проверенных моделей.
