# Стохастическая геометрия: stochastic_geometry.py

## Простое объяснение (для новичков)

Этот файл — «прогноз землетрясения» в инфополе. Он смотрит не на отдельные новости, а на их плотность: насколько тесно они «упакованы» в пространстве смыслов. И предсказывает момент, когда локальный инцидент станет глобальным кризисом.

**Как это работает:**

Представьте, что каждая новость — это растущий круг на карте. Пока круги далеко друг от друга, события остаются локальными. Но когда круги начинают соприкасаться и перекрываться, они образуют одну сплошную сеть. И тогда искра в одном месте мгновенно передаётся по всей сети.

Модуль считает, насколько плотно «упакованы» эти круги, и предупреждает, когда до сплошной сети осталось совсем немного.

**Что он делает:**

1. **Берёт точки** — события в пространстве признаков (время, регион, тема).
2. **Строит диаграмму Вороного** — делит пространство на ячейки. Каждая точка внутри ячейки ближе к своему «центру-новости», чем к любому другому.
3. **Считает среднюю площадь ячеек** — обратная величина плотности.
4. **Сравнивает с критическим порогом** — если плотность выше порога, система «перколирует» (протекает).
5. **Возвращает статус** — `SUBCRITICAL` (спокойно) или `UNIVERSAL_CLUSTER_FORMING` (формируется глобальный кластер).

**Зачем это нужно:**

Это математический прогноз «фазового перехода». Когда плотность событий достигает критической точки, локальные сообщения внезапно связываются в глобальную волну. Модуль предупреждает, когда до этого осталось совсем немного.

**Аналогия:**

Представьте лес. Пока деревья далеко друг от друга, пожар остаётся локальным. Но когда плотность деревьев превышает критическую, огонь переходит в «верховой пожар» — одна искра сжигает весь лес. Модуль измеряет «плотность деревьев» в информационном лесу.

## Научная база (для специалистов)

Модуль реализует **теорию перколяции** (протекания) на основе стохастической геометрии.

**Формально:**

1. **Диаграмма Вороного:** для набора точек `P = {p_1, ..., p_n}` в пространстве признаков. Пространство делится на ячейки `V(p_i)`, где каждая точка внутри ячейки ближе к `p_i`, чем к любой другой `p_j`.

2. **Площадь ячейки:** `area(V(p_i))` — геометрическая площадь ячейки.

3. **Средняя плотность:**

   **mean_density = 1 / mean(area)**

   где `mean(area)` — средняя площадь ячеек.

4. **Критический порог:** `critical_threshold ≈ 1.43` (для 2D/3D пространств). Это теоретическое значение из теории перколяции: при плотности выше этого порога возникает «бесконечный кластер» — связная структура, пронизывающая всё пространство.

5. **Классификация:**
   - `mean_density > critical_threshold` → `UNIVERSAL_CLUSTER_FORMING`.
   - `mean_density ≤ critical_threshold` → `SUBCRITICAL`.

**Теория случайных множеств (Матерон):**

Диаграмма Вороного — это пример «случайного множества». Теория Матерона изучает такие множества и их свойства (плотность, связность, перколяция). Модуль использует эти идеи для анализа инфополя.

**Почему `scipy.spatial.Voronoi`:**

Стандартная библиотека для диаграмм Вороного. Быстрая, надёжная, работает с многомерными пространствами. Альтернативы (`shapely`, `geopandas`) — тяжелее и медленнее.

**Ограничения:**

- Критический порог зависит от размерности пространства признаков. Для 2D — 1.43, для 3D — другое значение. Не переносите вслепую.
- Метрика чувствительна к выбору признаков. Набор `(время, регион, тема)` должен быть осмысленным.
- При малом числе точек (< 5) диаграмма Вороного вырождается. Модуль возвращает `SUBCRITICAL` с нулевой плотностью.
- Защита от деления на ноль: `1e-9` в знаменателе.

## Как работает (пошагово)

1. `calculate_percolation_threshold(event_vectors)` принимает массив векторов событий.
2. Проверяет, что точек достаточно (`len >= 5`). Иначе — `SUBCRITICAL`.
3. Строит диаграмму Вороного через `scipy.spatial.Voronoi`.
4. Для каждой ячейки вычисляет площадь через `shapely.geometry.Polygon`.
5. Вычисляет среднюю площадь.
6. Вычисляет `mean_density = 1 / (mean_area + 1e-9)`.
7. Сравнивает с `critical_threshold = 1.43`.
8. Возвращает объект: `{ mean_info_pressure, percolation_risk, phase_state }`.

**Формат ответа:**

```python
{
    'mean_info_pressure': 1.61,
    'percolation_risk': 'CRITICAL',
    'phase_state': 'UNIVERSAL_CLUSTER_FORMING'
}

Интерпретация:

    mean_info_pressure = 1.61 — плотность выше критического порога.

    percolation_risk = 'CRITICAL' — высокий риск фазового перехода.

    phase_state = 'UNIVERSAL_CLUSTER_FORMING' — формируется глобальный кластер.

Практические рекомендации

    В знаменателе используйте 1e-9. Защита от деления на ноль, если новостей нет. Это «машинный эпсилон».

    Критический порог зависит от размерности. Не переносите 1.43 из 2D в 3D автоматически. Калибруйте на исторических данных.

    Метрика чувствительна к выбору признаков. Набор (время, регион, тема) должен быть осмысленным. Если признаки не имеют смысла, плотность тоже не имеет смысла.

    Интерпретируйте phase_state как оценку предрасположенности к каскаду. Это не предсказание конкретного события. Это оценка «насколько система готова к фазовому переходу».

    Визуализируйте ячейки Вороного. Это наглядно объясняет результат неспециалисту.

    При малом числе точек (< 5) диаграмма вырождается. Модуль возвращает SUBCRITICAL с нулевой плотностью. Это правильно: не делайте выводов по малым выборкам.

    Комбинируйте с chaos_theory_engine.py. Если Ляпунов высокий, а плотность выше порога — система «перегрета» и «готова к перколяции». Это сильный сигнал.

    Для больших корпусов — вычисляйте батчами. Не за один проход. Иначе не хватит памяти.

    shapely.geometry.Polygon — стандартная библиотека. Не изобретайте свой расчёт площади.

    scipy.spatial.Voronoi — стандартная библиотека. Быстрая, надёжная.

    mean_density — обратная величина средней площади. Не путайте с count. Плотность — это «сколько событий на единицу пространства», а не «сколько всего событий».
