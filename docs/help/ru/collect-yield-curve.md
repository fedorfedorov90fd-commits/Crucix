# collect-yield-curve — Сборщик данных

## 📋 Описание
**Русский:**
Сборщик данных **collect-yield-curve** собирает данные из внешних источников и сохраняет их в корзину Crucix.

## 🎯 Назначение
- Сбор данных из внешних API
- Обновление корзины данных
- Мониторинг источников

## 🚀 Использование
- Запуск: `node scripts/collectors/collect-yield-curve.mjs`
- Автоматический запуск через оркестратор
- Логи: `/logs/collectors/collect-yield-curve.log`
