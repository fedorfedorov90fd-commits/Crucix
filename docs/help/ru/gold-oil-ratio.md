# Gold-Oil Ratio Module

## 📋 Описание
**Русский:**
Модуль **Gold-Oil Ratio** отображает соотношение цен на золото и нефть (WTI/Brent) — ключевой индикатор геополитического риска и инфляционных ожиданий. Рост соотношения указывает на увеличение рисков, падение — на стабилизацию.

**English:**
The **Gold-Oil Ratio** module displays the gold-to-oil (WTI/Brent) price ratio — a key indicator of geopolitical risk and inflation expectations. Rising ratio indicates increasing risks, falling indicates stabilisation.

## 🎯 Назначение
- Оценка геополитических рисков
- Инфляционные ожидания
- Торговые сигналы

## 🚀 Использование
1. Страница: `/gold-oil-ratio`
2. API: `/api/gold-oil-ratio`
3. Параметры: `?interval=daily`
