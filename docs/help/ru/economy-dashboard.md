# Economy Dashboard Module

## 📋 Описание
**Русский:**
Модуль **Economy Dashboard** агрегирует все экономические индикаторы в едином интерфейсе: ВВП, инфляция, безработица, PMI, индексы доверия, ставки, курсы валют и товарные цены. Комплексный взгляд на экономику.

**English:**
The **Economy Dashboard** module aggregates all economic indicators in a unified interface: GDP, inflation, unemployment, PMI, confidence indices, rates, currencies and commodity prices. Comprehensive economic view.

## 🎯 Назначение
- Макроэкономический мониторинг
- Сравнение стран
- Анализ трендов

## 🚀 Использование
1. Страница: `/economy-dashboard`
2. API: `/api/economy-dashboard`
3. Параметры: `?countries=US,RU,CN`
