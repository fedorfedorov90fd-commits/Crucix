# Unemployment Module

## 📋 Description
**English:**
The **Unemployment** module provides comprehensive data monitoring, analysis and reporting capabilities within the Crucix ecosystem.

## 🎯 Purpose
- Real-time data monitoring and analysis
- Integration with external data sources
- Automated reporting and visualization
- Risk assessment and early warning
- Multi-source data aggregation

## 🚀 How to Use
1. Access the module via: `/unemployment`
2. Use REST API: `/api/unemployment`
3. Configure via: `/config/unemployment.json`
4. Monitor status: `/api/unemployment/status`
