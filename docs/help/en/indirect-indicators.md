# Indirect Indicators Module

## 📋 Description
**English:**
The **Indirect Indicators** module provides comprehensive data monitoring, analysis and reporting capabilities within the Crucix ecosystem.

## 🎯 Purpose
- Real-time data monitoring and analysis
- Integration with external data sources
- Automated reporting and visualization
- Risk assessment and early warning
- Multi-source data aggregation

## 🚀 How to Use
1. Access the module via: `/indirect-indicators`
2. Use REST API: `/api/indirect-indicators`
3. Configure via: `/config/indirect-indicators.json`
4. Monitor status: `/api/indirect-indicators/status`
