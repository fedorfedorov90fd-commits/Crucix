# Jarvis Custom Module

## 📋 Описание
**Русский:**
Модуль **Jarvis Custom** предоставляет расширенные возможности кастомизации AI-ассистента Jarvis: настройка промптов, выбор моделей, обучение на пользовательских данных, создание специализированных агентов.

**English:**
The **Jarvis Custom** module provides advanced customization options for the Jarvis AI assistant: prompt configuration, model selection, training on user data, creation of specialized agents.

## 🎯 Назначение
- Кастомизация AI
- Создание агентов
- Настройка промптов

## 🚀 Использование
1. Страница: `/jarvis-custom`
2. API: `/api/jarvis-custom`
3. Параметры: `?mode=training&agent=analyst`
