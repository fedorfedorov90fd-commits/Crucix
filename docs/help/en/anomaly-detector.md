# Anomaly Detector Module

## 📋 Description
**English:**
The **Anomaly Detector** module provides comprehensive data monitoring, analysis and reporting capabilities within the Crucix ecosystem.

## 🎯 Purpose
- Real-time data monitoring and analysis
- Integration with external data sources
- Automated reporting and visualization
- Risk assessment and early warning
- Multi-source data aggregation

## 🚀 How to Use
1. Access the module via: `/anomaly-detector`
2. Use REST API: `/api/anomaly-detector`
3. Configure via: `/config/anomaly-detector.json`
4. Monitor status: `/api/anomaly-detector/status`
