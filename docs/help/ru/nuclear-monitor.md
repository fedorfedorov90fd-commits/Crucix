# Nuclear Monitor Module

## 📋 Описание
**Русский:**
Модуль **Nuclear Monitor** отслеживает данные о ядерной активности: работу реакторов, производство урана, ядерные испытания, уровень радиации. Интегрируется с МАГАТЭ, CTBTO и системами мониторинга радиации. Используется для оценки ядерных рисков и безопасности.

**English:**
The **Nuclear Monitor** module tracks nuclear activity data: reactor operations, uranium production, nuclear testing, radiation levels. Integrates with IAEA, CTBTO and radiation monitoring systems. Used for nuclear risk and safety assessment.

## 🎯 Назначение
- Мониторинг ядерной активности
- Оценка радиационной безопасности
- Анализ ядерных программ

## 🚀 Использование
1. Страница: `/nuclear-monitor`
2. API: `/api/nuclear-monitor`
3. Параметры: `?country=Iran&type=enrichment`
