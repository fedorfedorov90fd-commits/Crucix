SATELLITE — СПУТНИКОВЫЕ СНИМКИ
============================================================
Версия: 1.0.0
Порт: 3200
Статус: ✅ РАБОТАЕТ

ОПИСАНИЕ
---------
Интеграция со спутниковыми снимками через STAC API.
Поиск и получение снимков по координатам и дате.
Поддерживает основные спутниковые платформы.

ФУНКЦИИ
--------
- Поиск снимков по координатам
- Фильтрация по дате и радиусу
- Информация о спутниках
- Оценка облачности

ДОСТУПНЫЕ СПУТНИКИ
------------------
1. Sentinel-2   - ESA, разрешение 10м, повтор 5 дней
2. Landsat 9    - NASA, разрешение 15м, повтор 16 дней
3. MODIS        - NASA, разрешение 250м, повтор 1 день
4. Planet Scope - Planet, разрешение 3м, повтор 1 день

API ЭНДПОИНТЫ
-------------
GET    /satellite/search        - Поиск снимков
GET    /satellite/satellites    - Список спутников

ПРИМЕРЫ ЗАПРОСОВ
----------------
# Список спутников
curl http://localhost:3200/satellite/satellites

# Поиск снимков (Киев)
curl "http://localhost:3200/satellite/search?lat=48.4&lon=31.2&radius=50&date=2026-08-29"

# Поиск снимков (Ормузский пролив)
curl "http://localhost:3200/satellite/search?lat=26.5&lon=56.0&radius=30"

ЗАВИСИМОСТИ
-----------
- Node.js v22+
- Доступ к STAC API (внешний сервис)
