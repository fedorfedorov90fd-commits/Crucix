# Social Unrest Module

## 📋 Описание
**Русский:**
Модуль **Social Unrest** отслеживает индексы социальной напряжённости: протесты, забастовки, беспорядки, политические кризисы. Анализирует соцсети, новости и данные СМИ для раннего предупреждения.

**English:**
The **Social Unrest** module tracks social unrest indices: protests, strikes, riots, political crises. Analyzes social media, news and media data for early warning.

## 🎯 Назначение
- Раннее предупреждение о протестах
- Оценка социальной стабильности
- Мониторинг политических рисков

## 🚀 Использование
1. Страница: `/social-unrest`
2. API: `/api/social-unrest`
3. Параметры: `?country=US&type=protest`
