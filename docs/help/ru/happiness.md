# Happiness Index Module

## 📋 Описание
**Русский:**
Модуль **Happiness Index** отслеживает Всемирный индекс счастья (World Happiness Report) по странам. Показывает уровень счастья на основе ВВП, соцподдержки, продолжительности жизни, свободы, щедрости и коррупции.

**English:**
The **Happiness Index** module tracks the World Happiness Report by country. Shows happiness level based on GDP, social support, life expectancy, freedom, generosity and corruption.

## 🎯 Назначение
- Оценка благополучия
- Сравнение стран
- Социальный анализ

## 🚀 Использование
1. Страница: `/happiness`
2. API: `/api/happiness`
3. Параметры: `?country=Denmark&year=2026`
