# График алертов: real-chart.js

## Простое объяснение (для новичков)

Этот файл — «график тревог» на дашборде. Он показывает, как распределены алерты по типам и уровню серьёзности. Вы сразу видите: каких алертов больше — критических, высоких или средних, и к какому типу они относятся.

**Что он делает:**

1. **Запрашивает данные** у API `/api/layers/alerts/stats`.
2. **Строит столбчатую диаграмму** — каждый столбец соответствует типу алерта.
3. **Раскрашивает столбцы** по уровню серьёзности: красный — `high`, оранжевый — `medium`, зелёный — `low`.
4. **Добавляет подписи** — название типа и количество.

**Как читать график:**

- Высокий красный столбец — много критических алертов этого типа. Сигнал тревоги.
- Низкий зелёный — мало, и они не критичны.
- Много столбцов разных цветов — разнообразие алертов.

**Зачем это нужно:**

Вы сразу видите, где «горит». Если все алерты — `silence_gap` (молчание), значит, проблема в молчании. Если много `framing_gap` — проблема в поляризации. График помогает prioritize.

**Аналогия:**

Это как приборная панель в машине. Лампочки разных цветов: красная — «стоп», жёлтая — «внимание», зелёная — «всё хорошо». График показывает, сколько лампочек каждого цвета горит прямо сейчас.

## Научная база (для специалистов)

Виджет реализует **столбчатую диаграмму** (bar chart) на SVG для визуализации распределения алертов по типам и серьёзности.

**Архитектура:**

- **Технология:** Vanilla JS, SVG. Без D3.js — для простоты и портативности.
- **Данные:** `GET /api/layers/alerts/stats` — агрегаты по типам и серьёзности.
- **Формат:** `{ by_type: { silence_gap: 2, topic_gap: 1, framing_gap: 1, ... }, by_severity: { high: 3, medium: 2 } }`.
- **Цвета:** `high` — `#ef4444` (красный), `medium` — `#f59e0b` (оранжевый), `low` — `#22c55e` (зелёный).
- **Геометрия:** столбцы шириной `barWidth = (W - PAD * 2) / N`, высота пропорциональна количеству.

**Формально:**

Для каждого типа `t` с количеством `count(t)`:

**height(t) = (count(t) / max_count) · (H - PAD * 2)**

где `max_count` — максимум по всем типам.

**Оси:**

- X — типы алертов (`silence_gap`, `topic_gap`, `framing_gap`, ...).
- Y — количество.

**Подписи:**

- Название типа под столбцом (поворот на -45° для длинных имён).
- Количество над столбцом.

**Ограничения:**

- Не показывает динамику (только срез на момент запроса).
- Не показывает разбивку по серьёзности внутри типа (только общий цвет).
- При большом количестве типов (> 10) — столбцы становятся тонкими и нечитаемыми.

## Как работает (пошагово)

1. При загрузке страницы (`DOMContentLoaded`) вызывается `mountRealChart()`.
2. `mountRealChart()` находит контейнер по `id` (по умолчанию `'real-chart'`).
3. Отправляет `fetch('/api/layers/alerts/stats')`.
4. Получает JSON, извлекает `by_type` и `by_severity`.
5. Если данных нет — показывает «Нет данных».
6. Вычисляет `max_count` — максимум по всем типам.
7. Создаёт SVG с `viewBox="0 0 600 300"`.
8. Рисует оси: X — типы, Y — количество.
9. Рисует столбцы: для каждого типа — прямоугольник с цветом по серьёзности.
10. Добавляет подписи: название типа (поворот -45°) и количество.
11. Вставляет SVG в контейнер.

**Структура SVG:**

```html
<svg viewBox="0 0 600 300">
  <!-- Оси -->
  <line x1="50" y1="250" x2="550" y2="250" stroke="#444" />
  <line x1="50" y1="50" x2="50" y2="250" stroke="#444" />
  <!-- Столбцы -->
  <rect x="60" y="180" width="40" height="70" fill="#ef4444" />
  <text x="80" y="175" text-anchor="middle">2</text>
  <text x="80" y="270" text-anchor="end" transform="rotate(-45 80 270)">silence_gap</text>
  <!-- ... -->
</svg>

Пример использования

В HTML-странице:
html

<div id="real-chart"></div>
<script type="module" src="/widgets/real-chart.js"></script>

В другом виджете (программно):
javascript

import { mountRealChart } from '/widgets/real-chart.js';

mountRealChart('my-chart-container');

Что появится на экране:

    Столбчатая диаграмма 600×300.

    Столбцы: silence_gap (2), topic_gap (1), framing_gap (1), feed_failure (1).

    Цвета: красный — high, оранжевый — medium, зелёный — low.

    Подписи: название типа и количество.

Пример данных от API:
json

{
  "stats": {
    "by_type": {
      "silence_gap": 2,
      "topic_gap": 1,
      "framing_gap": 1,
      "feed_failure": 1
    },
    "by_severity": {
      "high": 3,
      "medium": 2
    },
    "count": 5
  }
}

Практические рекомендации

    Цвета серьёзности — high (красный), medium (оранжевый), low (зелёный). Интуитивно и совпадает с другими виджетами.

    viewBox="0 0 600 300" — компактный размер. Позволяет масштабировать SVG без потери качества.

    Поворот подписей на -45° — стандарт для длинных имён. Если имена короткие (до 8 символов), можно не поворачивать.

    Подписи над столбцами — количество. Полезно для точного чтения.

    max_count — нормализация. Без неё столбцы будут разной высоты в зависимости от абсолютных значений, что искажает картину.

    Fallback на ошибки — если API недоступен, показывается сообщение. Страница не падает.

    Тёмная тема — background: #0d0d1a. Стандарт для профессиональных терминалов.

    Не используйте для динамики — столбчатая диаграмма показывает только срез. Для динамики — линейный график.

    Не используйте для > 10 типов — столбцы становятся тонкими и нечитаемыми. Если типов больше — агрегируйте.

    by_severity — можно использовать для дополнительной раскраски (например, если в типе есть high — красный, если только medium — оранжевый).
