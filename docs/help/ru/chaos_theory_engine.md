# Теория хаоса: chaos_theory_engine.py

## Простое объяснение (для новичков)

Этот файл — «термометр» информационного поля. Он измеряет, насколько система «перегрета»: если бросить камешек в пруд — круги затухнут, а если бросить в перегретую систему — рванёт.

**Что он делает:**

1. **Считает экспоненту Ляпунова** — численную меру «чувствительности» системы. Если она больше 0.5, информационное поле находится в режиме хаоса: малейший вброс вызовет непропорционально огромный отклик.
2. **Считает RQA-метрики** (рекуррентный количественный анализ) — показатели `DET` (детерминизм) и `LAM` (ламинарность). Они помогают отличить живую дискуссию от механической генерации.
3. **Возвращает статус** — `CHAOTIC` или `STABLE`, с меткой `HIGH_CASCADE_RISK` при высоком риске каскада.

**Зачем это нужно:**

В спокойном поле фейк затухает. В перегретом — вызывает шторм. Если система показывает `CHAOTIC`, аналитик знает: сейчас нельзя вбрасывать новые темы — будет непредсказуемая реакция. Или наоборот: если нужно вызвать резонанс — момент подходящий.

**Аналогия:**

Представьте, что вы смотрите на поверхность воды. В обычном состоянии — рябь затухает. В состоянии «перегрева» — каждая капля вызывает волну. Экспонента Ляпунова — это численная мера «перегрева».

## Научная база (для специалистов)

Модуль реализует методы теории детерминированного хаоса применительно к временным рядам информационной интенсивности.

**Экспонента Ляпунова:**

Наибольшая экспонента Ляпунова (`lyap_r` из библиотеки `nolds`) измеряет скорость расхождения близких траекторий в фазовом пространстве. Формально:

**λ = lim (1/t) · ln(|δZ(t)| / |δZ(0)|)**

где `δZ(t)` — расстояние между двумя траекториями в момент `t`. Если λ > 0, траектории расходятся экспоненциально — система хаотична. Если λ < 0, траектории сходятся — система устойчива.

**Порог 0.5** — эмпирический. Значение > 0.5 трактуется как режим хаоса. Для информационного поля это означает: небольшой вброс (фейк, провокация) способен вызвать непропорционально большой отклик.

**Рекуррентный количественный анализ (RQA):**

RQA строит матрицу повторяемости состояний системы и вычисляет:

- **`DET` (детерминизм)** — доля рекуррентных точек, образующих диагональные линии. Высокий DET означает, что система «шаблонна» — она повторяет свои состояния.
- **`LAM` (ламинарность)** — доля рекуррентных точек, образующих вертикальные линии. Высокая LAM означает, что система «застревает» в одном состоянии.

**Интерпретация комбинации:**

- **Высокий Ляпунов + высокий DET** — управляемая нестабильность. Система хаотична для наблюдателя, но шаблонна для того, кто её контролирует. Это «почерк» бот-сетей.
- **Высокий Ляпунов + низкий DET** — естественный хаос. Живая дискуссия, где никто не контролирует процесс.
- **Низкий Ляпунов** — система стабильна. Вбросы затухают.

**Ограничения:**

- Экспонента Ляпунова требует достаточно длинного ряда (порядка сотен точек). На коротких окнах оценка нестабильна.
- Порог 0.5 эмпирический — калибруйте под ваши данные.
- `CHAOTIC` — это оценка чувствительности, а не предсказание конкретного события.

## Как работает (пошагово)

1. Ряд (число публикаций по теме за интервал или индекс тональности) подаётся в `lyap_r` с параметрами `emb_dim=10`, `lag=1`, `min_tsep=20`.
2. Результат сравнивается с порогом: при значении > 0.5 возвращается статус `CHAOTIC` и метка `HIGH_CASCADE_RISK`.
3. Параллельно считается RQA-матрица; `DET` и `LAM` извлекаются как дополнительные признаки.
4. Комбинация «высокий Ляпунов + высокий DET» интерпретируется как признак управляемой нестабильности.
5. Результаты используются для оценки каскадного риска при интерпретации алертов.

**Формат ответа:**

```python
{
    'system_state': 'CHAOTIC',       # или 'STABLE'
    'lyapunov_exponent': 0.62,
    'determinism': 0.87,             # DET
    'laminarity': 0.72,              # LAM
    'warning': 'HIGH_CASCADE_RISK',  # или 'NORMAL'
    'attribution_fingerprint': 0.72  # LAM как «почерк» ботов
}

Пример использования
python

from services.chaos_theory_engine import analyze_information_dynamics
import numpy as np

# Ряд: число публикаций по теме за каждую минуту
series = np.array([12, 15, 8, 22, 45, 38, 52, 61, 48, 33, 25, 18, 14, 11, 9, 7, 5, 4, 3, 2])

result = analyze_information_dynamics(series)
print(result)
# {'system_state': 'CHAOTIC', 'lyapunov_exponent': 0.62, 'determinism': 0.87, ...}

Что означает результат:

    CHAOTIC + lyapunov > 0.5 — система в режиме хаоса. Любой вброс вызовет каскад.

    determinism > 0.8 — система шаблонна. Возможно, это бот-сеть, которая создаёт хаос для наблюдателя.

    HIGH_CASCADE_RISK — высокий риск каскада. Аналитик должен быть готов к резкому росту публикаций по теме.

Практические рекомендации

    Длина ряда — минимум 100–200 точек. На коротких окнах (10–20 точек) оценка Ляпунова нестабильна.

    Порог 0.5 — эмпирический. Калибруйте его под ваши данные и единицы измерения ряда.

    Не интерпретируйте CHAOTIC как «будет взрыв». Это оценка чувствительности, а не предсказание конкретного события.

    RQA-показатели полезнее в связке с другими модулями (например, с детектором синхронности), а не изолированно.

    Для визуализации используйте фазовые портреты (график x(t) против x(t+τ)) — они нагляднее одного числа.

    attribution_fingerprint (LAM) — «почерк» источника. Высокая ламинарность при высоком Ляпунове — признак управляемой нестабильности.

    Не запускайте на каждом запросе. Модуль вычислительно затратен. Запускайте по расписанию (раз в час) или по событию (при новом алерте).

    Комбинируйте с pattern-recognizer.mjs — он считает Z-score аномалий. Вместе они дают полную картину: «насколько система хаотична» + «где именно аномалия».
