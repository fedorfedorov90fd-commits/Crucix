# currents — Новостной агрегатор Currents API

## 📋 Описание
**Русский:**
Модуль **currents-api** отдаёт статьи из **Currents API** — новостного агрегатора с категориями, источниками, регионами и тональностью.

## 🎯 Назначение
- Отображение новостного потока на карте мира.
- Классификация статей по категориям (политика, экономика, технологии, спорт и др.).
- Анализ тональности новостей.
- Фильтрация по регионам и источникам.

## 🚀 Использование
- Страница: `/currents` (или через панель слоёв на `/geo-map`)
- API-эндпоинт: `GET /api/layers/currents`
- Подпути: `?format=json|csv|series|stats|raw`
- Фильтры: `?category=`, `?region=`, `?q=`, `?limit=`
