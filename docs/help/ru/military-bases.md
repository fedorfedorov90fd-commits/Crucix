# Military Bases Module

## 📋 Описание
**Русский:**
Модуль **Military Bases** отображает расположение военных баз и объектов по всему миру. Показывает принадлежность, тип, численность и активность. Используется для геополитического анализа и оценки военного присутствия.

**English:**
The **Military Bases** module displays military bases and facilities worldwide. Shows affiliation, type, size and activity. Used for geopolitical analysis and military presence assessment.

## 🎯 Назначение
- Анализ военного присутствия
- Геополитический мониторинг
- Оценка конфликтного потенциала

## 🚀 Использование
1. Страница: `/military-bases`
2. API: `/api/military-bases`
3. Параметры: `?country=US&type=naval`
