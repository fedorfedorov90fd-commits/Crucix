# CLI Client Module

## 📋 Описание
**Русский:**
Модуль **CLI Client** предоставляет командный интерфейс для управления Crucix из терминала. Позволяет запускать сборщики, получать данные, управлять конфигурацией и выполнять диагностику без веб-интерфейса.

**English:**
The **CLI Client** module provides a command-line interface for managing Crucix from the terminal. Allows running collectors, fetching data, managing configuration and performing diagnostics without web interface.

## 🎯 Назначение
- Управление из терминала
- Автоматизация задач
- Удалённое администрирование

## 🚀 Использование
1. Страница: `/cli-client`
2. API: `/api/cli-client`
3. Команды: `node cli.js --collector=all`
