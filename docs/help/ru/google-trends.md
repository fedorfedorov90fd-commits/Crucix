# Google Trends Module

## 📋 Описание
**Русский:**
Модуль **Google Trends** отслеживает популярность поисковых запросов в реальном времени. Показывает динамику интереса к ключевым темам: экономика, политика, технологии, криптовалюты. Используется для прогнозирования рыночных трендов и оценки общественных настроений.

**English:**
The **Google Trends** module tracks real-time search query popularity. Shows interest dynamics for key topics: economy, politics, technology, cryptocurrencies. Used for forecasting market trends and assessing public sentiment.

## 🎯 Назначение
- Анализ общественного интереса
- Прогнозирование трендов
- Оценка рыночных настроений

## 🚀 Использование
1. Страница: `/google-trends`
2. API: `/api/google-trends`
3. Параметры: `?q=inflation,stock market&geo=US`
