АРХИТЕКТУРА ПРОЕКТА: CRUCIX

=== ПРИНЦИПЫ ===
1. ВСЕ модули работают локально — без зависимости от внешних серверов
2. ВСЕ данные собираются из открытых источников
3. ВСЯ аналитика выполняется локально (Ollama) или через бесплатные API
4. Модули НЕ зависят друг от друга (слабая связанность)
5. Каждый модуль экспортирует единый интерфейс

=== СТРУКТУРА КОДА ===
- apis/sources/ — модули сбора данных
- dashboard/panels/ — панели интерфейса
- scripts/ — вспомогательные скрипты
- server.mjs — точка входа

=== КОНТРАКТЫ ===
1. Каждый источник данных экспортирует async function fetch()
2. Каждая панель экспортирует render() и onAction()
3. Данные в корзине хранятся в JSON с полями: id, title, date, url, summary, source

=== СТАНДАРТЫ ===
- ES Modules (import/export)
- fetch для HTTP-запросов
- Логи с префиксом [Модуль]
- Обработка ошибок через try/catch
