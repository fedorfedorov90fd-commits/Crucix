# DXY Module

## 📋 Описание
**Русский:**
Модуль **DXY** отслеживает индекс доллара США (DXY) — курс доллара к корзине шести основных валют. Используется для оценки силы доллара, влияния на мировую торговлю и сырьевые рынки.

**English:**
The **DXY** module tracks the US Dollar Index (DXY) — the dollar's exchange rate against a basket of six major currencies. Used for assessing dollar strength, impact on world trade and commodity markets.

## 🎯 Назначение
- Оценка силы доллара
- Анализ валютных рынков
- Влияние на сырьевые цены

## 🚀 Использование
1. Страница: `/dxy`
2. API: `/api/dxy`
3. Параметры: `?interval=30d`
