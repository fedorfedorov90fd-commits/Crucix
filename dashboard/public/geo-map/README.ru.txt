1. ОБЩЕЕ ОПИСАНИЕ
================================================================================
Файл geo-map.html разделен на логические блоки для удобства редактирования.
Каждый блок находится в отдельной папке и отвечает за свою часть функционала.

2. СТРУКТУРА ПАПОК
================================================================================
dashboard/public/geo-map/
├── css/
│   └── geo-map.css          # Все стили для карты
├── js/
│   ├── geo-map-core.js      # Ядро карты (инициализация Leaflet)
│   ├── country-boundaries.js # Границы и цвета стран (раскраска)
│   └── markers.js           # Маркеры событий на карте
├── blocks/
│   ├── topbar.js            # 1-й блок: кнопки (главная, копировать, список страниц, help, ru/en)
│   ├── dashboards-nav.js    # 2-й блок: 17 дашбордов
│   └── layer-panel.js       # 3-й блок: 121 слой
├── templates/               # Шаблоны для будущих элементов
├── README.ru.txt            # Описание структуры (русский)
└── README.en.txt            # Описание структуры (английский)

3. ОПИСАНИЕ БЛОКОВ
================================================================================

3.1. geo-map-core.js (Ядро карты)
- Инициализация карты Leaflet
- Хранение глобальных данных (страны, маркеры, слои)
- Экспорт функций для доступа к данным

3.2. country-boundaries.js (Границы и цвета стран)
- Загрузка GeoJSON границ стран
- Раскраска стран по статусам (critical, pre-war, high, medium, low, inactive)
- Добавление подписей стран на карту
- Цветовая схема:
  🔴 critical  — #ef4444 (Критический)
  🟠 pre-war   — #f97316 (Предвоенный)
  🟠 high      — #f59e0b (Высокий)
  🟡 medium    — #eab308 (Средний)
  🟢 low       — #22c55e (Нормальный)
  ⚪ inactive  — #3a3a4a (Нет данных)

3.3. markers.js (Маркеры)
- Отображение маркеров событий на карте
- Тепловая карта (вкл/выкл)
- Временная шкала событий
- Подсчет количества маркеров

3.4. topbar.js (1-й блок)
- Кнопка ← НА ГЛАВНУЮ — переход на /jarvis
- Кнопка 📋 КОПИРОВАТЬ — копирование полного снапшота карты
- Кнопка 📡 Список страниц — переход на /registry
- Кнопка ❓ HELP — вызов справки
- Кнопка 🌡️ Тепловая — включение/выключение тепловой карты
- Кнопка 📅 Хронология — включение/выключение временной шкалы
- Кнопка 📄 PDF — экспорт карты в PDF
- Переключатель RU/EN — смена языка интерфейса

3.5. dashboards-nav.js (2-й блок)
- 17 кнопок для перехода к дашбордам:
  Центр аналитики, Экономика, Финансы, Военный, Геополитика,
  Экология, Кибер, Космос, Новости, AI, Наука, ESG, Угрозы,
  Здоровье, Энергетика, Транспорт, Регионы

3.6. layer-panel.js (3-й блок)
- Панель слоев справа (как в Crucix)
- 121 слой, сгруппированный по категориям
- Поиск по слоям
- Подсветка активного слоя
- Сохранение состояния в localStorage

4. КАК РЕДАКТИРОВАТЬ
================================================================================
1. Стили → geo-map/css/geo-map.css
2. Логика карты → geo-map/js/geo-map-core.js
3. Цвета стран → geo-map/js/country-boundaries.js
4. Маркеры → geo-map/js/markers.js
5. Кнопки → geo-map/blocks/topbar.js
6. Дашборды → geo-map/blocks/dashboards-nav.js
7. Слои → geo-map/blocks/layer-panel.js

5. ПРИНЦИП РАБОТЫ
================================================================================
1. geo-map.html загружает CSS и подключает JS-модули
2. geo-map-core.js инициализирует карту
3. Загружаются данные из API (/api/geo/markers, /api/geo/status, /api/layers)
4. country-boundaries.js раскрашивает страны
5. markers.js отображает маркеры
6. layer-panel.js создает панель слоев

6. КЛЮЧЕВЫЕ ФУНКЦИИ
================================================================================
- initMap() — создание карты
- loadCountryBoundaries() — загрузка границ и раскраска стран
- loadMarkers() — загрузка маркеров
- loadLayer(layerId) — загрузка конкретного слоя
- copyAllData() — копирование полного снапшота
- toggleHeat() — тепловая карта
- toggleTimeline() — временная шкала
- calculateSSI() — расчет индекса напряженности

7. ЗАМЕЧАНИЯ
================================================================================
- Все блоки независимы — изменение одного не ломает другие
- При добавлении нового слоя нужно обновить layer-manager.mjs на сервере
- Цвета стран управляются через STATUS_COLORS в country-boundaries.js
- Активный слой сохраняется в localStorage
