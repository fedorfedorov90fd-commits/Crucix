# News Aggregator Module

## 📋 Description
**English:**
The **News Aggregator** module provides comprehensive data monitoring, analysis and reporting capabilities within the Crucix ecosystem.

## 🎯 Purpose
- Real-time data monitoring and analysis
- Integration with external data sources
- Automated reporting and visualization
- Risk assessment and early warning
- Multi-source data aggregation

## 🚀 How to Use
1. Access the module via: `/news-aggregator`
2. Use REST API: `/api/news-aggregator`
3. Configure via: `/config/news-aggregator.json`
4. Monitor status: `/api/news-aggregator/status`
