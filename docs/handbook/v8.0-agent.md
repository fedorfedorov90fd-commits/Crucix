# Crucix v8.0 — AI Agent над детерминированным ядром

**Версия:** 8.0.0
**Расположение:** apis/predict/agent/ + dashboard/agent.html
**Назначение:** LLM-планировщик над 61 модулем Crucix. Оператор задаёт вопрос — агент выбирает модули, запускает их, отвечает.

## Архитектура — три уровня

    ┌──────────────────────────────────────────────────────┐
    │  Level 3: Chat UI (dashboard/agent.html)              │
    │  WebSocket + HTTP, интерфейс оператора                │
    └──────────────────────┬───────────────────────────────┘
                           │  HTTP POST /api/agent/query
                           │  WebSocket /agent
                           ▼
    ┌──────────────────────────────────────────────────────┐
    │  Level 2: AI Agent (apis/predict/agent/)              │
    │  planner → executor → narrator                        │
    │  LLM (Ollama) + fallback                              │
    └──────────────────────┬───────────────────────────────┘
                           │  registry.call(toolName, args)
                           ▼
    ┌──────────────────────────────────────────────────────┐
    │  Level 1: Детерминированное ядро (engine.mjs)         │
    │  16 фаз A–U, 45 базовых + 16 новых модулей           │
    │  Работает НЕЗАВИСИМО от LLM                          │
    └──────────────────────────────────────────────────────┘

**Ключевой принцип:** LLM НЕ переписывает ядро. LLM вызывает ядро как API.

## Tool Registry — 19 инструментов

### Категории

| Категория | Кол-во | Примеры |
|-----------|--------|---------|
| base | 3 | engine_full, regime_shift, explainability |
| v6 | 5 | neural_causal_discovery, causal_rl, zk_federated |
| catalog | 6 | mcmc, physics_inspired, anomaly_detection |
| v7 | 5 | world_model, neural_ode, simulation_engine |

### Структура tool

    {
      name: 'continuous_causal',
      description: 'Continuous-Time SCM: Neural ODE + do-operator + ATE',
      argsSchema: { epochs: 'number', interventionVar: 'string' },
      defaults: { epochs: 3, interventionVar: 'tension' },
      minHistory: 20,
      category: 'v7',
      returns: '{ dag, training, forecast, counterfactual, ate }',
      when: 'Запросы "что если X=Y"',
      path: './v7/continuous_causal.mjs',
      fn: 'crucixContinuousCausal',
    }

### Whitelist

LLM может вызвать **только** tools из реестра. Если LLM вернёт `unknown_tool`, шаг отклоняется. Это критично для safety.

### Sanitize args

Аргументы от LLM проходят через `sanitizeArgs`:
- Типы приводятся к argsSchema.
- Значения вне schema удаляются.
- Применяются defaults.

Это защищает от инъекций (например, попытки передать путь через args).

## Planner — 3 режима

### 1. plan(query) — только план

    const planner = new Planner();
    const result = await planner.plan('Есть ли аномалии?');
    // { mode, plan: [{tool, args, reason}], reasoning }

Используется для отладки и для случаев, когда executor внешний.

### 2. planAndExecute(query) — план + выполнение

    const result = await planner.planAndExecute('аномалии');
    // { mode, plan, executions: [{tool, ok, result, elapsedMs}] }

Tools выполняются через Executor с retry + circuit breaker + metrics.

### 3. fullPipeline(query, { narrator }) — полный цикл

    const result = await planner.fullPipeline('аномалии', {
      narrator: async (input) => await narrate(input, { useLLM: true }),
    });
    // { mode, plan, executions, answer, sessionFile }

Дополнительно: narrator формирует ответ оператору. Session сохраняется в runs/agent/session_<id>.json.

## Executor — безопасность и метрики

### Retry

Transient errors (timeout, network) ретраятся до 2 раз с exponential backoff. Логические ошибки (insufficient_history, unknown_tool) — без retry.

### Circuit breaker

3 падения подряд → tool отключается на 5 запусков. Восстанавливается автоматически.

### Метрики

Per-tool: calls, successes, failures, totalMs, retries. Сохраняются в runs/agent/executor_metrics.json.

### Параллелизм

executePlan с parallel=true запускает шаги батчами по 4 через Promise.allSettled.

## Narrator — двойной режим

### Template (всегда работает)

extractSignals() знает 16 типов tools:
- neural_causal_discovery → nEdges, top edge
- anomaly_detection → nAnomalies, isAnomaly
- continuous_causal → ATE per variable
- simulation_engine → consensus, confidence
- ... и т.д.

TemplateNarrate формирует текст:
1. Заголовок с запросом.
2. Список выбранных модулей.
3. Результаты по каждому (signals).
4. Итоговый confidence (high/moderate/low).
5. Рекомендация.

### LLM (опционально)

llmNarrate отправляет результаты LLM для формулировки. При timeout или ошибке — автоматический fallback на template.

## Server — HTTP + WebSocket

### Запуск

    PORT=8090 node apis/predict/agent/server.mjs
    DISABLE_LLM=1 node apis/predict/agent/server.mjs

### HTTP эндпоинты

| Метод | Путь | Назначение |
|-------|------|------------|
| GET | /health | Проверка живости |
| GET | /api/agent/status | Статус системы |
| GET | /api/agent/tools | Список tools |
| GET | /api/agent/sessions | История сессий |
| GET | /api/agent/session/:id | Детали сессии |
| POST | /api/agent/query | Главный эндпоинт |
| GET | / | UI (agent.html) |

### WebSocket

    ws://localhost:8090/agent

Протокол:
- Client → Server: `{ type: 'query', query: '...' }`
- Server → Client: `{ type: 'processing' }`
- Server → Client: `{ type: 'agent_response', data: {...} }`
- Ping/pong для keep-alive.
- Close frame для завершения.

### Безопасность

- host = 127.0.0.1 по умолчанию.
- maxBodyBytes = 100 KB.
- query.length ≤ 2000.
- request timeout 300s.
- CORS разрешён только для GET/POST/OPTIONS.

## Fallback — критичен для production

**Проблема:** Ollama LLM может быть недоступна (timeout 60s при холодном старте).

**Решение:** FallbackPlanner (keyword-based) работает мгновенно:
- «что если» → continuous_causal
- «через N часов» → simulation_engine
- «аномалии» → anomaly_detection
- «действие/политика» → dreamer
- «причина/влияет» → neural_causal_discovery
- default → simulation_engine + anomaly_detection

**Результат:** система работает даже без LLM. LLM — оптимизация поверх.

## Диагностика

### Быстрая проверка

    curl http://127.0.0.1:8090/health
    curl http://127.0.0.1:8090/api/agent/status

### Тестовый запрос

    curl -X POST http://127.0.0.1:8090/api/agent/query \
      -H "Content-Type: application/json" \
      -d '{"query":"аномалии"}'

### Типичные проблемы

| Симптом | Причина | Решение |
|---------|---------|---------|
| `mode: fallback` всегда | LLM timeout | Предзагрузить модель: `ollama run llama3.2` |
| `unknown_tool` в rejected | LLM выдумал tool | Проверить tool_registry (LLM prompt) |
| `insufficient_history` | Мало sweep'ов | Подождать N sweep'ов (minHistory от 20 до 30) |
| Session file не создаётся | Права на runs/agent/ | chmod 755 runs/agent |
| WebSocket не подключается | Порт занят | Сменить PORT |
