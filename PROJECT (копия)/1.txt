=== ПРОЕКТ CRUCIX — РАЗРАБОТКА ИНТЕРФЕЙСА УПРАВЛЕНИЯ RSS ===

=== ФАЙЛ RSS-ЛЕНТ ===
Уже есть готовый OPML-файл с 150+ источниками, разбитыми по категориям:
/home/ta8_/Рабочий стол/Crucix/data/feeds/feeds.opml

=== ТРЕБОВАНИЯ К ИНТЕРФЕЙСУ ===

1. ПАНЕЛЬ УПРАВЛЕНИЯ RSS (РАЗВОРАЧИВАЮЩЕЕСЯ ОКНО)
Функции:
- Посмотреть список всех RSS-лент (название, URL, статус)
- Добавить одну новую ленту (ввести URL и название)
- Удалить ленту (кнопка рядом с каждой)
- Обновить все ленты (кнопка)
- Импортировать OPML-файл (загрузить с компьютера)
- Экспортировать OPML-файл (скачать текущий список)

Статистика:
- Всего лент: X
- Работающих лент: X
- Не работающих лент: X

2. ЛЕНТА НОВОСТЕЙ (ОТДЕЛЬНОЕ ОКНО)
Региональные фильтры (кнопки):
- 🌍 МИР (все новости)
- 🇺🇸 США
- 🇪🇺 ЕВРОПА
- 🌍 АФРИКА
- 🏛 БЛИЖНИЙ ВОСТОК
- 🌎 ЛАТИНСКАЯ АМЕРИКА
- 🌏 АЗИАТСКО-ТИХООКЕАНСКИЙ РЕГИОН
- ⚡ ЭНЕРГЕТИКА И РЕСУРСЫ
- 🏛 ПРАВИТЕЛЬСТВО
- 🧠 АНАЛИТИЧЕСКИЕ ЦЕНТРЫ
- 📊 ПРОГНОЗЫ

Количество новостей: по умолчанию 20, можно настроить до 30.
Автопрокрутка: вкл/выкл (галка), при наведении останавливается.
Скорость: регулируемая (или медленнее по умолчанию).
Счётчик новостей внизу: "Новостей за сегодня: X"
