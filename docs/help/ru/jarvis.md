# Jarvis Module

## 📋 Описание
**Русский:**
Модуль **Jarvis** — это AI-ассистент на базе больших языковых моделей (LLM). Отвечает на вопросы, анализирует данные, генерирует отчёты и помогает в принятии решений. Интегрируется с Ollama, GPT, Claude и локальными моделями.

**English:**
The **Jarvis** module is an AI assistant based on large language models (LLM). Answers questions, analyzes data, generates reports and assists in decision making. Integrates with Ollama, GPT, Claude and local models.

## 🎯 Назначение
- Интеллектуальный помощник
- Анализ данных
- Генерация отчётов

## 🚀 Использование
1. Страница: `/jarvis`
2. API: `/api/jarvis`
3. Параметры: `?q=Анализ экономики России`
