4. API
========================================
- /api/rss/* — управление RSS
- /api/basket/* — корзина данных
- /api/news/* — новости
- /api/ai/rate — AI оценка
- /api/ai/chat — AI чат
- /api/storage/* — хранение
- /api/geo/* — геополитические маркеры

========================================
5. СТРАНИЦЫ
========================================
- /jarvis — главный интерфейс (6 кнопок)
- /rss-feed — RSS лента
- /rss-dashboard — управление RSS
- /ai-chat — AI помощник
- /geo-map — геополитическая карта
- /basket — корзина данных (Модуль №4)
- /grid-tool — инструмент "Сетка" (для редактирования)
- /crucix — новый дашборд (экспериментальный)

========================================
6. ИНСТРУМЕНТ "СЕТКА" (/grid-tool)
========================================
- Отображает jarvis.html в iframe
- Накладывает координатную сетку поверх страницы
- Кнопка "Копировать ВСЮ страницу" — детализация всех элементов
- Подсказка при наведении на элемент
- Переключение сетки (кнопка "⊞ Сетка")

========================================
7. ВНЕДРЁННЫЕ УЛУЧШЕНИЯ ИЗ PR
========================================
- safeFetch: экспоненциальная задержка, Retry-After
- OpenAI-совместимый провайдер (Ollama, LM Studio)
- OFAC: загрузка только первых 64KB
- Docker: не-root пользователь
- NOAA: исправление параметра limit
- Сервер: динамическая ширина баннера
- Mistral: модель по умолчанию mistral-small-latest
