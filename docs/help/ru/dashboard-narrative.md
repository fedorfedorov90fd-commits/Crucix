# Дашборд нарративов: dashboard-narrative.html

## Простое объяснение (для новичков)

Этот файл — отдельная страница, на которой аналитик видит «карту смыслов»: как разные группы источников описывают одни и те же темы. Это визуальное сравнение нарративов.

**Что на странице:**

1. **Scatter-график** — точки в двумерном пространстве. По горизонтали — западный охват темы, по вертикали — российский. Диагональ — паритет (обе стороны пишут одинаково).
2. **Матрица источников** — таблица, где видно, сколько статей по каждой теме у каждого источника.

**Как читать scatter:**

- Точка в правом верхнем углу — тему освещают обе стороны.
- Точка в левом верхнем углу — тему освещают только российские источники.
- Точка в правом нижнем углу — только западные.
- Точка на диагонали — паритет.

**Зачем это нужно:**

Вы сразу видите, где нарративы совпадают, а где — расходятся. Если тема «энергетика» — в левом верхнем углу (только российские), а «кибер» — на диагонали (обе стороны), это уже сигнал: одна тема активно освещается, другая — игнорируется.

**Аналогия:**

Это как карта звёздного неба. Точки — темы. Расстояние между ними — разница в нарративах. Если две точки рядом — нарративы похожи. Если далеко — расходятся.

## Научная база (для специалистов)

Дашборд реализует визуализацию **полярности нарративов** через scatter-график и таблицу источников.

**Архитектура:**

- **Статический HTML** — без серверного рендеринга.
- **Scatter на SVG** — не на Canvas. Это позволяет масштабировать без потери качества и добавлять интерактивность (подсказки при наведении).
- **Оси:** X — `western_count` (западный охват), Y — `russian_count` (российский охват).
- **Диагональ паритета** — линия `y = x`. Если точка выше диагонали — российский охват больше. Если ниже — западный.
- **Цвет точки** — `severity`: `high` (красный), `normal` (зелёный), `critical` (оранжевый).
- **Размер точки** — `total_events`: чем больше событий, тем крупнее точка.

**Формат данных:**

```json
[
  {
    "topic": "энергетика",
    "russian_count": 40,
    "western_count": 2,
    "total_events": 45,
    "severity": "high"
  },
  {
    "topic": "кибер",
    "russian_count": 12,
    "western_count": 15,
    "total_events": 30,
    "severity": "normal"
  }
]

Масштабирование:

    maxX = max(western_count), maxY = max(russian_count).

    maxN = max(maxX, maxY) — единая шкала для обеих осей.

    scaleX(x) = PAD + (x / maxN) * (W - PAD * 2).

    scaleY(y) = H - PAD - (y / maxN) * (H - PAD * 2).

Это позволяет сравнивать темы с разным охватом на одном графике.

Ограничения:

    Для polarity нужны события с обеими группами. Если western_count = 0 — точка уходит на ось Y (не видна на диагонали).

    reaction_gap (разница во времени) не отображается на scatter — только в таблице.

    На текущих данных (мало западных фидов) большинство точек — в левом верхнем углу.

Как работает (пошагово)

    Страница загружается в браузере.

    Подключаются стили (тёмная тема).

    Рендерится topbar — верхняя панель с навигацией.

    Рендерится nav-dashboards — список дашбордов.

    Загружаются виджеты:

        narrative-scatter.js — рисует scatter.

        source-matrix.js — рисует матрицу источников.

    narrative-scatter.js делает fetch('/api/layers/narrative-framing/topics?limit=50').

    Получает JSON с темами.

    Вычисляет maxN — максимум по обеим осям.

    Рисует SVG: сетка, диагональ, оси, точки.

    При наведении на точку — подсказка с topic, russian_count, western_count, severity.

Практические рекомендации

    Scatter на SVG, не на Canvas — масштабируется без потери качества, поддерживает интерактивность.

    Единая шкала maxN — позволяет сравнивать темы с разным охватом. Не делайте отдельные шкалы для X и Y — это искажает картину.

    Диагональ паритета — визуальный ориентир. Если точка на диагонали — обе стороны пишут одинаково.

    Цвет точки — severity. Красный — high, зелёный — normal, оранжевый — critical. Интуитивно.

    Размер точки — total_events. Чем больше событий, тем крупнее точка. Не делайте слишком крупные — они перекрывают друг друга.

    limit=50 — максимум тем на графике. Больше — визуальный шум.

    Fallback на ошибки — если API недоступен, показывается сообщение. Страница не падает.

    Тёмная тема — background: #0d0d1a. Стандарт для профессиональных терминалов.

    Сетка — линии каждые maxN / 5. Помогают оценить масштаб.

    Оси с подписями — «Западный охват →» и «Российский охват ↑». Не забывайте подписи.

    viewBox — 0 0 600 500. Позволяет масштабировать SVG без потери качества.

    overflow: auto — если точек много, они могут выходить за пределы. Скролл спасает.
