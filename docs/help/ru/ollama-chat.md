# Ollama Chat Module

## 📋 Описание
**Русский:**
Модуль **Ollama Chat** предоставляет интерфейс для общения с локальными LLM-моделями через Ollama. Поддерживает Llama 2/3, Mistral, Gemma, DeepSeek и другие модели. Используется для локального AI-ассистента без необходимости облачных API.

**English:**
The **Ollama Chat** module provides an interface for communicating with local LLM models via Ollama. Supports Llama 2/3, Mistral, Gemma, DeepSeek and other models. Used for local AI assistant without cloud APIs.

## 🎯 Назначение
- Локальное общение с AI
- Тестирование моделей
- Конфиденциальный анализ

## 🚀 Использование
1. Страница: `/ollama-chat`
2. API: `/api/ollama-chat`
3. Параметры: `?model=llama3&q=Привет`
