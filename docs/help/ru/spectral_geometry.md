# Спектральная геометрия: spectral_geometry.py

## Простое объяснение (для новичков)

Этот файл — «ЭКГ инфосферы». Он измеряет, насколько устойчива система связей между источниками и темами. Проще говоря: насколько легко в этой системе распространяется ложь или вирусный контент.

**Как это работает:**

Представьте, что источники — это города, а связи между ними — дороги. Если дорог много и они образуют запутанную сеть — любая новость разлетится по всей системе почти без сопротивления. Если сеть разреженная — сигнал затухает внутри своего кластера.

Модуль считает «спектральную щель» — численную меру того, насколько хорошо сеть «перемешивает» сигнал.

**Что означает результат:**

- **Узкая щель** — система «сверхпроводящая» для лжи. Любой вброс распространяется мгновенно. Состояние паники или массовой истерии.
- **Широкая щель** — система устойчива. Сигнал затухает внутри кластера. Ложь не выходит за пределы своего пузыря.

**Зачем это нужно:**

Это объясняет, почему в одних обществах пропаганда не работает, а в других захватывает всех за дни. Дело не в «правде» или «лжи», а в топологии связей — в спектре.

**Аналогия:**

Представьте два пруда. В одном вода спокойная — брошенный камень даёт круги, которые затухают. В другом — вода «перегретая» — камень вызывает волну, которая не затухает. Спектральная щель — это численная мера «перегретости» информационного пруда.

## Научная база (для специалистов)

Модуль реализует **спектральный анализ графа** через вычисление собственных значений матрицы Лапласа.

**Формально:**

1. **Матрица смежности `A`:** для графа связей между источниками и темами. `A[i][j] = 1`, если есть связь, иначе `0`.

2. **Матрица степеней `D`:** диагональная матрица, где `D[i][i]` = степень узла `i` (число связей).

3. **Оператор Лапласа `L`:** `L = D - A`. В физике описывает, как тепло или вибрация распространяются по телу. В инфополе — как распространяется сигнал.

4. **Спектр:** набор собственных значений `λ_1 ≤ λ_2 ≤ ... ≤ λ_n` матрицы `L`.

5. **Спектральная щель:** `gap = λ_2 - λ_1`.

**Почему `λ_1` близка к нулю:**

`λ_1` всегда равна 0 для связного графа. Это математическое свойство: оператор Лапласа имеет как минимум одно нулевое собственное значение. Интерес представляет `λ_2` — алгебраическая связность (связность Фидлера).

**Интерпретация:**

- **`gap > 0.5`** — система устойчива. Сигнал затухает внутри кластеров. `IMMUNE_TO_PROPAGANDA`.
- **`gap ≈ 0`** — система «сверхпроводящая». Любой вброс распространяется без сопротивления. `HIGHLY_VULNERABLE`.

**Почему `scipy.sparse`:**

Для больших графов (миллионы узлов) полное разложение матрицы невозможно. `scipy.sparse.linalg.eigsh` с `which='SM'` (Smallest Magnitude) находит только несколько наименьших собственных значений. Это в 1000 раз быстрее полного расчёта.

**Ограничения:**

- Пороги щели зависят от масштаба и плотности графа. Калибруйте на исторических срезах.
- `λ_1` всегда близка к нулю — это норма. Интерес представляет `λ_2`.
- Матрица должна быть симметричной и без «висячих» изолированных узлов. Иначе спектр искажается.
- Модуль вычислительно тяжёл на плотных графах. Запускайте по расписанию, а не на каждый запрос.

## Как работает (пошагово)

1. `analyze_spectral_gap(adjacency_matrix)` принимает матрицу смежности.
2. Строит граф через `networkx.from_numpy_array()`.
3. Строит оператор Лапласа через `nx.laplacian_matrix()`.
4. Находит 3 наименьших собственных значения через `scipy.sparse.linalg.eigsh(L, k=3, which='SM')`.
5. Берёт `λ_1` и `λ_2` (первые два из трёх).
6. Вычисляет `gap = λ_2 - λ_1`.
7. Сравнивает с порогом:
   - `gap > 0.5` → `IMMUNE_TO_PROPAGANDA`.
   - `gap ≤ 0.5` → `HIGHLY_VULNERABLE`.
8. Возвращает объект: `{ spectral_gap, lambda_1, lambda_2, system_resilience }`.

**Формат ответа:**

```python
{
    'spectral_gap': 0.12,
    'lambda_1': 0.13,
    'lambda_2': 0.25,
    'system_resilience': 'HIGHLY_VULNERABLE'
}

Интерпретация:

    spectral_gap = 0.12 — узкая щель. Система высокопроводящая.

    system_resilience = 'HIGHLY_VULNERABLE' — высокий риск быстрого распространения возмущений.

Пример использования
python

from services.spectral_geometry import analyze_spectral_gap
import numpy as np

# Матрица смежности: 3 источника, связи между ними
adjacency_matrix = np.array([
    [0, 1, 1],
    [1, 0, 0],
    [1, 0, 0]
])

result = analyze_spectral_gap(adjacency_matrix)
print(result)
# {'spectral_gap': 0.12, 'lambda_1': 0.13, 'lambda_2': 0.25, 'system_resilience': 'HIGHLY_VULNERABLE'}

Что происходит:

    Модуль строит граф из матрицы смежности.

    Вычисляет оператор Лапласа.

    Находит два наименьших собственных значения.

    Вычисляет gap = λ_2 - λ_1.

    Сравнивает с порогом 0.5.

    Возвращает результат.

Практические рекомендации

    Пороги щели зависят от масштаба и плотности графа. Калибруйте на исторических срезах. Не переносите значения из одного графа в другой.

    λ_1 всегда близка к нулю. Это норма. Интерес представляет λ_2 (алгебраическая связность).

    Матрица должна быть симметричной. Если граф направленный — используйте (A + A^T) / 2. Иначе спектр искажается.

    Удалите изолированные узлы. «Висячие» узлы дают нулевые собственные значения и искажают спектр.

    Проводите стресс-тесты. Пересчитывайте щель при удалении части крупнейших источников. Смотрите, как меняется устойчивость.

    Модуль вычислительно тяжёл на плотных графах. Запускайте по расписанию (раз в час) или по событию (при новом алерте). Не на каждый запрос.

    Для отчётов переводите числа в относительную шкалу (нормируйте на максимальное историческое значение). Иначе читателю трудно интерпретировать абсолютные величины.

    Комбинируйте с chaos_theory_engine.py. Если Ляпунов высокий, а щель узкая — система «перегрета» и «сверхпроводящая» одновременно. Это сильный сигнал.

    scipy.sparse.linalg.eigsh — только для симметричных матриц. Для несимметричных — eigs. Но для инфополя обычно используется симметричная матрица.

    networkx.laplacian_matrix — стандартный способ. Не изобретайте свой оператор Лапласа.

    gap > 0.5 — эмпирический порог. Для разных графов может быть разным.
