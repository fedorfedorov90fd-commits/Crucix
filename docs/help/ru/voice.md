# Voice — Голосовой интерфейс

## Что это

Voice — модуль для распознавания и синтеза речи, обработки голосовых команд. Позволяет управлять Crucix голосом: задавать вопросы, запрашивать отчёты, получать оповещения. Поддерживает множество языков, включая русский.

## Как пользоваться

1. Настройте микрофон и динамики
2. Получите API-ключ для STT/TTS (Google, Microsoft, OpenAI)
3. В `.env` пропишите ключи
4. Запустите модуль: `node scripts/collectors/collect-voice.mjs`
5. Произнесите: "Crucix, покажи отчёт по санкциям"

## Профессиональное использование

- **Оперативные центры** используют голосовое управление
- **Диспетчеры** освобождают руки
- **Специалисты с ограниченными возможностями** используют как основной интерфейс
- **Разработчики** интегрируют оповещения

## ❓ Часто задаваемые вопросы

**Вопрос:** Какие языки поддерживаются?
**Ответ:** 50+ языков, включая русский, английский, китайский.

**Вопрос:** Нужен ли интернет?
**Ответ:** Да, для облачных API (Google, Microsoft) или нет для локальных моделей.

**Вопрос:** Какие команды поддерживаются?
**Ответ:** Любые, настраиваются в конфиге.

## 🎯 Интерактивный туториал

**Шаг 1:** Получите API ключ (Google Cloud Speech-to-Text)

```
# https://cloud.google.com/speech-to-text
```

**Шаг 2:** Сохраните ключ

```
echo "STT_API_KEY=ключ" >> .env
echo "TTS_API_KEY=ключ" >> .env
```

**Шаг 3:** Запустите модуль

```
node scripts/collectors/collect-voice.mjs
```

**Шаг 4:** Произнесите команду

```
# Скажите в микрофон: "Crucix, покажи отчёт по санкциям"
# Модуль распознает и выполнит
```
