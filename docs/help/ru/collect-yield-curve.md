# Кривая доходности: collect-yield-curve.mjs

## Простое объяснение (для новичков)

Этот файл — «финансовый рентген» системы. Он собирает не новости, а сухие цифры — доходность государственных облигаций США. И на их основе вычисляет главный макроэкономический индикатор — **инверсию кривой доходности**.

**Что такое кривая доходности:**

Представьте, что вы даёте деньги в долг государству. За 2 года оно обещает вернуть с одним процентом, за 10 лет — с другим. Обычно за 10 лет платят больше, чем за 2 (чем дольше срок — тем выше риск, тем выше процент).

Но иногда происходит странное: за 2 года платят больше, чем за 10. Это называется **инверсией**. И это — математический предвестник экономического спада.

**Что делает модуль:**

1. **Скачивает** данные с официального сайта Минфина США (`home.treasury.gov`).
2. **Извлекает** доходность 2-летних и 10-летних облигаций.
3. **Вычисляет спред:** `10Y - 2Y`.
4. **Определяет статус:**
   - `spread < -0.5` → `CRITICAL` (глубокая инверсия, риск рецессии через 6–12 месяцев).
   - `spread < 0` → `HIGH` (инверсия, замедление экономики).
   - `spread > 1.5` → `HIGH` (сильный рост, ожидание инфляции).
   - иначе → `NORMAL` (нормальная кривая).
5. **Сохраняет** в таблицу `yield_curve` с полями `date`, `yield_10y`, `yield_2y`, `spread`, `status`, `message`.

**Зачем это нужно:**

Это «Lead Time» — время упреждения. Мы видим кризис ещё до того, как он начался. Если модуль показывает `CRITICAL`, значит, через полгода в экономике начнутся большие проблемы, независимо от того, что пишут в газетах.

**Аналогия:**

Это как градусник для экономики. Если температура 38° — вы знаете, что что-то не так, ещё до того, как появились симптомы. Инверсия кривой доходности — это «температура 38°» для мировой экономики.

## Научная база (для специалистов)

Кривая доходности (yield curve) отражает зависимость процентных ставок от срока кредита. В нормальной экономике за 10 лет платят больше, чем за 2 года. Отрицательная разница (инверсия) исторически предшествовала рецессиям с упреждением 6–18 месяцев (lead time). Это стандартный термин из учебников по финансам.

**Формально:**

**spread = yield_10Y - yield_2Y**

- `spread > 0` — нормальная кривая. Долгосрочные ставки выше краткосрочных.
- `spread < 0` — инверсия. Краткосрочные ставки выше долгосрочных. Инвесторы ожидают снижения ставок в будущем (из-за рецессии).
- `spread < -0.5` — глубокая инверсия. Сильный сигнал рецессии.

**Источник данных:**

`home.treasury.gov` — официальный API Минфина США. OData XML, без ключа. Возвращает дневные данные за год. Формат:

```xml
<entry>
  <content>
    <m:properties>
      <d:NEW_DATE>2026-10-30T00:00:00</d:NEW_DATE>
      <d:BC_2YEAR>4.56</d:BC_2YEAR>
      <d:BC_10YEAR>4.94</d:BC_10YEAR>
    </m:properties>
  </content>
</entry>

Fallback-источники:

    FRED (Federal Reserve Economic Data) — требует API-ключ. Используется как fallback, если Treasury недоступен.

    stooq — закрыт с 2026 (CAPTCHA), не используется.

Парсинг:

Регулярное выражение ищет <d:BC_2YEAR> и <d:BC_10YEAR>. Важно: теги могут иметь атрибуты (<d:BC_2YEAR m:type="Edm.Double">), поэтому regex должен быть устойчив к атрибутам.
Как работает (пошагово)

    main() читает YIELD_SOURCE из .env (по умолчанию auto).

    fetchYieldSeries(source, fredKey) выбирает источник:

        treasury — только Treasury.

        fred — только FRED.

        auto — Treasury, при ошибке → FRED (если ключ есть).

    fetchFromTreasury() скачивает OData XML за текущий год.

    parseTreasuryXml(xml) извлекает записи: date, y10, y2.

    Если записей нет — ошибка no rows parsed (формат изменился?).

    saveSeries(client, source, rows) сохраняет в таблицу yield_curve через INSERT ... ON CONFLICT (date) DO UPDATE.

    Для каждой записи вычисляется spread и status через classifySpread().

    Возвращается итог: сколько записей получено, сколько вставлено, сколько обновлено.

Классификация:
javascript

export function classifySpread(spread) {
  if (spread < -0.5) return { status: 'critical', message: 'ГЛУБОКАЯ ИНВЕРСИЯ: риск рецессии (Lead Time: 6-12 мес)' };
  if (spread < 0)    return { status: 'high',     message: 'Инверсия: ожидание замедления экономики' };
  if (spread > 1.5)  return { status: 'high',     message: 'Сильный Steepener: ожидание инфляции/роста' };
  return { status: 'normal', message: 'Нормальная кривая' };
}

Практические рекомендации

    YIELD_SOURCE=treasury — основной источник. Официальный, без ключа, стабильный.

    YIELD_SOURCE=auto — если Treasury недоступен, переключается на FRED (если ключ задан). Надёжнее, но требует FRED_API_KEY.

    YIELD_SOURCE=fred — только FRED. Требует ключ. Используйте, если Treasury заблокирован.

    Запускайте раз в день — данные обновляются раз в сутки (после закрытия торгов). Запуск чаще — лишняя нагрузка.

    ON CONFLICT (date) DO UPDATE — при повторном запуске за тот же день данные обновляются, а не дублируются.

    date::text в API — чтобы избежать сдвига тайм-зоны. pg конвертирует DATE в JS Date в локальной TZ, и 2026-10-30 превращается в 2026-10-29T21:00:00.000Z. ::text отдаёт "2026-10-30" без времени.

    classifySpread — порог -0.5 для глубокой инверсии. Для российской кривой (ОФЗ) пороги могут отличаться — калибруйте под свой рынок.

    max_items_per_feed: 100 — не применимо к yield curve (это не RSS). Но общий принцип: не тянуть больше, чем нужно.

    Если Treasury недоступен из РФ — используйте YIELD_SOURCE=fred + FRED_API_KEY. Или — MOEX КБД (российская кривая ОФЗ) как отдельный эндпоинт.

    Таблица yield_curve — 209 строк за год. Не удаляйте старые данные: они нужны для анализа трендов.

Ключевые решения (запомнить!)

    Treasury OData XML — не JSON. response.json() — баг. Парсить XML через regex или fast-xml-parser.

    Теги с атрибутами. <d:BC_2YEAR m:type="Edm.Double">4.21</d:BC_2YEAR> — regex должен быть устойчив к атрибутам.

    d:Date → d:NEW_DATE. С 2025 Минфин США переименовал тег. Парсер должен искать оба варианта.

    date::text в SQL. Иначе pg конвертирует DATE в JS Date в локальной TZ, и дата сдвигается на день.

    ON CONFLICT (date) DO UPDATE. При повторном запуске данные обновляются, а не дублируются.
