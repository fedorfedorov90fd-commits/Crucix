# BDI Module

## 📋 Описание
**Русский:**
Модуль **BDI** отслеживает Балтийский сухой индекс (Baltic Dry Index) — ключевой индикатор глобальной торговли и экономической активности. Отражает стоимость перевозки сырьевых товаров морем. Используется для прогнозирования экономического цикла.

**English:**
The **BDI** module tracks the Baltic Dry Index — a key indicator of global trade and economic activity. Reflects the cost of shipping raw materials by sea. Used for economic cycle forecasting.

## 🎯 Назначение
- Оценка глобальной торговли
- Прогнозирование экономического цикла
- Индикатор спроса на сырьё

## 🚀 Использование
1. Страница: `/bdi`
2. API: `/api/bdi`
3. Параметры: `?interval=30d`
