# Jarvis Cards Module

## 📋 Описание
**Русский:**
Модуль **Jarvis Cards** предоставляет карточки с результатами работы AI-ассистента Jarvis. Отображает анализ данных, прогнозы, рекомендации в удобном карточном формате для быстрого просмотра.

**English:**
The **Jarvis Cards** module provides cards with Jarvis AI assistant results. Displays data analysis, forecasts, recommendations in a convenient card format for quick viewing.

## 🎯 Назначение
- Визуализация результатов AI
- Карточный интерфейс
- Быстрый просмотр

## 🚀 Использование
1. Страница: `/jarviskart`
2. API: `/api/jarviskart`
3. Параметры: `?type=forecast&limit=10`
