# Виджет статей: articles.js

## Простое объяснение (для новичков)

Этот файл — «лента новостей» на дашборде. Он показывает последние 20 статей из базы в виде списка: заголовок, источник, время публикации и цветной ярлык группы (russian / western / neutral).

**Что он делает:**

1. Запрашивает у API `/api/layers/articles?limit=20` список статей.
2. Для каждой статьи создаёт блок с:
   - цветным ярлыком группы (`russian` — синий, `western` — красный, `neutral` — зелёный);
   - именем источника;
   - временем публикации;
   - кликабельным заголовком (открывается в новой вкладке).
3. Если статей нет — показывает «Нет статей».
4. Если ошибка — показывает сообщение об ошибке.

**Зачем это нужно:**

Это «витрина» для аналитика. Он открывает дашборд и сразу видит: что происходит в информационном поле прямо сейчас, от кого, в какое время. Без этого виджета дашборд был бы набором графиков без «живого» контента.

**Аналогия:**

Это как лента в социальной сети. Только вместо постов друзей — новости от СМИ, и вместо лайков — цветовые метки групп.

## Научная база (для специалистов)

Виджет реализует паттерн **Presentational Component**: он не содержит бизнес-логики, только получает данные и отображает их.

**Архитектура:**

- **Источник данных:** `GET /api/layers/articles?limit=20` — API-модуль `articles-api.mjs`.
- **Формат данных:** массив объектов `{ title, link, source, published_at, group }`.
- **Рендеринг:** Vanilla JS, `innerHTML` с шаблонными строками. Без React/Vue — чистый DOM.
- **Стилизация:** инлайн-стили (без внешних CSS-файлов). Это делает виджет портативным: можно вставить на любую страницу.
- **Цветовая кодировка:** `groupColor = { russian: '#3b82f6', western: '#ef4444', neutral: '#10b981' }`. Синий/красный/зелёный — интуитивная семиотика.
- **Обработка ошибок:** `try/catch` вокруг `fetch`. Если API недоступен — показывается сообщение, страница не падает.

**Ограничения:**

- `max-height: 500px; overflow-y: auto` — список скроллится, не растягивает страницу.
- `limit=20` — жёстко задано. Для других нужд — параметр в URL.

## Как работает (пошагово)

1. При загрузке страницы (`DOMContentLoaded`) вызывается `mountArticles()`.
2. `mountArticles()` находит контейнер по `id` (по умолчанию `'articles'`).
3. Отправляет `fetch('/api/layers/articles?limit=20')`.
4. Получает JSON, извлекает `data.items`.
5. Если массив пуст — показывает «Нет статей».
6. Если не пуст — проходит по каждой статье, формирует HTML-блок:
   - ярлык группы (цветной);
   - имя источника;
   - время публикации (в локали `ru-RU`);
   - заголовок (ссылка на оригинал).
7. Вставляет весь HTML в контейнер.
8. Применяет стили (фон, граница, скролл).

## Пример использования

**В HTML-странице:**

```html
<div id="articles"></div>
<script type="module" src="/widgets/articles.js"></script>

В другом виджете (программно):
javascript

import { mountArticles } from '/widgets/articles.js';

mountArticles('my-articles-container');

Пример данных от API:
json

{
  "count": 20,
  "items": [
    {
      "title": "Силы ПВО уничтожили три БПЛА на подлете к Москве",
      "link": "https://tass.ru/...",
      "source": "ТАСС",
      "published_at": "2026-11-02T08:32:49.000Z",
      "group": "russian"
    }
  ]
}

Практические рекомендации

    limit=20 — оптимально для виджета. Больше — тормозит рендеринг. Меньше — не видно картины.

    Цветовая кодировка — синий/красный/зелёный. Для дальтоников можно добавить иконки (🔵/🔴/🟢) или текстовые метки.

    Инлайн-стили — делают виджет портативным. Но для сложных дашбордов лучше вынести в CSS-файл.

    max-height: 500px — список скроллится. Если хотите видеть больше — увеличьте, но следите, чтобы не ломать сетку дашборда.

    Ссылки открываются в новой вкладке (target="_blank") — аналитик не теряет дашборд.

    Время в локали ru-RU — toLocaleTimeString('ru-RU'). Для других языков — замените локаль.

    Обработка пустого массива — показывается «Нет статей». Не оставляйте пустой блок без сообщения.

    Обработка ошибок — показывается сообщение об ошибке. Не давайте странице «молча» падать.
