# TIPS Module

## 📋 Описание
**Русский:**
Модуль **TIPS** отслеживает реальные процентные ставки через инфляционно-индексируемые облигации (TIPS). Показывает реальную доходность, инфляционные ожидания и денежно-кредитную политику.

**English:**
The **TIPS** module tracks real interest rates through Treasury Inflation-Protected Securities (TIPS). Shows real yields, inflation expectations and monetary policy.

## 🎯 Назначение
- Оценка реальных ставок
- Инфляционные ожидания
- Денежно-кредитная политика

## 🚀 Использование
1. Страница: `/tips`
2. API: `/api/tips`
3. Параметры: `?maturity=10y`
