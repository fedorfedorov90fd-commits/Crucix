# Debt-to-GDP Module

## 📋 Описание
**Русский:**
Модуль **Debt-to-GDP** отслеживает государственный долг в процентах к ВВП по странам. Показывает динамику, структуру долга, риски дефолта и бюджетную устойчивость. Используется для макроэкономического и кредитного анализа.

**English:**
The **Debt-to-GDP** module tracks government debt as percentage of GDP by country. Shows dynamics, debt structure, default risks and fiscal sustainability. Used for macroeconomic and credit analysis.

## 🎯 Назначение
- Оценка долговой устойчивости
- Риски дефолта
- Сравнение стран

## 🚀 Использование
1. Страница: `/debt-gdp`
2. API: `/api/debt-gdp`
3. Параметры: `?country=US&type=general`
