───────────────────────────────────────
НАЗНАЧЕНИЕ
───────────────────────────────────────
Показать геополитические полюса: какие страны к какому полюсу
принадлежат, с какой уверенностью, и какие векторы действуют
между полюсами.

КЛЮЧЕВОЙ ПРИНЦИП:
  Полюс НЕ задан списком — он ВЫЧИСЛЕН из данных.
  Если данные изменятся, полюс изменится автоматически.

───────────────────────────────────────
КАК ПОЛЬЗОВАТЬСЯ
───────────────────────────────────────
1. Открой http://localhost:3117/pole-map
2. Страница загружает данные из /api/layers/pole-tracker
3. Смотри блоки:
   - Badge с индексом полярности (сверху справа)
   - Три карточки дебатов (позиции Россия/Запад/Неприсоединившиеся)
   - Три колонки полюсов со странами
   - Блок «Не классифицированы»
   - Векторы полярности
   - Basket-статус

Автообновление каждые 60 секунд.

───────────────────────────────────────
ЧТО ПОКАЗЫВАЕТ КАЖДАЯ ЧАСТЬ
───────────────────────────────────────
BADGE ИНДЕКСА (сверху справа)
  Число 0.0..1.0.
  <0.3 — зелёный (однополярный мир)
  0.3..0.6 — жёлтый (умеренная полярность)
  >0.6 — красный (сильная полярность)

ТРИ КАРТОЧКИ ДЕБАТОВ
  Позиции по полярности:
  🇷🇺 Россия: «Мир многополярный»
  🇺🇸 Запад: «Мир однополярный»
  🌍 Неприсоединившиеся: «Многополярность как возможность не выбирать»

КОЛОНКА «РОССИЙСКИЙ ПОЛЮС»
  - Название фрейминга
  - Список стран с confidence-барами (первые 20)
  - Итого: сколько всего стран

КОЛОНКА «ЗАПАДНЫЙ ПОЛЮС»
  Симметрично

КОЛОНКА «НЕПРИСОЕДИНИВШИЕСЯ»
  Симметрично

БЛОК «НЕ КЛАССИФИЦИРОВАНЫ»
  Страны, по которым недостаточно данных
  (confidence = 0.1, basis = no_data)
  Показывается списком тегов.

ВЕКТОРЫ ПОЛЯРНОСТИ
  sanctions_flow       — поток санкций (detected/no_data)
  info_war             — информационная война
  military_presence    — военное присутствие
  economic_decoupling  — экономический разрыв
  diplomatic_activity  — дипломатическая активность
  un_voting            — голосования в ООН
  Статус: detected (зелёный) / partial_data (жёлтый) / no_data (серый)

BASKET-СТАТУС
  По каждому индикатору:
  sanctions, conflicts, internet_outages, military_bases, gdelt,
  trade, unrest, diplomatic, un_votes
  Показывает: loaded + source_file + records.
  Серые — «нет файла». Зелёные — «загружено N записей».

───────────────────────────────────────
КНОПКА «КОПИРОВАТЬ»
───────────────────────────────────────
Девять форматов. Копирует снапшот карты: индекс, дебаты,
полюса со странами и confidence.

───────────────────────────────────────
КНОПКА «HELP»
───────────────────────────────────────
Открывает этот файл.

ЧАСТЫЕ ПРОБЛЕМЫ
───────────────────────────────────────
Большинство стран в «Не классифицированы»
  Это нормально для первой версии. Basket-файлы неполные.
  Чем больше файлов в data/basket/ и чем они полнее, тем меньше unknown.

Все confidence в диапазоне 0.3-0.6
  Сейчас countMentions ищет подстроку в JSON — это грубо.
  Точная классификация требует парсинга направленных санкций,
  голосований в ООН, торговых потоков по полям.

Страница пустая (нет данных)
  Ctrl+Shift+R (hard reload). Возможно кэш.
