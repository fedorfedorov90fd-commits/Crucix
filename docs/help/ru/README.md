## Быстрый старт

1. **Установите API-ключи** (для FRED, NewsAPI, NOAA, OpenSky, Social) в `.env`
2. **Запустите сборщик** нужного модуля: `node scripts/collectors/collect-{name}.mjs`
3. **Получите данные** через API: `http://localhost:3117/api/{name}?params`
