=== ТРЕБОВАНИЯ К ИНТЕРФЕЙСУ УПРАВЛЕНИЯ RSS ===

== 1. ПАНЕЛЬ УПРАВЛЕНИЯ RSS (РАЗВОРАЧИВАЮЩЕЕСЯ ОКНО) ==

Функции:
- Посмотреть список всех RSS-лент (название, URL, статус)
- Добавить одну новую ленту (ввести URL и название)
- Удалить ленту (кнопка рядом с каждой)
- Обновить все ленты (кнопка)
- Импортировать OPML-файл (загрузить с компьютера)
- Экспортировать OPML-файл (скачать текущий список)

Статистика:
- Всего лент: X
- Работающих лент: X
- Не работающих лент: X

== 2. ЛЕНТА НОВОСТЕЙ (ОТДЕЛЬНОЕ ОКНО) ==

2.1. Региональные фильтры (как в WorldMonitor)

Строка кнопок-фильтров по регионам:
- 🌍 МИР (все новости)
- 🇺🇸 США
- 🇪🇺 ЕВРОПА
- 🌍 АФРИКА
- 🏛 БЛИЖНИЙ ВОСТОК
- 🌎 ЛАТИНСКАЯ АМЕРИКА
- 🌏 АЗИАТСКО-ТИХООКЕАНСКИЙ РЕГИОН
- ⚡ ЭНЕРГЕТИКА И РЕСУРСЫ
- 🏛 ПРАВИТЕЛЬСТВО
- 🧠 АНАЛИТИЧЕСКИЕ ЦЕНТРЫ
- 📊 ПРОГНОЗЫ

При нажатии на кнопку — в ленте показываются только новости из выбранного региона.
Кнопка "МИР" — показывает все новости (по умолчанию).

2.2. Формат отображения

Окно с новостями, которые прокручиваются по кругу (как в WorldMonitor).
Каждая новость — это короткая строка с заголовком.
При наведении мыши на новость — прокрутка останавливается.
Переключатель "Автопрокрутка" (галка) — включает/выключает автоматическую прокрутку.

2.3. Количество новостей

- По умолчанию: 20 новостей
- Возможность настроить: до 30 (пользователь выбирает)

2.4. Скорость прокрутки

- Текущая скорость — слишком быстрая
- Нужно добавить регулятор скорости (или сделать медленнее по умолчанию)

2.5. Счётчик новостей

Внизу окна с бегущими новостями отображается:
"Новостей за сегодня: X"
