# cii — Индекс нестабильности стран (Country Instability Index)

## 📋 Описание
**Русский:**
Модуль **cii-api** отдаёт **Индекс нестабильности стран (CII)** — сводный показатель, оценивающий уровень внутренней нестабильности государства по 5 уровням (от низкого до критического).

## 🎯 Назначение
- Отображение индекса нестабильности стран на choropleth-карте мира.
- Ранжирование стран по 5 уровням нестабильности.
- Основа для анализа рисков и прогнозирования кризисов.

## 🚀 Использование
- Страница: `/cii` (или через панель слоёв на `/geo-map`)
- API-эндпоинт: `GET /api/layers/cii`
- Подпути: `?format=json|csv|series|stats|raw`
- Связанные метрики: 5 уровней нестабильности (`CRITICAL`, `HIGH`, `MEDIUM`, `LOW`, `STABLE`)
