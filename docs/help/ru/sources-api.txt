=== SOURCES-API — СПРАВКА ===

МОДУЛЬ:      apis/sources/sources-api.mjs
ТИП:         Layer (single-method, контракт v2)
ПОРТ:        3117
СТАТУС:      ✅ работает (200)

НАЗНАЧЕНИЕ:
  Отдаёт список источников RSS с агрегатами (адаптация feeds.mjs
  песочницы с Fastify+PostgreSQL на Express+basket).

ИСТОЧНИК:
  Fallback-цепочка (rsshub → rss-latest → rss-universal → rss).
  Сборщик: scripts/collectors/collect-rsshub.mjs.

ЭНДПОИНТЫ:
  GET /api/layers/sources             — список источников
  GET /api/layers/sources/stats       — агрегаты (count, total_articles, by_group)
  GET /api/layers/sources/status      — health-check
  GET /api/layers/sources/feed-status — статусы (ok/error/last_seen)
  GET /api/layers/sources/top?n=N     — топ-N по количеству
  GET /api/layers/sources/by-group    — группировка по группам (russian/western/neutral)

  count: 11 источников
  total_articles: 500
  by_group: { russian: 6, western: 5 }

ПРИМЕРЫ:
  curl http://localhost:3117/api/layers/sources
  curl http://localhost:3117/api/layers/sources/by-group
