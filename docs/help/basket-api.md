# basket-api

## 📋 О МОДУЛЕ / ABOUT

**Русский:**
Центральное хранилище всех собранных данных. Все модули сохраняют данные в корзину в формате JSON.

**English:**
Central storage for all collected data. All modules save data to the basket in JSON format.

## 🚀 КАК ИСПОЛЬЗОВАТЬ / HOW TO USE

**Русский:**
1. Модуль доступен через API: `/api/basket-api/`
2. Для проверки статуса: `GET /api/basket-api/status`
3. Для получения данных: `GET /api/basket-api/`

**English:**
1. Module is available via API: `/api/basket-api/`
2. For status check: `GET /api/basket-api/status`
3. For data retrieval: `GET /api/basket-api/`
