# Облако слов: wordcloud.js

## Простое объяснение (для новичков)

Этот файл — «облако слов» на дашборде. Он показывает частотные темы в виде облака, где чем чаще слово встречается в новостях, тем крупнее оно отображается. Самые важные темы сразу бросаются в глаза.

**Что он делает:**

1. **Запрашивает данные** у API `/api/layers/articles?limit=500`.
2. **Извлекает слова** из заголовков статей.
3. **Считает частоту** — сколько раз каждое слово встретилось.
4. **Отбрасывает стоп-слова** — «и», «в», «на», «the», «a» и т.д.
5. **Строит облако** — слова располагаются в контейнере, размер пропорционален частоте.
6. **Раскрашивает** — слова разных групп (`russian`, `western`, `neutral`) разными цветами.

**Как читать облако:**

- Крупное слово — тема, о которой пишут чаще всего.
- Мелкое слово — редкая тема.
- Цвет — группа источника (синий — russian, красный — western, зелёный — neutral).

**Зачем это нужно:**

Вы сразу видите, о чём говорят СМИ прямо сейчас. Без чтения сотен заголовков. Это «снимок» информационного поля.

**Аналогия:**

Это как облако тегов на сайте. Вы открываете и сразу видите: «энергетика», «Украина», «санкции» — крупные. Значит, об этом говорят больше всего.

## Научная база (для специалистов)

Виджет реализует **word cloud** — визуализацию частотного распределения слов, где размер шрифта пропорционален частоте.

**Архитектура:**

- **Технология:** Vanilla JS, HTML/CSS. Без D3.js — для простоты и скорости.
- **Данные:** `GET /api/layers/articles?limit=500` — статьи.
- **Извлечение слов:** из заголовков (`title`). Разбиение по пробелам и знакам препинания.
- **Стоп-слова:** словарь для русского и английского. «И», «в», «на», «the», «a» — отбрасываются.
- **Фильтр длины:** слова короче 4 символов — отбрасываются. Это убирает предлоги и союзы.
- **Частота:** `Map<word, count>`. Для каждого слова — сколько раз встретилось.
- **Размер:** `fontSize = 12 + (count / max_count) * 36`. От 12 до 48 px.
- **Цвет:** по группе источника, где слово встречается чаще всего.

**Формально:**

1. **Извлечение слов:** `words = extractWords(title)`.
2. **Фильтрация:** `filtered = words.filter(w => w.length > 4 && !STOP_WORDS.has(w))`.
3. **Частота:** `frequency[word]++` для каждого слова.
4. **Нормализация:** `size(word) = 12 + (frequency[word] / max_frequency) * 36`.
5. **Раскладка:** слова располагаются в контейнере (`flex-wrap`, `display: flex`). Без сложной упаковки — просто поток.

**Почему без D3.js:**

Для облака слов D3.js избыточен. Достаточно HTML/CSS с `flex-wrap`. Это проще, быстрее, портативнее.

**Почему размер 12–48 px:**

- Минимум 12 px — читаемость.
- Максимум 48 px — не перекрывает другие слова.
- Пропорционально частоте — интуитивно.

**Ограничения:**

- Без алгоритма упаковки слова могут перекрываться. Для плотных облаков — нужен `d3-cloud`.
- Стоп-слова — статический словарь. Для специфических корпусов — настройте.
- Слова короче 4 символов отбрасываются. Это убирает «США», «ЕС» — значимые слова. Добавьте белый список.
- Частота считается по заголовкам. Тело статьи не учитывается.

## Как работает (пошагово)

1. При загрузке страницы (`DOMContentLoaded`) вызывается `mountWordcloud()`.
2. `mountWordcloud()` находит контейнер по `id` (по умолчанию `'wordcloud'`).
3. Отправляет `fetch('/api/layers/articles?limit=500')`.
4. Получает JSON, извлекает `data.items`.
5. Для каждого item извлекает `title`.
6. Разбивает заголовок на слова, приводит к нижнему регистру, убирает пунктуацию.
7. Фильтрует: длина > 4, не стоп-слово.
8. Считает частоту через `Map`.
9. Находит `max_count` — максимальную частоту.
10. Сортирует по частоте (убывание).
11. Для каждого слова создаёт `<span>`:
    - `fontSize` пропорционален частоте.
    - `color` — по группе.
    - `display: inline-block`, `margin: 4px`.
12. Вставляет слова в контейнер (`flex-wrap`).
13. Применяет стили (фон, граница, скролл).

**Структура HTML:**

```html
<div id="wordcloud" style="display: flex; flex-wrap: wrap; gap: 8px;">
  <span style="font-size: 48px; color: #3b82f6;">энергетика</span>
  <span style="font-size: 36px; color: #ef4444;">санкции</span>
  <span style="font-size: 24px; color: #10b981;">Украина</span>
</div>

Пример использования

В HTML-странице:
html

<div id="wordcloud"></div>
<script type="module" src="/widgets/wordcloud.js"></script>

В другом виджете (программно):
javascript

import { mountWordcloud } from '/widgets/wordcloud.js';

mountWordcloud('my-wordcloud-container');

Что появится на экране:

    Облако слов: крупные — частые, мелкие — редкие.

    Цвета: синий (russian), красный (western), зелёный (neutral).

    flex-wrap — слова автоматически переносятся.

Пример данных от API:
json

{
  "items": [
    { "title": "Переговоры по энергетике возобновились", "source": "ТАСС", "group": "russian" },
    { "title": "Санкции против России усиливаются", "source": "Reuters", "group": "western" }
  ]
}

Практические рекомендации

    limit=500 — компромисс между полнотой и скоростью. Больше — тормозит.

    Стоп-слова — статический словарь. Для специфических корпусов — настройте. Добавьте «однако», «также», «который».

    Фильтр длины — 4 символа. Убирает предлоги, но пропускает «США», «ЕС». Добавьте белый список для таких слов.

    Размер 12–48 px — оптимально. Не делайте слишком мелкие — нечитаемо. Не делайте слишком крупные — перекрывают.

    Без D3.js — для облака достаточно HTML/CSS. Если нужна сложная упаковка — d3-cloud.

    flex-wrap — автоматический перенос. Не требует ручной раскладки.

    Цвета групп — синий/красный/зелёный. Интуитивно.

    Fallback на ошибки — если API недоступен, показывается «Нет данных». Страница не падает.

    Тёмная тема — background: #0d0d1a. Стандарт для профессиональных терминалов.

    Не используйте для > 100 слов — облако становится нечитаемым. Ограничьте топ-50.

    Сортировка по частоте — крупные слова первыми. Это делает облако читаемым.

    margin: 4px — минимальный отступ между словами. Без этого слова слипаются.

    overflow: auto — если слов много, они могут выходить за пределы. Скролл спасает.

    Для мобильных — уменьшите размер шрифта. 48 px на телефоне — слишком крупно.
