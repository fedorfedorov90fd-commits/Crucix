# cii-calculator API Module

## 📋 Описание
**Русский:**
API-модуль **cii-calculator** предоставляет REST API для работы с данными в системе Crucix.

## 🎯 Назначение
- Обработка API-запросов
- Валидация данных
- Формирование ответов

## 🚀 Использование
- GET `/api/cii-calculator` — получить данные
- POST `/api/cii-calculator` — создать запись
- PUT `/api/cii-calculator/:id` — обновить запись
- DELETE `/api/cii-calculator/:id` — удалить запись
