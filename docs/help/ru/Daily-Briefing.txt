============================================================
DAILY BRIEFING — ЕЖЕДНЕВНЫЙ AI-БРИФИНГ
============================================================
Версия: 1.0.0
Порт: 3160
Статус: ✅ РАБОТАЕТ

ОПИСАНИЕ
---------
Автоматическая генерация ежедневных AI-сводок на основе данных
из корзины Crucix. Использует Ollama для создания структурированных
брифингов с выделением ключевых событий, экономических трендов
и геополитических рисков.

ФУНКЦИИ
--------
- Сбор данных из корзины (последние 50 записей)
- Генерация структурированного брифинга через Ollama
- Разделы: главные события, экономика, риски, выводы
- Краткий формат (до 500 слов)

API ЭНДПОИНТЫ
-------------
GET    /briefing/latest          - Последний брифинг
POST   /briefing/generate        - Генерация брифинга

ПРИМЕРЫ ЗАПРОСОВ
----------------
# Получить последний брифинг
curl http://localhost:3160/briefing/latest

# Сгенерировать новый брифинг
curl -X POST http://localhost:3160/briefing/generate \
  -H "Content-Type: application/json" \
  -d '{"topics": ["geopolitics", "economy"]}'

СТРУКТУРА БРИФИНГА
------------------
1. ГЛАВНЫЕ СОБЫТИЯ (3-5 ключевых)
2. ЭКОНОМИЧЕСКИЙ ОБЗОР
3. ГЕОПОЛИТИЧЕСКИЕ РИСКИ
4. ВЫВОДЫ И РЕКОМЕНДАЦИИ

ЗАВИСИМОСТИ
-----------
- Node.js v22+
- Ollama (модель: llama3.2 или deepseek-r1)

УСТАНОВКА
---------
cd /home/ta8_/Рабочий стол/Crucix/crucix-extensions/daily-briefing
npm install
node index.mjs
