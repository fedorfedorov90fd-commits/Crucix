# 09. Нормализатор

[← Назад к INDEX](./INDEX.md)

## Расположение

/home/ta8_/Рабочий стол/Crucix/apis/sources/smartscroll-local/processing/normalizer.mjs

## Назначение

Приведение сырых событий к единому формату и извлечение сущностей.

## Класс

Normalizer

## Методы

- normalize(raw) — нормализация одного события
- normalizeBatch(raws) — пакетная нормализация

## Обработка

1. Очистка текста: удаление переводов строк, неразрывных пробелов, схлопывание пробелов
2. Извлечение сущностей через шаблоны:
   - аббревиатуры (2-6 заглавных)
   - имена собственные
   - даты
   - идентификаторы событий (например, рейс MH370)
3. Фильтрация стоп-слов
4. Ограничение: 30 сущностей на событие

## Выходной формат

- id, source, published_at, title, body
- entities, story_id, related_stories, url, category
