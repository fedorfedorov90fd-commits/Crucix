# Big Mac Index Alternative Module

## 📋 Описание
**Русский:**
Модуль **Big Mac Index Alternative** предоставляет альтернативные версии индекса Биг-Мака: с коррекцией на ВВП, на стоимость рабочей силы, с учётом налогов. Используется для более точного сравнения покупательной способности.

**English:**
The **Big Mac Index Alternative** module provides alternative versions of the Big Mac Index: adjusted for GDP, labour costs, taxes. Used for more accurate purchasing power comparison.

## 🎯 Назначение
- Альтернативные расчёты PPP
- Более точное сравнение валют
- Экономический анализ

## 🚀 Использование
1. Страница: `/big-mac-alt`
2. API: `/api/big-mac-alt`
3. Параметры: `?adjustment=gdp&currency=RUB`
