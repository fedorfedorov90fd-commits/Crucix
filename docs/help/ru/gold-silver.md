# Gold-Silver Ratio Module

## 📋 Описание
**Русский:**
Модуль **Gold-Silver Ratio** отображает соотношение цен на золото и серебро — ключевой индикатор драгоценных металлов. Используется для оценки относительной стоимости, инфляционных ожиданий и торговых стратегий.

**English:**
The **Gold-Silver Ratio** module displays the gold-to-silver price ratio — a key precious metals indicator. Used for relative value assessment, inflation expectations and trading strategies.

## 🎯 Назначение
- Анализ драгоценных металлов
- Торговые сигналы
- Инфляционные ожидания

## 🚀 Использование
1. Страница: `/gold-silver`
2. API: `/api/gold-silver`
3. Параметры: `?interval=30d`
