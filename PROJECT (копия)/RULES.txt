=== ПРАВИЛА ПРОЕКТА CRUCIX ===
Версия: 1.0
Дата: 2026-08-10

=== ОСНОВНЫЕ ПРАВИЛА ===

1. НЕ ТРОГАТЬ БАЗОВУЮ ФУНКЦИОНАЛЬНОСТЬ
   - Файлы, созданные автором проекта, НЕ УДАЛЯТЬ
   - НЕ изменять базовый интерфейс (jarvis.html)
   - НЕ удалять существующие модули
   - Все изменения делать ТОЛЬКО через добавление новых файлов

2. ДОБАВЛЕНИЕ НОВЫХ МОДУЛЕЙ
   - Создавать новые панели в /dashboard/panels/НОВЫЙ_МОДУЛЬ/
   - Регистрировать в /dashboard/inject.mjs (НЕ удаляя существующие)
   - Встраивать через iframe или отдельные контейнеры

3. ИНТЕРФЕЙС
   - Базовый интерфейс остаётся неизменным
   - Новые панели добавляются как отдельные окна/вкладки
   - Не перекрывать существующие элементы

4. КООРДИНАТЫ И РАЗМЕРЫ
   - Каждая панель описывается в CSS с координатами
   - Использовать относительные единицы (%, vh, vw)
   - Не перекрывать другие панели без согласования

5. ОТВЕТСТВЕННОСТЬ
   - Перед изменениями — создать бэкап
   - Проверять, что оригинальный функционал работает
   - Документировать все изменения

=== КАК ОПИСЫВАТЬ ИНТЕРФЕЙС ===

Для эффективной работы используй такие формулировки:

"Панель X находится в правом верхнем углу, размер 360x400px"
"Добавить новую панель слева внизу, под существующей панелью"
"Сдвинуть панель Y на 20px вправо"
"Уменьшить ширину панели Z до 300px"

=== ЧТО НЕЛЬЗЯ ДЕЛАТЬ ===

- Удалять существующие файлы проекта
- Перезаписывать jarvis.html без бэкапа
- Удалять существующие панели из inject.mjs
- Менять базовую структуру без согласования

=== ЧТО МОЖНО ДЕЛАТЬ ===

- Добавлять новые панели в отдельные файлы
- Регистрировать новые панели в inject.mjs (дописывать в конец)
- Создавать новые страницы (/rss-feed, /rss-dashboard)
- Модифицировать только свои файлы

=== БЭКАПЫ ===

Перед любыми изменениями:
cp файл файл.bak.$(date +%Y%m%d_%H%M%S)

=== ПРАВИЛО №6: МНОГОЯЗЫЧНОСТЬ ===
Каждый модуль Crucix должен поддерживать как минимум 2 языка:
- Русский (RU) — основной
- Английский (EN) — международный

Дополнительные языки (подключаются по мере необходимости):
- Китайский (ZH) — 🇨🇳
- Хинди (HI) — 🇮🇳

Структура для добавления нового языка:
1. Добавить язык в langData в соответствующем модуле
2. Добавить кнопку языка в интерфейс
3. Перевести все текстовые элементы

Все языковые данные хранятся в объекте langData внутри модуля.
Переключение языка происходит мгновенно, без перезагрузки страницы.

=== ПРАВИЛО №7: РАБОТА С ФАЙЛАМИ ===
Локальный ИИ НИКОГДА не просит пользователя:
- "Найди строку X в файле"
- "Найди секцию Y"
- "Замени вручную строку Z"

ВСЕГДА давай ПОЛНЫЙ код файла целиком для замены.
Пользователь должен только скопировать и заменить файл.
