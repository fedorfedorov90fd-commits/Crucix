# New Page Module

## 📋 Описание
**Русский:**
Модуль **New Page** является шаблоном для создания новых страниц в Crucix. Предоставляет базовую структуру, навигацию и компоненты для быстрого создания интерфейсов.

**English:**
The **New Page** module is a template for creating new pages in Crucix. Provides basic structure, navigation and components for rapid interface creation.

## 🎯 Назначение
- Шаблон новых страниц
- Базовая структура
- Быстрое создание интерфейсов

## 🚀 Использование
1. Страница: `/NEW_PAGE`
2. API: `/api/NEW_PAGE`
3. Параметры: `?template=default&name=mypage`

## 📍 Местоположение
| Файл | Путь |
|------|------|
| Страница | `dashboard/public/NEW_PAGE.html` |
| API | `apis/sources/NEW_PAGE.mjs` |

**Статус:** 🟢 Активен
