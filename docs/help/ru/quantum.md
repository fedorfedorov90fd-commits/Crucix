# Quantum — Квантовые вычисления

## Что это

Quantum-модуль отслеживает новости, события и публикации в области квантовых вычислений и постквантовой криптографии. Собирает: анонсы новых процессоров, публикации в arXiv, угрозы RSA/ECC, миграцию на Kyber/Dilithium.

## Как пользоваться

1. Запустите сборщик: `node scripts/collectors/collect-quantum.mjs`
2. Сборщик парсит arXiv и новостные порталы
3. Данные сохраняются в `/basket/quantum/`
4. Используйте `http://localhost:3117/api/quantum?type=breakthrough`

## Профессиональное использование

- **Криптографы** отслеживают прогресс квантовых атак
- **Специалисты по безопасности** планируют миграцию
- **Инвесторы** оценивают квантовые компании
- **Исследователи** получают оповещения о публикациях

## ❓ Часто задаваемые вопросы

**Вопрос:** Какие источники используются?
**Ответ:** arXiv, NewsAPI, Google Scholar, блоги компаний.

**Вопрос:** Как часто обновляется?
**Ответ:** Ежечасно.

**Вопрос:** Какие алгоритмы отслеживаются?
**Ответ:** RSA, ECC, Kyber, Dilithium, SPHINCS+.

## 🎯 Интерактивный туториал

**Шаг 1:** Запустите сборщик

```
node scripts/collectors/collect-quantum.mjs
```

**Шаг 2:** Получите последние прорывы

```
curl "http://localhost:3117/api/quantum?type=breakthrough"
```

**Шаг 3:** Проверьте угрозы RSA

```
curl "http://localhost:3117/api/quantum?type=threat&algorithm=RSA"
```
