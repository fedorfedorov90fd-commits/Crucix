# Scenarios Module

## 📋 Описание
**Русский:**
Модуль **Scenarios** предоставляет библиотеку готовых сценариев и пресетов для анализа различных ситуаций: кризисы, конфликты, экономические шоки. Позволяет загружать, редактировать и запускать сценарии.

**English:**
The **Scenarios** module provides a library of ready-made scenarios and presets for analyzing various situations: crises, conflicts, economic shocks. Allows loading, editing and running scenarios.

## 🎯 Назначение
- Библиотека сценариев
- Быстрый анализ
- Обучение и тренировки

## 🚀 Использование
1. Страница: `/scenarios`
2. API: `/api/scenarios`
3. Параметры: `?category=crisis&id=ukraine`
